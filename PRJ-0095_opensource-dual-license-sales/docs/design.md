# 설계
- core.js: 순수 함수. 브라우저(window.Core)와 node(module.exports) 양쪽에서 쓴다.
- 구간표: 줄마다 "최대 직원 수,개발자 1명 연 단가". 오름차순이어야 하며 `parseTiers`가 오류를 알려 준다. 직원 수가 마지막 구간을 넘으면 자동 견적 없이 문의로 보낸다.
- 판정(`judge`): SaaS 내장 재배포면 유형과 무관하게 문의 필요 -> 개인·비영리는 무료 -> 회사는 구간에 맞으면 유료, 구간 밖이면 문의. 잘못된 입력은 문의 필요(오류).
- 견적(`quote`): 총액 = 개발자 수 x 연 단가 x 연수. 할인율은 1년 0%, 2년 d2%, 3년 이상 d3%. 공급가 = 총액 - round(총액 x 할인율). 부가세 = round(공급가 x 10%).
  연차별 줄은 공급가를 `allocate`로 나누고 부가세는 연차 공급가 비율로 나눠 항목 합 = 총합이 항상 맞는다.
- CLA(`claCheck`): 외부 기여 있음 + 서명 없음, 또는 카피레프트 의존이면 blocked(이중 라이선스 불가). 회사 허락 없음은 warn.
- 저장: localStorage 키 prj0095-v1, 읽기·쓰기 모두 try/catch.
- 표시: 법률 자문 아님, 구간·단가는 예시값이라는 문구를 첫 화면 위쪽에 둔다.
