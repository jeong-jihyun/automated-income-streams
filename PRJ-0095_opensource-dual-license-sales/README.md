# 오픈소스 이중 라이선스 판매

개인은 무료, 기업 상업용은 유료로 주는 이중 라이선스 판매를 준비하는 휴대폰용 도구입니다. 법률 자문이 아니며, 직원 수 구간·단가·할인율은 입력칸에서 바꿀 수 있는 예시값입니다. 인터넷 없이 돌아갑니다.

## 할 수 있는 것
1. 판정기: 사용자 유형(개인·비영리·회사), 직원 수, SaaS 내장 재배포 여부를 고르면 "무료 사용 가능 / 유료 라이선스 필요 / 문의 필요"와 이유를 보여 줍니다.
2. 견적: 직원 수 구간, 개발자 수, 연 단가, 계약 연수, 다년 할인으로 견적을 냅니다. 부가세 10%이고 연차별 줄의 합이 총합과 항상 맞습니다.
3. CLA 점검: 외부 기여 코드가 있는데 기여자 동의(CLA)가 없으면 "이중 라이선스 불가" 경고를 띄웁니다.

## 쓰는 법
1. `app/index.html`을 열면 샘플이 이미 들어 있고 결과가 바로 보입니다.
2. 칸을 바꾸고 각 버튼을 누르면 다시 계산합니다. "샘플로 되돌리기"로 처음 값으로 돌아갑니다.
3. 입력값은 이 기기의 localStorage에만 저장됩니다.

## APK 받아 설치하는 법
1. 저장소를 GitHub에 푸시합니다.
2. GitHub 저장소의 Releases에서 릴리스 태그 `apk-PRJ-0095` 를 찾아 `.apk` 파일을 받습니다.
3. 받은 파일을 눌러 설치합니다.
4. "출처를 알 수 없는 앱" 설치를 막으면, 설정에서 허용한 뒤 다시 설치합니다.

## 시험
폴더 안에서 `node --test tests/test_all.js` (Node 22는 `tests/`만 쓰면 실패하므로 파일 이름까지 적습니다.)

## 확인한 것 / 못 한 것
확인한 것
- core.js 시험 18개 모두 통과 (구간 경계 9/10·49/50·999/1000, SaaS 문의 판정, 잘못된 입력, 할인 경계, 연차별 공급가·부가세 합 보존, CLA 경고).
- index.html 안 스크립트 문법 검사 통과, 세 파일에 http 주소 없음, viewport 설정 있음.

못 한 것
- 실제 폰 설치·화면 미확인 (브라우저로 열어 보지 않았고 APK도 만들지 않았습니다).
- 사람 눈으로 본 글자 크기·배치 확인.
- 법률 검토, 실제 라이선스 문서 작성, 결제·전송·로그인은 만들지 않았습니다.
