# PRJ-0086 노코드 앱 제작 대행 (의뢰 사양 점검·견적 도구)

노코드 앱 의뢰 내용을 JSON 사양(역할·표·화면·요구사항)으로 적으면 서로 맞지 않는 곳(없는 표·역할 참조, 중복 화면 등), 사람이 확인할 곳(연락처 노출, 결제·오프라인 요구 등), 작업 시간 범위를 알려 주는 명령줄 도구입니다. **앱을 만들거나 노코드 도구에 연결하지 않습니다.**

## 쓰는 법
```
python -m nocodeplan sample/spec.json
```

## 지키는 것
- '고쳐야 할 것'은 사양이 모순인 경우(없는 표·역할·동작, 알 수 없는 칸 종류, 화면 이름 비었거나 중복)이며 있으면 종료 코드 1입니다.
- '확인할 것'은 안 쓰는 표·역할, 연락처가 여러 역할에 목록으로 보이는 화면, 결제·오프라인·실시간·1000명 초과·외부 연동 4개 이상 같은 요구입니다.
- 시간 = 표당 2시간 + 칸당 0.5시간 + 화면당 3시간 + 요구사항 가산이며 단가 5만원은 예시 설정입니다.
- JSON 형식이 틀리면 종료 코드 2입니다.

## 확인한 것 (테스트 9개 통과)
모순 6종 탐지, 안 쓰는 표·역할 경고, 연락처 노출 경고, 요구사항 경고, 시간 계산식, 문제 없는 사양은 0건, 보고서 구성·안내 문구, 사양 형식 오류와 CLI 종료 코드.

## 확인하지 못한 것
- 실제 노코드 도구(Bubble, Glide 등)에서 만들어 보지 못했습니다. 도구별 한도·가격은 다루지 않았고 경고 문구는 일반적인 주의일 뿐입니다.
- 시간·단가 식은 예시이며 실제 작업량과 맞는지 검증하지 못했습니다.
- 권한은 역할 이름 목록만 점검하며 행 단위 접근 제한은 점검하지 않습니다.
- 의뢰 접수·계약·제작·납품은 만들지 않았습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
