# PRJ-0035 AI 맞춤 문제 출제 서비스 (출제·채점 엔진)

문제은행에서 학년과 약점(주제별 정답률)에 맞춰 문제를 뽑고, 계산 문제는 즉석에서 만들어 문제지·정답지(HTML)를 만들고 채점하는 명령줄 도구입니다. AI가 만든 문제를 은행에 넣기 전 검사하는 관문도 있습니다. AI는 연결돼 있지 않습니다.

## 쓰는 법
```
python -m quizgen make sample/bank.json --grade 4 --n 5 --math 3 --profile me.json --out out
python -m quizgen grade out/quiz.json 0,2,1,0,3,1,0,2 --profile me.json
```

## 지키는 것
- 정답률이 낮은 주제를 더 자주 뽑고, 같은 seed면 같은 문제가 나옵니다.
- 계산 문제는 정답과 해설을 계산으로 만들어 틀린 정답이 나올 수 없습니다.
- AI가 만든 문제는 형식·보기 중복·정답 범위·질문 중복·(선택) 정답 검증 함수를 통과한 것만 받습니다.
- HTML은 모든 글자를 이스케이프하고, 보기 순서는 섞되 정답 위치를 함께 옮깁니다.

## 확인한 것 (테스트 8개 통과)
문제은행 검증, 계산 문제 정답 전수 확인(학년 1~6 × 60개), 약점 가중 선택, 재현성·중복 없음, 채점·약점 기록, HTML 이스케이프·보기 섞기, AI 문제 거르기, CLI.

## 확인하지 못한 것
- **샘플 문제 7개는 제가 만든 예시이며 교육과정에 맞는지 교사가 검수한 것이 아닙니다.** 서술형·그림·수학 외 과목 자동 출제는 하지 않았습니다.
- 실제 AI 문제 생성 연결과 생성 문제의 품질·난이도 정확성(검증 함수가 있는 계산 문제 외에는 정답을 확인할 방법이 없음)
- 학년별 난이도 설정은 임의 기준이며 실제 학생으로 시험하지 않았습니다.
- 로그인·학생 데이터 보관(아동 개인정보), 화면, 구독 결제, 배포
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
