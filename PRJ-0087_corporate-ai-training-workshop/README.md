# 기업 AI 업무 활용 교육

회사에서 AI 업무 활용 교육(워크숍)을 열 때 쓰는 휴대폰 앱이에요. 인터넷 없이 폰 안에서만 돌아가요.

## 할 수 있는 일
1. **견적·손익 계산**: 강사료, 장소비, 1인 자료비, 인원, 1인 참가비를 넣으면 총비용, 매출, 손익, 손익분기 인원, 인원별 손익 표를 보여 줘요. 총비용을 인원수로 나눌 때 남는 돈은 앞사람부터 1원씩 더해서, 나눈 값의 합이 항상 총비용과 같아요.
2. **업무별 AI 활용 체크리스트**: 7가지 업무(메일, 회의록, 보고서, 엑셀, 번역, 정보 규칙, 확인)에 "안 함/가끔/자주"를 고르면 점수와 교육 주제 제안이 나와요.

첫 화면에 샘플 값이 들어 있어서 열자마자 결과가 보여요. 값을 바꾸고 "계산하기"를 누르면 다시 계산해요. 입력은 이 기기의 localStorage에만 저장돼요.

## APK 받아 설치하는 법
1. 이 저장소를 GitHub에 푸시해요.
2. GitHub의 Releases에서 `apk-PRJ-0087` 항목을 열어 `.apk` 파일을 받아요.
3. 폰에서 받은 파일을 눌러 설치해요.
4. "출처를 알 수 없는 앱" 설치를 물으면 이 설정에서 허용해 주세요.

(APK는 이 폴더가 아니라 저장소 쪽 빌드 과정에서 만들어져요. 이 폴더에는 APK가 없어요.)

## 시험하는 법
```
node --test tests/test_all.js
```
(Node 22에서는 `node --test tests/` 처럼 폴더만 주면 실행되지 않아서 파일 이름까지 적어요.)

## 확인한 것 / 못 한 것
확인한 것
- core.js의 계산·판정 시험 16개가 모두 통과해요 (합계 보존, 손익분기, 입력 오류, 체크리스트 점수, 외부 주소·fetch 없음).
- index.html 안의 스크립트가 문법 오류 없이 읽혀요.

못 한 것
- 실제 폰 설치·화면 미확인 (버튼 동작, 글씨 크기, 줄바꿈은 눈으로 못 봤어요).
- 브라우저에서 localStorage 저장·불러오기를 직접 돌려 보지 못했어요.
- APK 빌드와 GitHub Releases 올리기는 하지 않았어요.
- 세금·강사료 규정 같은 실제 사정은 반영하지 않았어요. 금액은 입력한 값 그대로예요.
