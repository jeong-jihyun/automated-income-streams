# 설계
## 계산 규칙 (core.js)
- 비용 = 강사료 + 장소비 + 1인 자료비 x 인원. 매출 = 참가비 x 인원. 손익 = 매출 - 비용.
- 손익분기 인원 = ceil((강사료+장소비) / (참가비 - 자료비)). 참가비 <= 자료비면 없음(null).
- 비용 분담 splitCost: 몫 = floor(총액/인원), 나머지 r원은 앞 r명에게 1원씩. 합 = 총액.
- 입력: 쉼표·공백·"원"·"명"은 지우고 정수로 읽는다. 빈 값·글자·음수·인원 0은 오류 문구.
- 표: 1명부터 (최대 인원·손익분기·10 중 큰 값 + 5, 200 한도)까지. 40 넘으면 간격을 띄운다.
## 체크리스트
- 7개 업무, 답 0/1/2. 점수 = 합/14 를 백분율로 반올림. 75 이상 활용 잘함, 40 이상 활용 중, 그 미만 시작 단계.
## 화면
- 한 페이지, 세로 화면, 글씨 18px 이상, 입력은 숫자 키패드(inputmode numeric).
