# 효과음 팩 빌더 (PRJ-0004)

원본 소리 폴더에서 앞뒤 무음 제거, 음량 맞춤, 16비트 WAV 변환, 파일명 정리, 목록 CSV, 판매 설명·태그 초안, 미리듣기 mp3, 품질 검사를 해 주는 명령줄 도구 (ffmpeg 사용).

## 준비
ffmpeg 설치 후 pip install pytest

## 사용법
```
python -m sfx_builder ./원본소리 ./팩결과 --theme Doors --prefix doors
```

## 테스트
`python -m pytest -q`

## 정책 주의
AudioJungle/Pond5 로그인·자동 업로드·자동 입력 기능은 없습니다. 업로드는 사람이 직접 합니다. 직접 녹음·제작한 소리만 쓰세요. sfx_builder/settings.json 의 규격 값은 예시이므로 공식 안내를 보고 고치세요.

## 한계 (솔직하게)
자동 테스트는 프로그램이 만든 더미 파일로만 했습니다. 실제 마켓 심사 통과와 실제 작품 품질은 확인하지 못했습니다.
테스트 7건은 2026-10-20 이 저장소에서 ffmpeg 포함으로 다시 실행해 통과를 확인했습니다. 규격 값은 예시이며 마켓 공식 안내와 대조하지 않았습니다. 소리를 귀로 들어 확인하지 못했습니다.
