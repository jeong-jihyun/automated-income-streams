- `docs/PRJ-0004_UI-설계서_v1.0.docx`
- `docs/PRJ-0004_기능정의서_v1.0.docx`

## 실행
HTML 파일을 모바일 또는 데스크톱 브라우저에서 열면 됩니다. 별도 빌드 도구가 필요하지 않습니다.

## 프로젝트 기준
기존 README의 CLI 명령은 유지합니다:
`python -m sfx_builder ./원본소리 ./팩결과 --theme Doors --prefix doors`

기능 범위: 앞/뒤 무음 제거, 음량 정규화, 16-bit WAV 변환, 파일명 정리, 품질 검사, MP3 미리듣기 생성, 판매용 CSV·설명·태그 초안.

## 중요한 구현 구분
HTML은 모바일 UX 검토용 프런트엔드 컨셉 프로토타입입니다. 파일 선택과 로컬 미리듣기, 화면 이동, 폼 검증, CSV 데모 내보내기는 동작하지만 실제 FFmpeg 변환이나 Python CLI/API 호출은 연결되어 있지 않습니다. 실제 처리 기능은 기존 Python 프로젝트 실행 환경에서 수행해야 합니다.

마켓 로그인/자동 업로드/자동 폼 입력은 기존 README와 동일하게 제외합니다. 규격값은 예시이므로 판매처 공식 안내를 확인하고, 직접 제작했거나 상업적 권리를 보유한 음원만 사용하세요.
