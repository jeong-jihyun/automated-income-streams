# PRJ-0033 AI 여행 일정 자동 생성 서비스 (규칙 기반 엔진)

장소 목록(JSON), 일수, 예산, 취향으로 날짜별 일정표(운영 시간·이동 시간 반영)를 만드는 명령줄 도구입니다. AI 없이 규칙으로 계산하며, 제휴 링크가 있으면 표시 문구를 자동으로 붙입니다.

## 쓰는 법
```
python -m tripplan sample/places.json --days 2 --budget 100000 --interests food,nature --pace normal --out trip.md
```

## 지키는 것
- 예산을 넘지 않게만 고르고, 취향 장소를 먼저 고릅니다.
- 운영 시간 안에서만 배치하고 못 맞추는 곳은 '시간이 안 맞아 뺀 곳'에 적습니다.
- 제휴 링크가 있으면 수수료 가능성을 글 끝에 밝힙니다.
- 샘플 장소는 가상 데이터이며 실제 장소·가격이 아닙니다.

## 확인한 것 (테스트 10개 통과)
예산 상한, 취향 우선, 장소 중복 없음·하루 개수, 운영 시간 준수, 늦게 여는 곳 처리, 배치 불가 보고, 거리 계산, 입력 검증, 제휴 문구, CLI.

## 확인하지 못한 것
- **실제 장소·가격·운영 시간 데이터는 연결하지 않았습니다**(사용자가 준 JSON만 사용). 지도·교통·날씨 API 미연동, 이동 시간은 직선거리 추정입니다.
- AI(LLM) 일정 생성·자연어 요청 해석은 만들지 않았고, 일정 품질을 사람이 평가해 보지 않았습니다.
- 예약 제휴 프로그램 가입·링크 연동, 결제·구독, 화면, 배포
- 제휴 표시 문구의 법적 적합성(표시광고법 등)은 확인하지 않았습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
