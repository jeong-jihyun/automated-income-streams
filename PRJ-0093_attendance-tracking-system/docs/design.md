# 설계
- core.js: 순수 함수. 브라우저(window.Core)와 node(module.exports) 양쪽에서 쓴다.
- 입력: 줄마다 `이름 날짜 출근 퇴근`(공백·쉼표·세미콜론 구분). 모르는 시각은 `-`. `#` 줄은 메모. 읽을 수 없는 줄은 줄 번호와 함께 오류로 알리고 나머지는 계속 계산한다.
- 하루 계산(calcDay): 퇴근 <= 출근이면 +24시간(자정 넘김). 총 시간 = 퇴근 - 출근. 휴게는 총 시간이 휴게2 기준(8시간) 이상이면 60분, 휴게1 기준(4시간) 이상이면 30분, 아니면 0(예시값). 근무 = 총 - 휴게. 연장 = 근무 - 소정(8시간)의 양수 부분.
- 야간: 출근~퇴근 구간과 야간 시간대(기본 22~06시, 하루를 넘나드는 창을 전날·당일·다음날로 펼쳐 겹침 합산)의 겹친 분. 휴게 시각은 알 수 없으므로 근무시간을 넘지 않게만 제한한다.
- 지각·조퇴: 소정 출근·퇴근 시각과 비교하되 봐주는 분을 반영. 출근이 소정 퇴근 시각 이전에 시작한 근무에만 판정(야간조는 판정 안 함).
- 누락: 출근만/퇴근만/둘 다 없음은 경고를 내고 시간에 넣지 않는다. 같은 사람·같은 날 2건 이상, 하루 16시간 초과도 경고.
- 급여 참고: 직원별 정확값 = 시급 × (근무분 + 연장분×가산 + 야간분×가산) / 60. 총액 = 정확값 합을 한 번 반올림. 직원별 금액은 allocate()(가장 큰 나머지 순서)로 나눠 직원 합 = 총액이 항상 맞는다.
- 기준값은 모두 예시이며 normalize()가 이상한 값을 기본값으로 되돌린다.
- 저장: localStorage 키 prj0093-v1, 읽기·쓰기 모두 try/catch.
- 한계: 주휴수당, 4대보험, 소득세, 법정 휴게·가산의 실제 요건은 다루지 않는다.
