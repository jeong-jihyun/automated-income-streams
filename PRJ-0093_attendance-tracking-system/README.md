# 근태·출퇴근 자동 집계 시스템

소규모 사업장의 출퇴근 기록을 여러 줄 글로 붙여넣으면 근무시간, 휴게 차감, 연장·야간 시간, 지각·조퇴, 출근만/퇴근만 누락 경고를 계산하고, 직원별 월 합계와 시급을 곱한 "급여 참고 합계"(원 단위, 합계 보존)를 보여 줍니다. 인터넷 없이 휴대폰에서 돌아갑니다.

세법·노동법 자문이 아닙니다. 소정 8시간, 야간 22~06시, 휴게(4시간 이상 30분, 8시간 이상 60분), 가산 비율 0.5, 시급 10,320원은 모두 예시값이며 화면의 입력칸에서 바꿀 수 있습니다.

## 쓰는 법
1. `app/index.html`을 열면 샘플 기록이 이미 들어 있고 결과가 바로 보입니다.
2. 기록은 한 줄에 `이름 날짜 출근 퇴근` 형식입니다. 모르는 시각은 `-` 로 씁니다. 퇴근이 출근보다 이르면 다음 날 퇴근(자정 넘김)으로 봅니다.
3. 기준값이나 시급을 바꾸고 "계산하기"를 누르면 다시 계산합니다.
4. 입력값은 이 기기의 localStorage에만 저장됩니다.

## APK 받아 설치하는 법
1. 저장소를 GitHub에 푸시합니다.
2. GitHub 저장소의 Releases에서 `apk-PRJ-0093` 을 찾아 `.apk` 파일을 받습니다.
3. 받은 파일을 눌러 설치합니다.
4. "출처를 알 수 없는 앱" 설치를 막으면, 설정에서 허용한 뒤 다시 설치합니다.

## 시험
`node --test tests/test_all.js` (Node 22에서는 `node --test tests/` 가 폴더를 파일로 읽어 실패해서 파일 이름까지 적습니다.)

## 확인한 것 / 못 한 것
확인한 것
- core.js 시험 16개 모두 통과 (시각·날짜 읽기, 오류 줄, 휴게 단계, 연장, 자정 넘김, 야간 겹침, 지각·조퇴, 누락 3종, 월 합계, 급여 합계 보존, 월 필터·중복·긴 근무 경고, 이상한 입력).
- index.html 안의 스크립트 문법 검사 통과, 세 파일에 http 주소 없음, viewport 설정 있음, 예시값·자문 아님 문구 있음, 저장이 try/catch 안에 있음(시험에서 확인).

못 한 것
- 실제 폰 설치·화면 미확인 (브라우저에서 열어 보지 않았고, APK도 만들지 않았습니다).
- 사람 눈으로 본 글자 크기·배치 확인.
- 실제 노동법·세법에 맞는지(휴게·가산·주휴·공제 등)는 확인하지 않았습니다. 주휴수당, 4대보험, 소득세 공제는 계산하지 않습니다.
- 파일 업로드, 결제, 전송, 로그인은 만들지 않았습니다.
