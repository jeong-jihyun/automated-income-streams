## 정확성 및 구현 경계
현재 GitHub 프로젝트는 Python CLI 중심입니다. HTML은 모바일 UI 컨셉으로 실제 MP3/PDF 생성 기능은 없습니다. API 설계서는 향후 모바일 웹과 Python 엔진을 연결하기 위한 제안이며 구현된 API가 아닙니다. `silent`는 시험용 무음이며 판매용이 아닙니다. `edge-tts`는 상업 이용/재판매 약관을 확인해야 합니다.
