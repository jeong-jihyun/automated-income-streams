# PRJ-0066 배당 캘린더·알림 서비스 (배당 일정·알림 글 도구)

보유 종목 CSV와 사용자가 넣은 배당 일정 CSV로 예상 수령액(세전·세후 가정)과 임박 알림 글, 월별 합계, 캘린더(.ics) 파일을 만드는 명령줄 도구입니다. **배당 일정을 수집하지 않고 알림도 보내지 않습니다(글만 만듭니다). 투자 조언이 아닙니다.**

## 쓰는 법
```
python -m divcal sample/holdings.csv sample/schedule.csv --today 2026-11-11 --days 7 --ics out.ics
```

## 지키는 것
- 매수일이 배당락일과 같거나 늦으면 배당 대상에서 제외하고 이유를 보여 줍니다.
- 배당락 D-n, 지급 D-n 알림은 기준 일수 안의 일정만 만들고, 보유 목록에 없는 종목의 일정은 무시하며 알립니다.
- 지급일이 배당락일보다 빠르거나 날짜 형식·수량이 틀리면 시작하지 않고 어디가 문제인지 알립니다.
- 세율은 예시(15.4%)이며 --tax로 바꿀 수 있습니다.

## 확인한 것 (테스트 10개 통과)
세전·세후 계산, 배당락일 당일·이후 매수 제외, 모르는 종목 무시, 알림 기간 경계, 월별 합계, .ics 이벤트 수, 잘못된 날짜·수량·열, CLI(세율 범위).

## 확인하지 못한 것
- **배당 일정·금액은 사용자가 입력한 값을 그대로 쓰며 실제 공시와 맞는지 확인하지 못했습니다.** 일정은 바뀔 수 있습니다.
- 배당락일 규칙(결제일 T+n)·해외 종목 원천징수·환율·분기별 세금 차이는 반영하지 않았습니다. 세율은 단순 예시입니다.
- 텔레그램 전송, 웹 서비스, 서버 운영, 구독 결제는 만들지 않았고 .ics를 실제 캘린더 앱에서 열어 보지도 못했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
