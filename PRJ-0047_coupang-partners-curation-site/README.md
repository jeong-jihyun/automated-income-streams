# PRJ-0047 쿠팡파트너스 상품 큐레이션 사이트 (정적 사이트 생성기)

사용자가 직접 넣은 상품 목록(JSON)으로 주제별 추천 페이지와 목차 페이지(HTML)를 만드는 도구입니다. 모든 페이지 위·아래에 제휴 수수료 고지문을 넣고, 링크는 제휴 주소만 허용하며, 오래된 가격은 표시하지 않습니다. 쿠팡에서 상품·가격을 가져오지 않습니다.

## 쓰는 법
```
python -m curation sample/products.json out --today 2026-10-27
# out/index.html 을 열어 확인
```

## 지키는 것
- 모든 페이지에 제휴 고지문이 위·아래 2번 들어갑니다(문구는 예시이므로 쿠팡 파트너스 최신 공식 문구를 직접 확인해 바꾸세요).
- 제휴 링크(https://link.coupang.com 등)가 아니거나 http이면 제외하고 이유를 알려 줍니다.
- 가격은 확인한 날짜와 함께 표시하고 7일이 지나면 숫자를 숨기고 '확인 필요'로 표시합니다. 가격이 없으면 판매 페이지 확인 안내.
- '무조건·100%·1위' 같은 과장·보장 표현이 든 상품은 제외합니다. 상품 이름 등은 HTML 이스케이프 처리.
- 상품 정보를 자동 수집하거나 사이트를 자동 게시하지 않습니다.

## 확인한 것 (테스트 8개 통과)
검증 규칙(링크·http·과장 표현·가격 날짜), 가격 표시(신선·오래됨·없음), 페이지 생성과 제외 보고, 고지문 2회 삽입, rel="sponsored nofollow noopener", HTML 이스케이프, 가격순 정렬(가격 없음은 뒤), 오류 처리, CLI.

## 확인하지 못한 것
- **쿠팡 파트너스 약관·고지 의무 문구·허용 링크 형태의 최신 내용은 확인하지 못했습니다**(시험용 허용 주소와 문구는 예시). 가입·승인 조건, 수수료율, 쿠키 기간도 미확인.
- 실제 상품·가격 정보는 사용하지 않았습니다(가짜 예시). 가격 자동 갱신은 하지 않으며 사용자가 날짜와 함께 입력해야 합니다.
- 휴대폰 화면 표시, 검색 노출(SEO), 호스팅·도메인 배포, 방문·수익 효과는 확인하지 못했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
