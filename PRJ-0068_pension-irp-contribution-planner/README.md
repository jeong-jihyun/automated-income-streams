# PRJ-0068 연금저축·IRP 적립 설계 도구 (은퇴 목표 월 적립액 계산)

나이·은퇴 나이·연봉·현재 잔액·월 납입액·수익률·물가상승률·목표 월 연금이 든 profile.json으로, 은퇴 목표에 필요한 월 적립액과 예상 세액공제를 계산해 글로 보여 주는 명령줄 도구입니다. **세법 한도·공제율은 설정 파일의 예시값이며 세무 자문·상품 추천이 아닙니다.**

## 쓰는 법
```
python -m pensionplan sample/profile.json [--config cfg.json]
```

## 지키는 것
- 공제 한도(합산 900만원, 연금저축 600만원)와 공제율(16.5%/13.2%, 연봉 5,500만원 기준)은 코드가 아니라 설정(CFG)에서 읽고 결과에 예시라고 적습니다.
- 물가상승을 반영해 은퇴 시점의 목표 금액을 키우고, 수익률이 높을수록 필요한 월 적립액이 줄어드는지 시험합니다.
- 현재 잔액만으로 목표를 채우면 추가 적립이 필요 없다고 알립니다.
- 나이 순서(현재 < 은퇴 < 기대수명)나 숫자가 아닌 값, 음수 금액은 시작하지 않고 어디가 문제인지 알립니다.

## 확인한 것 (테스트 10개 통과)
수익률 0%일 때 닫힌 식과 일치, 잔액만으로 충분한 경우, 필요 적립액이 목표에 도달, 수익률↑ 필요액↓, 물가상승 반영, 연봉·한도별 공제율, 경고 문구, 잘못된 입력, 설정 덮어쓰기, CLI.

## 확인하지 못한 것
- **현행 세법의 한도·공제율·수령 시 세율과 맞는지 확인하지 못했습니다.** 설정값은 예시입니다.
- 상품 수수료·운용 손실·물가상승·연금 수령 방식별 세금은 반영하지 않았습니다.
- 금융상품 추천이나 가입 연결은 하지 않으며 화면(UI)·서비스 운영은 만들지 않았습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
