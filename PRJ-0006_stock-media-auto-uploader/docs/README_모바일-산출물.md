# PRJ-0006 모바일 산출물 안내

모바일 UI 컨셉 HTML: [PRJ-0006_모바일-컨셉-시안.html](./PRJ-0006_모바일-컨셉-시안.html)

## 기존 기능과 경계
- 사진 파일 형식/해상도/용량/흐림 검사
- 메모 CSV 기반 키워드 정리, 상표 단어 제거 및 사람 관련 경고
- Adobe Stock / 크라우드픽 CSV, 권리 체크리스트, report.md 생성
- 기존 구현은 Python CLI이며 모바일 UI용 HTTP API는 아직 없음
- 영상 검사 미구현, 스톡 사이트 로그인/자동 업로드/자동 제출 제외
- settings.json의 규격값과 CSV 열은 예시값이며 플랫폼 공식 기준으로 단정하지 않음

HTML은 탭 전환, 파일 선택/파일명 표시, 메타 입력 및 키워드 추가/삭제, 체크리스트 UI를 포함하는 브라우저 시안입니다. 실제 엔진 검사나 CSV 파일 생성은 하지 않으며 로컬 API 어댑터 구현 후 연결해야 합니다.

상세 DOCX 4종과 ZIP 패키지는 별도 산출물로 제공됩니다.
