# PRJ-0006 스톡 사진·영상 자동 업로드 → 업로드 준비 도구 (stock_prep)

스톡 사이트에 **로그인하거나 자동으로 올리는 기능은 만들지 않았습니다** (약관 위반·계정 정지 위험).
대신 시간이 가장 많이 드는 "올리기 전 준비"를 도와줍니다. 모두 내 컴퓨터에서만 처리하고 외부로 전송하지 않습니다.

1. 파일 검사: 형식, 해상도(MP), 용량, 흐림 정도
2. 메모에서 키워드 정리: 중복·상표 단어 제거, 사람 관련 단어 경고, 개수 제한
3. 사이트별 메타데이터 CSV (`metadata_adobe_stock.csv`, `metadata_crowdpic.csv`)
4. 초상권·재산권 체크리스트(`release_checklist.md`)와 보고서(`report.md`)

## 준비
Python 3.10+, `pip install -r requirements.txt` (Pillow)

## 실행
```
python -m stock_prep ./사진폴더 sample/memo.csv ./결과
```
- 메모 CSV 열: `file, memo` (필수), `title` (선택). `sample/memo.csv` 참고.
- 문제가 있는 파일이 있으면 종료 코드 1, 입력 오류는 2.
- 업로드와 제출은 사이트에서 사람이 직접 합니다.

## 설정 (중요)
`stock_prep/settings.json` 의 최소 해상도, 용량, CSV 열 이름은 **예시값**입니다. 설계 당일 공식 안내를 확인하지 못했으니 올리기 전에 각 사이트 안내를 보고 고치세요.

## 테스트
`python -m pytest -q` → 10건 (더미 이미지: 큰 것·작은 것·흐린 것, 형식, 깨진 파일, 키워드, CSV 열, 빈 폴더, 메모 누락)

## 확인하지 못한 것
- 실제 스톡 심사 통과 여부, 사이트별 실제 CSV 형식과 최소 해상도
- 흐림 검사는 간단한 계산이라 실제 사진에서는 오탐·미탐이 있을 수 있음 (더미 이미지로만 확인)
- 영상 파일 검사는 만들지 않았음 (사진만)
