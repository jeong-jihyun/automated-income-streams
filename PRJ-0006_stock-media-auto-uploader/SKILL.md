# 스톡 업로드 준비

1. 사진 폴더와 메모 CSV(`sample/memo.csv` 형식) 경로를 확인한다.
2. `python -m stock_prep <폴더> <메모CSV> <결과폴더>` 를 실행하고 report.md 내용을 쉬운 한국어로 설명한다.
3. 규격 숫자는 `settings.json` 예시값이니 사이트 공식 안내 확인을 권한다.
4. 체크리스트(사람·상표·재산)는 사용자가 직접 확인하게 한다.
5. 로그인·자동 업로드·입력은 하지 않는다. 업로드와 제출은 사람이 한다.
