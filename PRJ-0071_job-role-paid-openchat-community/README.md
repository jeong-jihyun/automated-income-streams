# PRJ-0071 직무별 오픈채팅 유료 커뮤니티 (운영 보조 도구)

유료 직무 모임의 회원 CSV(id·직무·레벨·이용 만료일 등)로 이용 상태 보고, 만료 안내 문구 초안, 모의 면접 짝 맞추기, 게시글 규칙 점검을 하는 명령줄 도구입니다. **오픈채팅·결제와 연동하지 않으며 메시지를 전송하지도 않습니다(문구 초안만).**

## 쓰는 법
```
python -m jobchat report sample/members.csv --today 2026-11-11
python -m jobchat remind sample/members.csv --today 2026-11-11
python -m jobchat check "게시글 내용"
```

## 지키는 것
- 이용 중 / 곧 만료 / 만료로 나누고, 곧 만료와 만료 회원에게만 안내 문구 초안을 만듭니다.
- 모의 면접은 이용 중인 회원 중 같은 직무이고 가능한 시간이 겹치는 사람끼리 짝을 맞추며, 레벨이 높은 사람이 면접관이고 한 사람은 한 번만 배정됩니다.
- 짝이 없는 사람은 이유(겹치는 시간 없음, 상대 없음 등)와 함께 남깁니다. 만료 회원은 매칭에서 뺍니다.
- 게시글 점검은 규칙에 걸린 항목 이름만 알려 주고 글을 지우지 않습니다.
- 회원 id가 비었거나 중복, level·날짜 형식이 틀리면 시작하지 않고 몇 행인지 알립니다.

## 확인한 것 (테스트 9개 통과)
상태 분류, 안내 대상(곧 만료·만료만), 시니어-주니어 공통 시간 매칭, 만료 회원 제외, 겹치는 시간 없음·짝 없음 이유, 1인 1회 배정, 게시글 규칙, 잘못된 회원 파일, CLI.

## 확인하지 못한 것
- **카카오 오픈채팅은 연동하지 않았습니다.** 입장·강퇴·메시지 전송·결제는 모두 직접 해야 합니다.
- 유료 모임 운영의 약관·환불 규정·개인정보 처리 적합성은 확인하지 못했습니다.
- 회원 데이터는 합성 예시이며 실제 운영 규모에서의 사용성은 시험하지 못했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
