# PRJ-0056 캠핑·차박 용품 큐레이션 스토어 (세트 구성기)

상품 카탈로그(JSON)에서 인원·계절·방식(캠핑/차박)·예산에 맞는 세트를 자동으로 구성하는 명령줄 도구입니다. 필수 분류(텐트·침낭·매트·의자·조명·취사 등)를 채우고, 텐트 수용 인원·침낭 보온 등급·재고를 확인하며, 예산 안에서 상위 상품으로 단계적으로 바꿔 보고, 묶음 할인과 마진까지 계산합니다.

## 쓰는 법
```
python -m campset sample/catalog.json --persons 2 --season 봄가을 --mode 캠핑 --budget 400000
python -m campset sample/catalog.json --persons 2 --season 여름 --mode 차박 --budget 300000
```

## 지키는 것
- 텐트는 수용 인원 ≥ 인원, 침낭은 보온 등급(편안한 온도)이 계절 최저기온(봄가을 5℃·여름 15℃·겨울 -5℃, 예시값) 이하여야 합니다.
- 침낭·매트·의자는 사람 수만큼, 재고가 모자라면 후보에서 뺍니다.
- 가장 싼 구성도 예산을 넘으면 억지로 맞추지 않고 이유와 최저 금액을 알려 주고, 맞는 상품이 없는 분류는 어떤 분류인지 알려 줍니다.
- 4개 이상 구성하면 5% 묶음 할인을 적용하고 마진이 기준(기본 10%)보다 낮거나 재고가 3개 미만으로 남으면 경고합니다.

## 확인한 것 (테스트 15개 통과)
인원·재고 필터, 텐트 수용 인원, 침낭 보온 등급 규칙, 예산 부족 처리, 예산 안 상향 교체, 단체(4명) 수량 계산, 마진 계산과 경고, 차박 구성(텐트 없음), 빠진 분류 보고, 입력 오류, CLI.

## 확인하지 못한 것
- **실제 캠핑 용품·재고·가격으로는 시험하지 못했습니다**(가짜 예시 상품). 보온 등급과 계절 최저기온 기준은 제가 정한 예시이며 실제 안전 기준이 아닙니다. 고지대·야간 기온은 반영하지 않습니다.
- 스마트스토어 상품 등록·세트 상품 페이지·재고 연동은 만들지 않았습니다. 시즌별 수요, 실제 마진·판매 효과, 상품 소싱은 확인하지 못했습니다.
- KC 인증 등 용품 안전 인증과 가스류 판매 규정은 확인하지 못했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
