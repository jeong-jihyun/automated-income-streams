# PRJ-0080 엑셀 매크로·VBA 자동화 대행 (납품 전 VBA 소스 점검 도구)

VBA 소스 글(.bas/.txt)을 줄 단위로 훑어 외부 프로그램 실행·파일 삭제·외부 개체 생성·API 선언·자동 실행·오류 무시·고정 경로·코드 속 암호 같은 위험·불편 패턴을 위험도 순으로 알려 주는 명령줄 도구입니다. **매크로를 실행하거나 만들어 주지는 않습니다.**

## 쓰는 법
```
python -m vbacheck sample/risky.bas sample/clean.bas
```

## 지키는 것
- 주석(' 또는 Rem)은 무시하고, 문자열 안의 따옴표는 주석으로 보지 않습니다.
- 결과는 높음 → 중간 → 낮음, 같은 등급은 줄 번호 순입니다.
- 높음이 하나라도 있으면 종료 코드 1, 없으면 0, 파일을 못 읽으면 2입니다.
- Option Explicit 이 주석에만 있으면 없는 것으로 봅니다.

## 확인한 것 (테스트 9개 통과)
위험 예시에서 10가지 패턴이 모두 잡히는지, 깨끗한 예시는 0건인지, 주석·문자열 처리, 정렬, 줄 번호, 판정 문구, 종료 코드.

## 확인하지 못한 것
- 정규식 글자 패턴 검사라서 변수에 담아 숨긴 호출(예: 문자열을 이어 붙여 만든 명령)은 놓칠 수 있습니다.
- 실제 .xlsm 파일 안의 VBA를 꺼내 읽지는 않습니다. 소스 글로 내보낸 파일만 대상입니다.
- 실제 엑셀에서 매크로를 실행해 보지 못했습니다. 정상 매크로가 잘못 표시되는 경우(오탐)의 비율은 확인하지 못했습니다.
- 의뢰 접수·견적·계약, 매크로 작성 기능은 만들지 않았습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
