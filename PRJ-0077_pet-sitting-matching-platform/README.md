# PRJ-0077 반려동물 돌봄 매칭 플랫폼 (매칭 규칙 도구)

돌봄 요청 CSV와 돌봄이 CSV를 읽어 지역·동물 종류·크기·가능 기간·동시 돌봄 정원이 맞는 짝을 정하고 못 맺은 이유를 알려 주는 명령줄 도구입니다. **결제·연락·후기·신원 확인은 하지 않습니다.**

## 쓰는 법
```
python -m petsit sample/requests.csv sample/sitters.csv
```

## 지키는 것
- 형식 오류·중복 번호·끝 날짜가 시작보다 빠른 요청은 제외하고 몇 행인지 이유를 보여 줍니다.
- 동시에 맡는 수가 돌봄이의 정원(capacity)을 넘지 않게 배정합니다.
- 같은 입력이면 항상 같은 결과가 나옵니다(시작일 → 후보 수 → 번호 순).
- 미배정은 가장 많이 걸린 이유 한 가지를 적습니다.

## 확인한 것 (테스트 11개 통과)
읽기 검증(오류 행 제외·중복 번호·열 누락), 지역·크기·기간 불일치 판정, 정원 초과 방지, 배정 결과가 규칙을 모두 만족하는지, 같은 입력의 같은 결과, 출력 문구, CLI 종료 코드.

## 확인하지 못한 것
- 돌봄이의 신원·안전·후기는 확인할 수 없습니다. 배정은 후보 추천일 뿐입니다.
- 앱 화면, 결제, 연락 중계, 서비스 운영은 만들지 않았습니다.
- 배정 방식은 간단한 탐욕 방식이라 전체 최적 배정은 보장하지 않습니다.
- 실제 이용자 시험은 하지 못했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
