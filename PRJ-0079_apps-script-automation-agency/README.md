# PRJ-0079 구글 앱스 스크립트 자동화 대행 (의뢰 점검·견적 도구)

앱스 스크립트 자동화 의뢰 CSV를 읽어 작업 시간·견적 범위, 위험 표시, 필요한 권한(scope) 목록을 만들고 시작용 .gs 뼈대 코드를 출력하는 명령줄 도구입니다. **스크립트를 구글에 배포하거나 실행하지 않습니다.**

## 쓰는 법
```
python -m gasagency quote sample/requests.csv
python -m gasagency gen daily_trigger
```

## 지키는 것
- 지원 작업: dedupe, summary_mail, daily_trigger, form_to_sheet. 그 밖의 작업·형식 오류·중복 번호는 제외하고 몇 행인지 이유를 보여 줍니다.
- 시간은 작업 기본 시간 + 시트 추가분 + 외부 호출·개인정보 가산, 급행은 1.3배입니다. 단가(시간당 5만원)는 예시 설정값입니다.
- 개인정보·외부 호출·메일 발송 한도·급행은 주의 문구로 따로 표시합니다.

## 확인한 것 (테스트 13개 통과)
행 제외 사유, 견적 계산식, 위험 문구·권한 목록, 열 누락·중복 번호 오류, 출력 문구, CLI 종료 코드, 뼈대 코드 네 종류가 node 문법 검사(node --check)를 통과하는지.

## 확인하지 못한 것
- 뼈대 코드를 실제 구글 앱스 스크립트 환경에서 실행해 보지 못했습니다. 문법 검사만 했고 동작은 확인하지 못했습니다.
- 시간·단가 계산식은 예시이며 실제 작업량과 맞는지 검증하지 못했습니다.
- 권한 목록은 작성 시점의 일반적인 scope 이름이며 최신 구글 문서와 대조하지 못했습니다.
- 의뢰 접수·계약·대금 수령, 서비스 운영은 만들지 않았습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
