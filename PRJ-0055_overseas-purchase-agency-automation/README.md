# PRJ-0055 해외 구매대행 자동화 스토어 (판매가 계산·주문 관리 도구)

구매대행 판매자를 위한 세 가지 도구입니다. ① 해외 가격·배송비·환율·관세·부가세·마켓 수수료를 넣어 목표 마진이 나오는 판매가를 계산, ② 상품 제목에서 인증·식품·화장품·브랜드 등 '확인이 필요한' 품목을 표시, ③ 주문 상태(접수→결제확인→해외발주→…→완료)와 지연 주문을 로컬 파일로 관리합니다. 상품 수집·자동 발주는 하지 않습니다.

## 쓰는 법
```
python -m agency quote sample/rules.json --price-usd 150 --ship-usd 20 --category 의류
python -m agency check "아기 비타민 충전기 세트" --brands 나이키
python -m agency order orders.json new --id A1 --item 머그컵
python -m agency order orders.json move --id A1 --status 결제확인
python -m agency order orders.json late
```

## 지키는 것
- 관세율·면세 한도·부가세·환율·수수료는 rules.json에 사람이 넣는 값입니다(샘플은 예시). 환율 기준일이 결과에 표시됩니다.
- 제한 품목 확인은 '금지'가 아니라 '확인 필요' 안내이며, 걸리지 않아도 안전하다는 뜻이 아니라고 알려 줍니다.
- 주문 단계는 건너뛸 수 없고, 해외 발주 이후에는 이 도구로 취소할 수 없습니다(직접 확인하라고 안내). 단계별 지연 기준일을 넘으면 알려 줍니다.
- 해외 쇼핑몰·마켓에 접속하거나 자동 주문하지 않습니다.

## 확인한 것 (테스트 15개 통과)
면세/과세 계산(경계값 포함), 관세·부가세 금액, 판매가가 수수료·목표 마진을 만족, 입력 오류 3종·규칙 파일 오류, 제한 품목 표시, 주문 7단계 흐름과 이력, 단계 건너뛰기·중복·없는 주문 거부, 발주 후 취소 차단, 지연 계산, 깨진 파일 처리, CLI.

## 확인하지 못한 것
- **실제 관세법·면세 한도(국가·품목별)·부가세·개인통관·마켓 수수료는 확인하지 못했습니다.** 샘플 값은 예시이며 틀릴 수 있습니다. 실제 판매 전에 관세청·마켓 공식 안내와 세무 전문가 확인이 필요합니다.
- 제한 품목 목록은 제가 정한 간이 키워드이며 실제 수입 금지·인증 대상 목록과 다릅니다. 상표권·정품·구매대행 사업자 신고·통신판매업 신고 요건도 확인하지 못했습니다.
- 상품 수집·번역, 마켓(스마트스토어·쿠팡) 등록·주문 연동, 해외 결제·배송 추적, 환율 자동 갱신은 만들지 않았습니다. 실제 마진·수익은 확인하지 못했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
