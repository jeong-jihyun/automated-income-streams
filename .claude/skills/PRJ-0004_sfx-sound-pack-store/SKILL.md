# 효과음 팩 빌더

프로젝트 폴더: `PRJ-0004_sfx-sound-pack-store/` (이 안에서 명령을 실행한다)

1. 사용자의 폴더 경로를 확인한다.
2. `python -m sfx_builder` 로 실행하고 결과(통과/문제 목록)를 쉬운 한국어로 설명한다.
3. 규격 숫자는 설정 JSON 값이 예시임을 알리고 공식 안내 확인을 권한다.
4. 마켓/플랫폼에 자동 등록하지 않는다. 제출·업로드는 사람이 직접 한다.

사용 예:
```
python -m sfx_builder ./원본소리 ./팩결과 --theme Doors --prefix doors
```
