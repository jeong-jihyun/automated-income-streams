# 아이콘 팩 빌더

1. PNG 폴더 경로와 팩 이름, 테마를 확인한다.
2. `python -m icon_pack check --input <폴더>` 로 점검하고 불합격 사유를 쉬운 말로 설명한다.
3. 통과하면 `build --input <폴더> --out <결과> --name <팩 이름> --theme <테마>` 를 실행한다.
4. 규격은 예시값, AI 도구 약관과 마켓의 AI 표시 규칙은 사람이 확인해야 한다고 알린다.
5. 마켓 등록은 사람이 직접 한다. 자동 등록하지 않는다.
