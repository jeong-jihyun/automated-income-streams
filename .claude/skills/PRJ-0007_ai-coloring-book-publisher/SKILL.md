# 컬러링북 빌더

1. 이미지 폴더와 책 크기(예: 8.5x11)를 확인한다.
2. `python -m coloring_book check --input <폴더>` 로 점검하고 불합격 사유를 쉬운 말로 설명한다.
3. 합격하면 `build --input <폴더> --out <결과> --theme <주제>` 를 실행한다.
4. 규격 숫자는 예시값임을 알리고 KDP 공식 안내 확인을 권한다.
5. 업로드, AI 사용 여부 선택, 가격은 사람이 직접 한다. 자동 등록하지 않는다.
