# PRJ-0074 소모임·동호회 관리 앱 (회비·정산·공지 도구)

회비 납부 현황, 모임 비용 정산(송금 횟수 최소화), 일정 공지 문구와 참석 집계를 만드는 명령줄 도구입니다. **송금이나 메시지 전송은 하지 않고 문구와 계산만 만듭니다.**

## 쓰는 법
```
python -m clubapp dues sample/members.csv sample/payments.csv --month 2026-11 --today 2026-11-20
python -m clubapp settle sample/expenses.csv
python -m clubapp notice --title "정기 모임" --when 2026-11-22T14:00 --place 강남 --rsvp sample/rsvp.csv --event 11-22 --members sample/members.csv --today 2026-11-11
```

## 지키는 것
- 회비는 완납/일부 납부/미납으로 나누고 기한(매월 10일)이 지나면 '(기한 지남)'을 붙입니다.
- 회원 목록에 없는 입금자는 따로 알립니다(조용히 버리지 않음).
- 비용은 참가자 수로 나눌 때 남는 원을 이름순으로 1원씩 나눠 합계가 정확히 맞고, 모든 잔액의 합은 0원입니다.
- 송금은 받을 사람·보낼 사람을 큰 금액부터 맞춰 횟수를 줄이며, 정산하면 모두 0원이 되는지 시험합니다.

## 확인한 것 (테스트 10개 통과)
회비 상태(기한 전·후), 다른 달 입금 제외, 나눗셈 나머지 처리, 잔액 합계 0원, 송금 후 전원 0원, 송금 횟수 ≤ 인원−1, 참석 집계·공지 D-day 문구, 잘못된 입력, CLI 3가지 명령.

## 확인하지 못한 것
- **송금과 메시지 전송은 만들지 않았습니다.** 안내 문구는 사람이 복사해서 보내야 합니다.
- 송금 횟수 최소화는 단순한 탐욕 방식이라 항상 수학적 최소는 아닙니다(정산은 정확히 맞음).
- 회원 개인정보 보관·화면(UI)·서비스 운영은 만들지 않았고 실제 모임에서 써 보지 못했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
