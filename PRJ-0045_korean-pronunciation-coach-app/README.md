# PRJ-0045 AI 한국어 발음·말하기 교정 앱 (글자 비교 연습 도구)

학습자가 말한 것을 음성인식기가 받아 적은 글과 목표 문장을 자모(ㄱㅏ…) 단위로 비교해, 다르게 들린 곳·빠진 곳을 한국어와 영어로 알려 주는 명령줄 도구입니다. 목표 문장은 간이 규칙으로 '소리 나는 대로'(예: 좋다→조타) 바꾼 뒤 비교합니다. **소리 자체(억양·길이)는 평가하지 못합니다.**

## 쓰는 법
```
python -m coach 어머니 오머니
python -m coach 좋다 조타
```

## 지키는 것
- 결과마다 '음성인식기가 받아 적은 글을 비교한 것이며 소리 높낮이·길이·억양은 평가하지 못한다'는 문구를 붙입니다.
- 발음 변환은 연음·대표음·비음화·격음화 일부만 구현한 간이 규칙입니다(전체 규칙 아님).
- 음성 파일은 처리하지 않습니다. 인식된 글을 입력으로 받습니다.

## 확인한 것 (테스트 19개 통과)
자모 분해·합치기, 소리 변환 사례 10개(좋다→조타, 밥을→바블, 값이→갑시, 국물→궁물 등), 완전 일치 100점, 철자와 소리 차이 표시, 모음·격음 안내(한/영), 빠짐·더 들어감 구분, 빈 입력·비한글 처리, CLI.

## 확인하지 못한 것
- **실제 음성은 처리하지 않았습니다.** 마이크 녹음·음성인식(STT)을 연결하지 않았고, 시험은 글 입력만 사용했습니다. 실제 학습자 발음에서 인식기가 얼마나 정확히 받아 적는지는 확인하지 못했습니다.
- 음성인식기는 문맥에 맞게 '고쳐서' 적는 경향이 있어, 발음이 틀려도 맞게 적힐 수 있습니다(이 도구가 놓침).
- 간이 소리 변환에 없는 규칙(ㄴ 첨가, 사이시옷, 경음화 대부분, 한자어 예외 등)은 틀릴 수 있습니다. 원어민 교사 검수는 받지 않았습니다.
- 영어 안내는 모음 4개뿐입니다. 화면, 학습 기록, 결제
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
