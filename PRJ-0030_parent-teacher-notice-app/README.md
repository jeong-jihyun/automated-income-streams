# PRJ-0030 학부모-교사 알림장 앱 (시험용 핵심 엔진)

학원·어린이집 공지와 사진을 반 단위로 올리고, 보호자별 개인 링크로 전달·읽음 확인을 하는 명령줄 도구입니다. **문자·푸시는 실제로 보내지 않습니다**(발송 함수를 꽂는 구조).

## 쓰는 법
```
python -m noticeapp --db n.db import-guardians sample/guardians.csv      # 반,아이,보호자,전화,사진동의(Y/N)
python -m noticeapp --db n.db publish 해님반 --title "소풍 안내" --body "금요일 소풍입니다" --photo sample/photo1.jpg --kids 김하늘,박구름
python -m noticeapp --db n.db status 1
```
## 지키는 것
- 사진에 나온 아이(`--kids`)의 보호자가 **사진 공개 동의(Y)** 를 안 했으면 올리기를 막습니다. 아이 이름을 안 알려도 막습니다.
- 사진은 올리기 전에 위치·기기 정보(EXIF)를 지우고 긴 변 1280px로 줄입니다. JPEG/PNG, 8MB 이하만.
- 링크는 보호자·알림장마다 다른 무작위 토큰입니다. 처음 연 시각만 읽음으로 기록합니다.
- 전달 실패는 표시되고 `retry_failed`로 다시 보냅니다.

## 확인한 것 (테스트 8개 통과)
EXIF 제거, 사진 오류 처리, 개인 링크 발송, 동의 차단(저장 안 됨), 읽음 확인·재열기, 실패·재시도, 입력 검증, CLI.

## 확인하지 못한 것
- 실제 문자·카카오 알림톡·앱 푸시 발송, 보호자용 화면(웹/앱) — 이 도구는 엔진만 있음
- 얼굴 자동 인식은 없음: 사진 속 아이 이름은 교사가 직접 입력해야 하며 틀리면 막지 못함
- 개인정보보호법 등 법적 요건(동의서 양식·보관 기간), 로그인·권한 관리, 대용량 사진 저장소
- 앱스토어/구글플레이 등록은 직접 해야 함
