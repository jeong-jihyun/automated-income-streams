# PRJ-0053 통신·인터넷 가입 비교 제휴 (요금제 비교·상담 신청 기록 도구)

요금제 목록(JSON)에서 내 사용량(데이터·통화)에 맞는 것만 골라 월 실부담액(할인·단말 할부 반영)과 약정 기간 총액 순으로 비교하고, 가입 상담 신청을 **동의를 확인한 뒤에만** 이 컴퓨터의 파일에 기록하는 도구입니다. 제휴사로 전송하지 않습니다.

## 쓰는 법
```
python -m telecom compare sample/plans.json --gb 10 --discount 0.25 --device 0 --months 24
python -m telecom lead leads.jsonl --name 김철수 --phone 01012345678 --plan a-5g-light --agree-collect --agree-third
python -m telecom report leads.jsonl   # 이름·번호는 가려서 표시
python -m telecom delete leads.jsonl --phone 01012345678   # 상담 완료 후 파기
```

## 지키는 것
- 수집·이용 동의와 제3자 제공 동의가 둘 다 없으면 저장하지 않고 파일도 만들지 않습니다. 광고 수신 동의는 선택(기본 거부).
- 신청 기록 파일은 본인만 읽을 수 있게(권한 600) 저장하고, 보고서는 이름·번호를 가립니다. 번호로 기록을 지울 수 있습니다.
- 확인일이 30일 넘은 요금제는 '오래됨'으로 표시합니다. 모든 결과에 제휴 수수료 가능성 고지가 붙습니다.
- 실제 가입·제휴사 전송·자동 연락은 하지 않습니다.

## 확인한 것 (테스트 12개 통과)
사용량 필터(무제한 포함), 할인·단말 할부 계산, 총액 순 정렬, 오래된 요금 표시, 입력 파일 오류, 신청 검증 5가지(이름·번호·동의 2종·요금제), 동의 없으면 파일 미생성, 파일 권한 600, 마스킹, 파기, CLI.

## 확인하지 못한 것
- **실제 통신사 요금제·선택약정 할인율은 확인하지 못했습니다.** 시험 요금제는 가짜 예시이고 25% 같은 할인율은 사용자가 직접 입력합니다.
- **개인정보보호법·정보통신망법상 동의 문구·보관 기간·제3자 제공 고지 방식이 법적으로 충분한지 확인하지 못했습니다.** 동의 문구는 예시이며 서비스로 내기 전 법률 검토가 필요합니다.
- 통신 결합·인터넷·TV 상품 비교, 위약금·부가서비스 계산, 제휴사 리드 전송 연동, 워드프레스 화면, 보안 점검(암호화 저장 등)은 하지 않았습니다. 수익(건당 비용) 효과도 미확인.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
