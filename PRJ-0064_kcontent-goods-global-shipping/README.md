# PRJ-0064 K-콘텐츠 굿즈 해외 직배송 대행 (배송 견적·제한 점검 도구)

주문 CSV(국가·상품·무게·가격)와 요금표·규정 JSON으로 부피무게를 반영한 해외 배송 견적을 내고, 발송이 어려운 주문을 이유와 함께 가려 내는 명령줄 도구입니다. **실제 발송·결제·통관 신고는 하지 않습니다.**

## 쓰는 법
```
python -m kgoods sample/orders.csv --rates sample/rates.json --rules sample/rules.json --krw-per-usd 1400
```

## 지키는 것
- 청구무게 = max(실무게, 가로×세로×높이÷5000)을 100g 단위로 올림.
- 공식 라이선스 표시가 없는 굿즈, 배터리 포함 상품(항공), 국가별 반입 제한 분류, 무게 한도 초과 주문은 '발송불가 + 이유'로 표시하고 나머지 주문은 계속 처리합니다.
- 화장품·식품은 별도 확인 경고, 면세 한도 초과 가능성은 고객 사전 안내용 문구로 보여 줍니다.
- 같은 주문번호의 여러 줄은 한 주문으로 묶고, 국가가 다르면 거부합니다.

## 확인한 것 (테스트 12개 통과)
주문 묶기, 부피무게, 요금 단계 계산, 무게 한도 초과 주문만 차단, 라이선스·배터리·반입 제한 차단, 면세 안내, 잘못된 CSV, CLI(환율 0 거부).

## 확인하지 못한 것
- **운송사 실제 요금, 국가별 반입 제한·면세 한도·세금 규칙을 확인하지 못했습니다.** 요금표와 규정 파일의 값은 모두 예시입니다.
- 굿즈의 공식 라이선스 여부는 사용자가 넣은 표시(Y/N)를 믿을 뿐 증빙을 검증하지 않습니다.
- 실제 발송, 통관 서류, 결제, 환율 자동 반영은 만들지 않았습니다. 실제 해외 고객 주문으로 시험하지 못했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
