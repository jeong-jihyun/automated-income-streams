# PRJ-0050 지역 맛집·카페 리뷰 블로그 (후기 초안·점검 도구)

방문 메모(JSON)로 맛집·카페 후기 초안을 만들고, 쓴 글의 협찬 표시·과장 표현·사진 수·날짜 표기를 점검하며, 지역별 후기 목차를 만드는 명령줄 도구입니다. **방문일이 없거나 미래이면, 먹어 본 메뉴와 느낀 점이 없으면 초안을 만들지 않습니다.**

## 쓰는 법
```
python -m reviewblog make sample/visit.json --out post.md
python -m reviewblog check post.md --photos 5 --sponsored
python -m reviewblog index sample/visits_all.json
```

## 지키는 것
- 협찬이면 무엇을 받았는지 적어야 하고, 글 맨 위·맨 아래에 협찬 표시가 들어갑니다(문구는 예시이므로 최신 공식 표기 방식을 직접 확인).
- 가격·영업시간은 '방문일 기준'으로 표기합니다.
- '인생맛집·무조건·100%·역대급' 같은 과장 표현, 사진 5장 미만, 날짜 표기 누락을 점검합니다.
- 블로그에 자동 게시하거나 업체 정보를 수집하지 않습니다.

## 확인한 것 (테스트 12개 통과)
초안(협찬 위·아래, 방문일·가격 기준 표기, 아쉬운 점, 태그), 협찬 없을 때 표시 없음, 필수 입력 거부 6가지(미래 방문일 등), 점검 규칙, 지역별 목차 정렬, 오류 처리, CLI.

## 확인하지 못한 것
- **네이버·티스토리 및 공정거래위원회의 현재 협찬·광고 표기 규정은 확인하지 못했습니다.** 문구와 사진 5장 기준은 제가 정한 예시입니다.
- 실제 가게 후기로는 시험하지 못했습니다(가짜 예시 가게). 사진이 직접 찍은 것인지, 방문이 실제인지는 검사할 수 없습니다.
- 검색 노출(SEO), 체험단 선정·광고 수익, 블로그 게시 연동은 확인하지 못했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
