# PRJ-0072 러닝·운동 인증 챌린지 서비스 (인증 검증·환급 계산 도구)

챌린지 설정·참가자·운동 기록 CSV로 인증을 검증하고, 달성률에 따른 환급액과 수수료, 미환급금 처리(기부/보너스풀)를 계산하는 명령줄 도구입니다. **돈을 받거나 송금하지 않고 계산만 합니다.**

## 쓰는 법
```
python -m challenge sample/config.json sample/participants.csv sample/logs.csv --today 2026-11-14
```

## 지키는 것
- 인증은 챌린지 기간 안, 최소 거리·시간 이상, 하루 1회, proof_id(인증 자료) 필수·중복 불가, 속도가 비현실적이면 '직접 확인 필요'로 제외하고 몇 행인지 이유를 보여 줍니다.
- 같은 인증 자료는 먼저 낸 사람만 인정하고 나중에 낸 사람 기록은 거절합니다.
- 참가비 합계 = 환급 합계 + 수수료 + 기부/보너스풀 + 원 단위 나머지가 항상 맞는지 시험으로 검증합니다.
- 미달성자 몫은 설정에 따라 기부(donate) 또는 달성자 보너스풀(bonus_pool)로 나누고, partial_refund 설정이면 달성 비율만큼 환급합니다(원 단위 내림).
- 설정·참가자 파일이 이상하면(기간 순서, 목표 횟수, 수수료율, 참가비 0 이하) 시작하지 않고 알립니다.

## 확인한 것 (테스트 10개 통과)
인증 개수 집계, 거절 사유(형식·기간·최소 기준·미래), 중복 인증 자료 처리, 기본 정산, 돈 합계 보존, 수수료·기부 배분, 보너스풀은 달성자에게만, 부분 환급 내림, 잘못된 설정·참가자, CLI.

## 확인하지 못한 것
- **보증금을 걷고 돌려주는 방식이 사행성·금융 관련 법규에 걸리지 않는지 확인하지 못했습니다.** 실제 운영 전 검토가 필요합니다.
- 결제·송금·본인 확인·GPS/기기 연동은 만들지 않았고 기록은 스스로 입력한 값입니다(조작 가능).
- 수수료·환급 규칙은 예시 설정이며 화면·서비스 운영은 만들지 않았습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
