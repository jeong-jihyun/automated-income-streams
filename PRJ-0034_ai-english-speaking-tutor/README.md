# PRJ-0034 AI 영어 회화 튜터 앱 (연습·교정 엔진)

말한 문장(받아쓰기 결과)을 목표 문장과 비교해 점수와 틀린 곳을 알려 주고, 자주 하는 영어 실수를 한글로 짚어 주는 명령줄 도구입니다. 음성 인식은 함수를 꽂아 쓰는 구조이며 이 도구에는 들어 있지 않습니다.

## 쓰는 법
```
python -m tutor check "He go to school"
python -m tutor drill sample/scenarios.json --id 1 --said "can i have a coffee please" --log log.json
python -m tutor progress log.json
```

## 지키는 것
- 대소문자·문장부호는 점수에 영향을 주지 않습니다(단어만 비교).
- 교정은 확실한 규칙(3인칭 -s, be동사, a/an, 대문자 I, 비교급 등)만 지적하고 문장을 통째로 고쳐 쓰지 않습니다.
- 음성 파일은 저장하지 않고, 로그에는 날짜·문장·점수만 남깁니다.
- 인식 결과가 비면 점수를 매기지 않습니다.

## 확인한 것 (테스트 8개 통과)
단어 오류율(바뀜·빠짐·더함), 문법 규칙(예외 단어 포함), 연습 피드백, 음성 인식 함수 연결·빈 결과 처리, 기록과 진행 요약, CLI.

## 확인하지 못한 것
- **발음은 평가하지 못합니다.** 받아쓰기 글자만 비교하므로 발음이 나빠도 글자가 맞으면 높은 점수가 나옵니다.
- 실제 음성 인식(마이크 입력)과 AI 대화·자유 대화 교정은 연결하지 않았습니다.
- 문법 규칙은 일부뿐이라 많은 실수를 놓칩니다(영어 교사가 검수한 것이 아님).
- 앱 화면, 구독 결제, 스토어 등록, 어린이 사용자 개인정보 처리
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
