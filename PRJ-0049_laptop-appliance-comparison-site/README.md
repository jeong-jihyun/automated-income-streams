# PRJ-0049 노트북·가전 비교표 제휴 사이트 (비교표·가격 기록 도구)

사용자가 넣은 스펙(JSON)과 가격 기록(CSV)으로 비교표 HTML을 만들고, 항목별 가장 좋은 값을 초록색으로 표시하며, 가격이 내렸는지·기록 중 최저가인지 알려 주는 도구입니다. 가격 기록은 `add-price` 명령으로 직접 한 줄씩 추가합니다(자동 수집 없음).

## 쓰는 법
```
python -m comparison add-price n1 1090000 --history prices.csv
python -m comparison build sample/products.json --history sample/prices.csv --out compare.html --today 2026-10-27
```

## 지키는 것
- 항목마다 higher(클수록 좋음)/lower(작을수록 좋음)/info(비교 제외)를 지정합니다. 동점은 모두 표시, 값이 하나뿐이면 표시하지 않습니다.
- 가격 기록이 7일보다 오래되면 숫자를 숨기고 '가격 확인 필요'로 표시합니다(오래된 가격으로 구매 유도 방지).
- 알림은 '기록 중 최저가'(기록 3개 이상)와 '직전보다 10% 이상 하락'뿐입니다. 제휴 링크 가능성 고지문이 항상 페이지 위에 들어갑니다.
- 상품·가격 정보를 자동 수집하지 않으며, 이름 등은 HTML 이스케이프 처리합니다.

## 확인한 것 (테스트 7개 통과)
항목별 최고값 판단(동점·info 제외·값 1개), 가격 상태(최저가·하락 알림·오래됨·없음), HTML 내용(고지문·이스케이프·정보 없음 표시), 입력 파일 오류 3종, 가격 추가(잘못된 값 거부), CLI.

## 확인하지 못한 것
- **실제 노트북·가전의 스펙과 가격은 넣어 보지 않았습니다**(가짜 예시). 가격 자동 수집·갱신은 없어 사용자가 직접 기록해야 하고, 가격 변동의 실제 정확도는 확인하지 못했습니다.
- 제휴 고지 문구와 쇼핑몰 가격 표시 규정은 예시이며 각 제휴 프로그램의 약관을 확인하지 못했습니다.
- 워드프레스 연동(이 도구는 단독 HTML 생성), 휴대폰 화면 가독성, 검색 노출, 수익 효과는 확인하지 못했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
