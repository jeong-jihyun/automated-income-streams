# PRJ-0100 개인 프로젝트 포트폴리오 관리 앱

기존 `PRJ-0001_goodnotes-digital-planner`와 별개의 신규 프로젝트입니다. PRJ-0001의 기존 소스·문서·메뉴는 변경하지 않습니다.

- `docs/PRJ-0100_기능정의서_v1.0.docx`
- `docs/PRJ-0100_UI-설계서_v1.0.docx`
- `docs/PRJ-0100_API-설계서_v1.0.docx`

- `docs/모바일_컨셉_디자인_시안.html`

## 제품 범위
개인 프로젝트의 아이디어·계획·진행·검수·출시·운영 상태, 작업, 마일스톤, 산출물 링크, 포트폴리오 공개 후보, 리포트와 JSON 백업을 관리합니다.

## 실행 및 구현 경계
HTML은 브라우저에서 직접 실행하는 모바일 우선 인터랙션 프로토타입이며 localStorage를 사용합니다. 인증, 서버 동기화, 실제 파일 업로드, GitHub API 연동은 아직 구현되지 않았습니다. API 설계서는 후속 서버 구현을 위한 REST 계약 초안입니다.

## 변경관리
기능·화면·API·디자인 토큰 변경 시 관련 문서를 함께 갱신하고 문서 버전을 올립니다. 기존 PRJ-0001 굿노트 디지털 플래너 폴더는 이 프로젝트의 범위가 아닙니다.
