# PRJ-0038 AI 계약서 위험 조항 검토 서비스 (규칙 기반 점검 도구)

계약서 텍스트를 조항(제N조)으로 나눠, 자동 갱신·일방적 해지·높은 위약금·무제한 책임·저작권 귀속·기간 없는 비밀유지·늦은 대금 지급 등 주의할 문구를 찾아 쉬운 말과 '물어볼 것'으로 알려 주는 명령줄 도구입니다. **법률 자문이 아닙니다.**

## 쓰는 법
```
python -m contractrev sample/contract.txt --out review.md
```

## 지키는 것
- 문구와 숫자(위약금 30% 이상, 대금 60일 이상)를 함께 봅니다. 단어만 있다고 모두 경고하지 않습니다.
- 결과는 높음 > 중간 > 참고 순서로 보여 주고, 빠진 것처럼 보이는 내용(계약 기간·대금·해지·분쟁 해결)도 알려 줍니다.
- 모든 결과에 '법률 자문 아님, 전문가 확인' 문구를 붙이고, 걸린 게 없어도 안전하다고 말하지 않습니다.
- 계약서 내용은 이 도구 안에서만 처리하고 외부로 보내지 않습니다.

## 확인한 것 (테스트 7개 통과)
조항 나누기(제N조·번호 줄·전체), 샘플 계약서의 주요 위험 조항 감지, 숫자 기준 확인, 깨끗한 계약서·누락 안내, 쌍방 조항 오검출 방지, 보고서 형식, CLI. (개발 중 숫자가 앞에 오는 문장과 '갑은' 조사를 놓치는 결함 2건을 시험으로 찾아 고침)

## 확인하지 못한 것
- **기준 수치(30%, 60일)와 문구 목록은 제가 정한 예시이며 변호사 검토를 받지 않았습니다.** 표준계약서와 비교하거나 실제 판례·법률(약관규제법, 하도급법 등)과 대조하지 않았습니다.
- 규칙에 걸리지 않는 위험이 훨씬 많습니다(문장이 다르면 못 찾음). 영문 계약서, 표·특약·별첨, 스캔 PDF(OCR)는 지원하지 않습니다.
- AI 해설 연결, 건당 결제·구독, 화면, 계약서(개인정보 포함) 보관·보안 설계
- 법률 서비스 규제(비변호사의 법률 자문 제공 금지 등) 검토는 하지 않았습니다. 서비스로 낼 때는 '자문 아님' 표시와 법률 검토가 필요합니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
