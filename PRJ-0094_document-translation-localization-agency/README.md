# 문서 번역·현지화 자동화 대행

AI로 번역한 글에 전문가 검수를 더해 납품할 때 쓰는 도구입니다. 번역은 이 도구가 하지 않습니다(외부 AI 호출 없음). 원문과 번역문을 문단별로 붙여 넣으면 빠진 곳·어긋난 곳을 찾아 주고, 단어 수와 검수 단계로 대행 견적(부가세 10% 포함)을 계산합니다. 인터넷 없이 휴대폰에서 돌아갑니다.

## 쓰는 법
1. `app/index.html`을 열면 샘플 원문·번역문·용어집이 이미 들어 있고 결과가 바로 보입니다.
2. 문단은 줄에 `---` 만 적어 나누거나 빈 줄로 나눕니다. 원문과 번역문의 문단 수를 맞춥니다. (`---`를 쓰면 빈 문단도 찾아냅니다)
3. 용어집은 한 줄에 `원어=번역어`. 번역어가 여러 개 허용되면 `|`로 잇습니다. `#`로 시작하는 줄은 메모입니다.
4. "점검하기"를 누르면 오류(반드시 고칠 것)와 확인(사람이 볼 것)이 문단 번호와 함께 나옵니다.
5. 견적 칸의 단가를 바꾸고 "견적 계산"을 누릅니다. 단어 수를 비우면 원문에서 셉니다.
6. 입력값은 이 기기의 localStorage에만 저장됩니다.

## 점검 항목
- 빈 문단(비었거나 `-`, `TODO`, `번역 필요` 같은 자리표시), 문단 수 불일치
- 숫자·날짜·외부 주소가 원문과 번역문에서 같은지 (1,000과 1000은 같게 봄, 연도 없는 날짜는 월·일만 비교)
- 영문 고유명사 후보(문장 첫머리가 아닌 대문자 단어, 대문자 약어)가 번역문에 그대로 있는지
- 용어집 위반 (원문에 원어가 있는데 번역문에 번역어가 없음)
- 길이 비율 이상 (번역문 글자 수/원문 글자 수가 하한·상한 밖)

## APK 받아 설치하는 법
1. 저장소를 GitHub에 푸시합니다.
2. GitHub 저장소의 Releases에서 `apk-PRJ-0094` 태그를 찾아 `.apk` 파일을 받습니다.
3. 받은 파일을 눌러 설치합니다.
4. "출처를 알 수 없는 앱" 설치를 막으면, 설정에서 허용한 뒤 다시 설치합니다.

## 시험
폴더 안에서 `node --test tests/test_all.js` (Node 22에서는 `tests/` 만 쓰면 폴더를 파일로 읽어 실패하므로 파일 이름까지 적습니다.)

## 확인한 것 / 못 한 것
확인한 것
- core.js 시험 22개 모두 통과 (문단 나누기, 용어집, 날짜·숫자·주소·고유명사 뽑기, 샘플에서 의도한 문제 7종 검출, 깨끗한 번역은 문제 없음, 문단 수 불일치, 길이 비율, 단어 수, 견적 계산, 돈 합계 보존).
- index.html 안의 스크립트 문법 검사 통과, 세 파일에 http 글자 없음, viewport 설정·필요한 입력칸 있음(시험에서 확인).

못 한 것
- 실제 폰 설치·화면 미확인 (브라우저에서 열어 보지 않았고, APK도 만들지 않았습니다).
- 사람 눈으로 본 글자 크기·배치 확인.
- 숫자 읽기는 아라비아 숫자와 `만·억·천`, `thousand·million·billion`만 다룹니다. "five" 같은 글자 숫자, 영문 이외의 고유명사(한글·한자 이름)는 점검하지 못합니다. 용어집에 넣으면 용어집 점검으로 잡습니다.
- 영문 용어는 단어 단위로 찾아서 복수형(plans)은 못 찾습니다.
- 번역 품질(뜻·어색함) 판단은 하지 않습니다. 검수는 사람의 몫입니다.
- 결제, 전송, 파일 업로드는 만들지 않았습니다.
