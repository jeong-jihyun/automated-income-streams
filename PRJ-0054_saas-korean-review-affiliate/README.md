# PRJ-0054 해외 SaaS 한국어 후기 제휴 (가이드 초안·점검 도구)

직접 써 본 해외 SaaS의 사실(써 본 날짜·단계별 사용법·장단점·요금)을 JSON으로 넣으면 한국어 시작 가이드 초안을 만들고, 쓴 글의 제휴 고지·과장·달러 가격 환율 표기·스크린샷·균형을 점검하는 명령줄 도구입니다. 달러 요금은 환율과 기준일을 함께 적어야 원화로 환산합니다.

## 쓰는 법
```
python -m saasguide make sample/facts.json --out guide.md
python -m saasguide check guide.md
```

## 지키는 것
- 써 본 날짜(tested_on)·단계·아쉬운 점·https 제휴 링크가 없으면 만들지 않습니다. 미래 날짜도 거부.
- 달러 가격은 환율과 환율 기준일이 있어야 하고, 원화는 '약 …원(100원 단위)'으로 표시하며 카드 수수료·부가세 미포함을 안내합니다.
- 써 본 지 30일이 지나면 '화면·가격이 바뀌었을 수 있다'는 경고를 넣습니다.
- 맨 위·맨 아래에 제휴 고지(문구는 예시)를 넣고, 자동 게시나 제휴 프로그램 가입은 하지 않습니다.

## 확인한 것 (테스트 13개 통과)
환율 환산, 초안 구조(고지 위·아래, 요금표, 환율 기준일, 스크린샷 자리, 아쉬운 점), 오래된 확인일 경고, 입력 거부 7가지, 요금 없는 경우, 점검 규칙, 오류 처리, CLI.

## 확인하지 못한 것
- **Canva·Notion 등 실제 제휴 프로그램의 약관·수수료·고지 요구·허용 홍보 방식은 확인하지 못했습니다**(시험 서비스는 가상의 '예시노트'). 제휴 문구는 예시입니다.
- 실제 서비스를 써 본 후기로는 시험하지 못했습니다. 환율은 사용자가 입력한 값이며 자동으로 가져오지 않습니다. 스크린샷은 자리만 만들고 직접 찍어 넣어야 합니다.
- 유튜브 영상 대본·자막, 검색 노출, 제휴 수익 효과는 확인하지 못했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
