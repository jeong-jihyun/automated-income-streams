# PRJ-0057 주문 제작 포토북·머그 자동 발주 (인쇄 파일 준비·전달함 도구)

고객이 보낸 사진을 머그·포토북 인쇄용으로 점검·변환(300dpi)하고, 주문을 제작사로 **한 번만** 전달하는 '전달함'을 관리하는 명령줄 도구입니다. 사진이 너무 작으면(150dpi 미만) 거절하고, 조금 흐리거나 많이 잘리면 경고합니다. 전달이 실패하면 최대 3번까지 다시 시도하고 그래도 안 되면 사람이 확인하도록 표시합니다.

## 쓰는 법
```
python -m printorder check sample/photo_big.jpg --product mug_wrap
python -m printorder prepare sample/photo_big.jpg mug.png --product mug_wrap
python -m printorder dispatch order.json --outbox outbox.json --vendor-dir vendor_inbox
```

## 지키는 것
- 인쇄 크기·해상도 기준(머그 200×90mm, 포토북 210×210mm, 250dpi 이상 양호/150dpi 미만 거절)은 예시이며 실제 제작사 규격이 아닙니다.
- 같은 주문은 두 번 전달하지 않습니다(이미 보냄 표시). 실패하면 횟수와 오류를 기록하고 3번째 실패에서 'needs_manual'로 멈춥니다.
- 전달 파일이 없거나 수량이 1~100이 아니면 보내지 않습니다.
- 기본 전달 대상은 시험용 가짜 제작사(폴더 복사)이며 실제 제작사·스마트스토어에는 연결하지 않습니다.

## 확인한 것 (테스트 14개 통과)
인쇄 픽셀 크기 계산, 해상도 등급 3단계, 잘림 비율 경고, cover/contain 변환(여백·크기), EXIF 회전 처리, 전달 1회 보장(중복 방지), 실패 재시도→사람 확인, 실패 후 성공 시 오류 지움, 주문 검증 4종, 깨진 전달함 처리, CLI와 300dpi 저장.

## 확인하지 못한 것
- **실제 인쇄 제작사의 규격(도련·재단선·안전 영역·색상 프로필 CMYK)과 주문 API를 확인하지 못했습니다.** 화면 색과 인쇄 색이 다를 수 있고, 머그 곡면 왜곡·재단 여백은 반영하지 않았습니다.
- 실제 인쇄물은 만들어 보지 않았습니다(가짜 그림으로 파일 변환만 시험). 스마트스토어 주문 수집·송장·결제·환불 연동은 하지 않았습니다.
- 고객 사진의 저작권·초상권·개인정보 보관 정책, 미리보기(목업) 화면은 만들지 않았습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
