# PRJ-0061 스마트스토어 상품 등록 자동화 도구 (일괄 등록 전 검수·정리 도구)

엑셀(.xlsx)·CSV 한 장에 적은 여러 상품을 등록 전에 한꺼번에 검수하는 명령줄 도구입니다. 오류를 '몇 행 어느 열이 왜 문제인지' 알려 주고, 통과한 상품만 정리된 CSV로 내보냅니다. **스마트스토어에 업로드하지 않습니다**(검수·정리까지).

## 쓰는 법
```
python -m bulklist sample/products.xlsx --categories sample/categories.json --out ok.csv --errors errors.csv
```

## 지키는 것
- 필수 열(상품명·판매가·재고·카테고리·대표이미지·상세설명)이 없으면 시작하지 않고, 모르는 열은 무시한다고 알립니다.
- 검수: 상품명 50자 이하·특수문자(★♥ 등)·금지어('최저가·1위·무조건·100%')·같은 단어 반복·상품명 중복, 가격(숫자·100원 이상·10원 단위), 재고 정수, 카테고리 코드, 이미지(https 또는 파일 존재), 상세설명 20자 이상, 배송비, 옵션 형식과 조합 100개 이하.
- 기준값은 예시이며 실제 스마트스토어 규칙과 다를 수 있습니다. 통과한 행만 내보내고 오류 행은 이유와 함께 목록으로 저장합니다(끝에 업로드는 하지 않는다는 안내).
- 엑셀 수식으로 읽힐 수 있는 값('=', '+', '-', '@'로 시작)은 내보낼 때 앞에 작은따옴표를 붙여 막습니다.

## 확인한 것 (테스트 12개 통과)
엑셀·CSV 읽기 결과 동일, 정상 행 통과, 행별 오류 감지(특수문자·금지어·가격 단위·상품명 중복·카테고리·이미지·옵션·배송비·http 주소·단어 반복), 옵션 파서와 조합 수 제한, 필수 열 누락·빈 파일·없는 파일 처리, 빈 행 무시, 수식 방지 내보내기, CLI와 오류 CSV.

## 확인하지 못한 것
- **스마트스토어(네이버 커머스)의 실제 상품 등록 양식·카테고리 코드·글자 수 제한·금지어·API 규칙을 확인하지 못했습니다.** 기준값과 내보내기 열 구성은 제가 정한 예시라 실제 대량 등록 양식과 다를 수 있습니다.
- 실제 업로드(API·대량 등록 화면 연동)는 만들지 않았습니다. 이미지 규격(크기·용량)·상세설명 HTML 검사·재고 연동·상품정보제공고시·KC 인증 같은 항목은 검수하지 않습니다.
- 실제 판매 데이터로 시험하지 못했습니다(가짜 상품 4행). 판매 효과는 확인하지 못했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
