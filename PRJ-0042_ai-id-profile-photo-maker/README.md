# PRJ-0042 AI 증명사진·프로필 사진 생성 (사진 정리 도구)

셀카를 이력서(3×4cm)·SNS(정사각형)용 프로필 사진으로 정리하는 명령줄 도구입니다. 얼굴 위치를 기준으로 자르고, 단색 벽 같은 단순한 배경은 원하는 색(흰색·회색·하늘색)으로 바꾸고, 밝기를 살짝 맞춥니다. **AI 생성이 아니며 얼굴·피부를 고치거나 모양을 바꾸지 않습니다.**

## 쓰는 법
```
python -m profilephoto sample/selfie.jpg --preset resume_3x4 --face 300,250,300,400 --color blue --out result.jpg
# 규격: linkedin(800x800) / resume_3x4(354x472) / id_35x45(413x531, 연습용)
```

## 지키는 것
- 여권·주민등록증 등 공식 서류용 사진이 아닙니다(규격 이름에도 '제출용 아님'을 적었습니다). 공식 서류는 해당 기관 규정을 따라 촬영해야 합니다.
- 배경이 복잡하면 억지로 지우지 않고 '바꾸지 않았어요'라고 알려 줍니다. 안쪽 구멍처럼 막힌 부분은 지우지 않습니다.
- 밝기는 모든 색에 같은 배수(0.85~1.2배)만 곱해 피부색·옷 색이 변하지 않게 합니다.
- 얼굴 위치를 안 알려 주면 추정했다고 알리고, 사진 가장자리가 모자라 배경색으로 채운 경우도 알립니다.

## 확인한 것 (테스트 12개 통과)
배경 교체(가짜 셀카 이미지), 안쪽 구멍 보존, 복잡한 배경 거부, 자르기 계산, 규격별 정확한 크기, 가장자리 부족 안내, 얼굴 상자 검증, 사진 점검(작음·어두움·밝음), 색 보존(피부·옷·배경 색 수치 확인), 밝기 배수 제한, CLI. 결과 이미지를 직접 눈으로도 확인했습니다. (개발 중 자동 대비 보정이 피부를 주황색·옷을 검정으로 바꾸는 문제를 찾아 밝기 보정으로 교체)

## 확인하지 못한 것
- **실제 사람 사진으로는 시험하지 못했습니다.** 시험 이미지는 단색 벽 앞의 도형으로 만든 가짜 셀카입니다. 머리카락 가장자리·그림자·안경 등은 실제 사진에서 거칠게 처리될 수 있습니다.
- **얼굴 자동 인식은 없습니다**(이 환경에 얼굴 인식 데이터가 없었음). 얼굴 위치를 직접 알려 주어야 정확합니다.
- AI 배경 제거·옷 변경·표정 보정·조명 보정은 하지 않았고 연결하지 않았습니다. 사진 개인정보(얼굴) 보관·삭제 정책, 건당 결제, 화면, 배포
- 각 서비스(링크드인 등)의 현재 권장 크기와 증명사진 공식 규격은 확인하지 못했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
