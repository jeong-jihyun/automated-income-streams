# PRJ-0073 원데이 클래스 중개 플랫폼 (예약·환불·정산 계산 도구)

클래스 목록(JSON)과 예약 CSV로 정원·대기자 처리, 취소 시점별 환불액, 강사 정산(수수료 15%)을 계산하는 명령줄 도구입니다. **결제·정산 지급은 하지 않고 계산만 합니다.**

## 쓰는 법
```
python -m classmkt sample/classes.json sample/bookings.csv --commission 0.15 --now 2026-11-11T09:00
```

## 지키는 것
- 정원이 차면 대기자로 두고, 확정자가 취소하면 대기자를 순서대로 확정으로 올립니다. 정원 초과·중복 예약은 시험으로 막습니다.
- 환불은 수업 7일 전 100%, 3일 전 50%, 1일 전 30%, 그 뒤 0%(설정 예시)입니다.
- 정산 시각(--now)을 주면 수업 시작 전에 확정 인원이 min_students 미만인 클래스를 '폐강 후보'로 표시하고 전액 환불로 계산하며, 시각을 안 주면 폐강 계산을 하지 않습니다.
- 강사 정산 = 결제 − 환불 − 수수료(기본 15%)이고 돈 합계가 보존되는지 시험합니다.
- 잘못된 클래스·예약 입력은 한 번에 모아서 어느 줄인지 알립니다.

## 확인한 것 (테스트 10개 통과)
정원·대기 승격, 정원·중복 방지, 환불 비율·금액, 오류 모아 보고, 정산 돈 합계 보존, 최소 인원 미달 폐강, 시각 없을 때 폐강 없음, 잘못된 클래스, CLI.

## 확인하지 못한 것
- **결제 대행·정산 지급·세금계산서/통신판매중개 의무는 확인하지 못했고 만들지 않았습니다.**
- 환불 규정은 예시이며 소비자 분쟁 해결 기준과 맞는지 확인하지 못했습니다.
- 강사 인증·후기·화면·서비스 운영은 만들지 않았습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
