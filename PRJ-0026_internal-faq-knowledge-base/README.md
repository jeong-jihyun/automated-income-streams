# PRJ-0026 사내 FAQ·지식베이스

질문·답변 CSV를 색인해 **자연어로 물어보면 가장 알맞은 답을 찾아 주는** 사내 검색 도구입니다. 한글 형태소 분석기 없이 "단어 + 글자 2개씩(2-gram)"으로 색인해 조사가 붙어도("연차를", "연차는") 찾고, BM25로 순위를 매깁니다. **외부 AI(API)와 인터넷을 쓰지 않습니다.**

```bash
python -m faq_kb build --csv sample/faq.csv --index kb.json
python -m faq_kb ask "연차 신청은 어떻게 해요?" --index kb.json [--dept hr]
python -m faq_kb check --csv sample/faq.csv --days 365      # 오래된 답변·수정일 없음·비슷한 질문 점검
python -m pytest -q
```
- 점수가 낮으면 억지로 답하지 않고 "찾지 못했습니다, 담당자에게 문의"로 응답. 부서 전용(dept) 문서는 해당 부서에만 보임.

## 확인한 것 / 못 한 것
- 확인(테스트 12개, 항목 5개): 조사·어미가 붙은 한글 질문 검색, 답 없을 때 빈 결과, 부서별 공개 범위, 오래된 문서·중복 질문 점검, CSV 오류 안내.
- **못 한 것**: 항목이 5개뿐인 예시라 **실제 수백~수천 건에서의 검색 품질은 모릅니다.** 동의어("휴가"="연차")·오타는 처리하지 않습니다(태그로 보완). AI가 문장으로 답을 만들어 주는 기능(RAG)은 일부러 넣지 않았습니다(API 비용·정확성 검증 필요). 로그인·권한 연동(SSO), 웹 화면, 위키 문서 작성·승인 흐름, 구독 결제는 없습니다. 부서 구분은 `--dept` 값을 믿는 방식이라 **보안 장치가 아닙니다.** 민감한 문서는 이 도구의 부서 값에 의존하지 마세요.
