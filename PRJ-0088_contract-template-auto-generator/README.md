# 계약서·서류 템플릿 자동 생성 시스템

휴대폰에서 인터넷 없이 쓰는 작은 웹앱입니다. 용역 계약서·임대차 계약서·차용증 중 하나를 고르고 빈칸을 채우면 문서 초안이 만들어지고, 빈 칸·금액 한글 표기·날짜 순서 오류를 점검해 줍니다.

**이 문서는 연습·참고용 초안이며 법률 자문이 아닙니다.**

## 쓰는 법
1. `app/index.html`을 열면 샘플 값이 미리 들어 있고 결과가 바로 보입니다.
2. 서류 종류를 바꾸거나 입력칸 값을 고친 뒤 "문서 만들기·점검" 버튼을 누릅니다.
3. "샘플로 채우기"는 예시로 되돌리고, "모두 지우기"는 칸을 비웁니다.
4. 용역 계약서에는 "총 대금 30/30/40 자동 나누기" 버튼이 있습니다.
5. "문서 복사하기"로 글을 복사합니다.
6. 입력한 값은 이 기기 브라우저(localStorage)에만 저장됩니다. 서버로 보내는 것은 없습니다.

## 점검하는 것
- 필수 칸이 비었는지 (본문에는 【○○ 입력 필요】로 표시)
- 금액이 숫자인지, 0원이면 안 되는 칸인지
- 금액 한글 표기 (예: 3,000,000원 = 일금 삼백만원정), 직접 쓴 한글 금액이 숫자와 맞는지
- 계약금+중도금+잔금 = 총 대금인지 (모자라거나 많은 금액을 알려 줌)
- 날짜가 실제로 있는 날짜인지, 계약일→시작일→종료일 같은 순서가 맞는지
- 차용증 연 이자율 20% 초과 경고, 월세 0원 경고, 같은 이름 경고

## APK 받아 설치하는 법
1. 이 저장소를 GitHub에 푸시합니다.
2. GitHub 저장소의 Releases에서 `apk-PRJ-0088` 항목으로 들어가 `.apk` 파일을 받습니다.
3. 받은 파일을 눌러 설치합니다.
4. "출처를 알 수 없는 앱" 설치를 막는다는 안내가 나오면 설정에서 허용한 뒤 다시 설치합니다.

(APK 만들기 자체는 이 폴더에 포함되어 있지 않습니다.)

## 시험 돌리기
```
node --test tests/test_all.js
```
참고: 이 환경의 Node 22에서는 `node --test tests/`가 폴더를 파일로 읽어 실패했습니다. 파일 이름을 직접 쓰세요.

## 확인한 것 / 못 한 것
확인한 것
- `node --test tests/test_all.js` 실행: 18개 시험 모두 통과 (한글 금액, 금액·날짜 읽기, 분할 합계 보존, 샘플 통과, 빈칸·합계 불일치·날짜 순서 오류 판정, 외부 주소 없음 검사).
- index.html 안의 스크립트 문법 검사 통과 (`node --check`).

못 한 것

- APK 빌드, GitHub 푸시, 릴리스 만들기.
- 법률 검토. 문구와 20% 이자율 기준은 예시이며 실제 법 조건과 다를 수 있음.
