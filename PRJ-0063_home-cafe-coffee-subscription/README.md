# PRJ-0063 홈카페 원두 정기배송 (취향 맞춤 구독 추천 도구)

고객의 맛 취향(산미·바디·쓴맛 1~5)과 추출 방식, 배송 주기를 받아 원두를 추천하고, 로스팅 신선도·재고를 확인해 배송 예정일을 만드는 명령줄 도구입니다. **결제·배송·로스터리 연동은 하지 않습니다.**

## 쓰는 법
```
python -m coffeesub sample/profile.json sample/beans.json --today 2026-11-11
```

## 지키는 것
- 추천은 취향 점수 차이(낮을수록 비슷)로 정렬하고, 로스팅 후 45일 넘은 원두·재고 부족·추출 방식 불일치·미래 로스팅일은 이유와 함께 제외합니다.
- 신선도 라벨: 5일 미만 가스 빼는 중, 5~30일 좋음, 30~45일 주의(기준일은 예시).
- 디카페는 고객이 요청할 때만 추천합니다.
- 배송일은 주말이면 다음 월요일로 미룹니다(예시 규칙). 입력 오류(범위 밖 점수 등)는 모두 모아서 알려 줍니다.

## 확인한 것 (테스트 11개 통과)
취향 거리 계산, 정렬, 오래된 원두·재고·방식 제외, 신선도 라벨, 디카페 규칙, 용량별 가격, 배송일 계산(주말·주기), 잘못된 입력, CLI.

## 확인하지 못한 것
- **취향 점수는 단순한 숫자 거리이며 실제 맛과 일치하는지 확인하지 못했습니다.** 원두 점수(산미 등)는 사람이 정해 넣는 값입니다.
- 로스터리 재고·실제 로스팅 일정, 결제(정기결제), 택배 연동, 주말·공휴일 배송 정책은 확인하지 못했습니다(공휴일 미반영).
- 신선도 기준(5/30/45일)과 분쇄도 안내는 일반적인 예시입니다. 실제 고객 시험은 하지 못했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
