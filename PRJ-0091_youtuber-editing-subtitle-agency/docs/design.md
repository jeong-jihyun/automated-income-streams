# 설계
- core.js: 순수 함수. 브라우저(window.Core)와 node(module.exports) 양쪽에서 쓴다.
- SRT: 빈 줄로 덩어리를 나누고 번호 줄(없어도 됨) + 시간 줄 + 본문. 시간은 `HH:MM:SS,mmm`.
- 점검: 겹침(앞 끝 > 뒤 시작), 길이 0 이하, 줄별 글자 수(공백 제외), 초당 글자 수(공백·줄바꿈 제외 글자 / 초).
- 시간 이동: 밀리초 단위로 더하고 0 미만은 0에 멈추며 몇 개가 멈췄는지 알려 준다.
- 견적: 편집비 = round(분×분당 단가), 수정비 = 횟수×1회 단가. 부가세 = round(공급가×10%).
  항목별 부가세는 가장 큰 나머지 순서(allocate)로 나눠 항목 합 = 총 부가세, 공급가+부가세 = 총합이 항상 맞는다.
- 저장: localStorage 키 prj0091-v1, 읽기·쓰기 모두 try/catch.
