# 유튜버용 영상 편집·자막 대행

자막(SRT) 글을 붙여넣으면 겹치는 구간, 너무 긴 줄, 초당 글자 수 초과를 찾아 주고, 시간을 앞뒤로 옮긴 새 SRT를 보여 줍니다. 영상 길이와 단가로 대행 견적(부가세 10% 포함)도 계산합니다. 영상 분석·업로드는 없고, 인터넷 없이 휴대폰에서 돌아갑니다.

## 쓰는 법
1. `app/index.html`을 열면 샘플 자막과 샘플 견적이 이미 들어 있고 결과가 바로 보입니다.
2. 칸 값을 바꾸고 "점검하고 이동하기" 또는 "견적 계산"을 누릅니다.
3. 입력값은 이 기기의 localStorage에만 저장됩니다.

## APK 받아 설치하는 법
1. 저장소를 GitHub에 푸시합니다.
2. GitHub 저장소의 Releases에서 `apk-PRJ-0091` 을 찾아 `.apk` 파일을 받습니다.
3. 받은 파일을 눌러 설치합니다.
4. "출처를 알 수 없는 앱" 설치를 막으면, 설정에서 허용한 뒤 다시 설치합니다.

## 시험
`node --test tests/test_all.js` (Node 22에서는 `node --test tests/` 가 폴더를 파일로 읽어 실패해서 파일 이름까지 적습니다.)

## 확인한 것 / 못 한 것
확인한 것
- core.js 시험 13개 모두 통과 (시간 변환, SRT 읽기·쓰기, 겹침·긴 줄·초당 글자 수 판정, 시간 이동과 0초 멈춤, 견적 계산, 돈 합계 보존).
- index.html 안의 스크립트 문법 검사 통과, 세 파일에 http 주소 없음, viewport 설정 있음(시험에서 확인).

못 한 것
- 실제 폰 설치·화면 미확인 (브라우저에서 열어 보지 않았고, APK도 만들지 않았습니다).
- 사람 눈으로 본 글자 크기·배치 확인.
- 영상·소리 분석, 파일 업로드, 결제, 전송은 만들지 않았습니다.
