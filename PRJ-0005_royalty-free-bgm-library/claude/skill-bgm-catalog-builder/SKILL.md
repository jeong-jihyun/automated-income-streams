# BGM 카탈로그 빌더

1. 곡 정보 CSV(`sample/tracks.csv` 형식)와 음악 폴더 경로를 확인한다.
2. `python -m bgm_catalog <csv> <음악폴더> <결과폴더>` 를 실행하고 결과를 쉬운 한국어로 설명한다.
3. 검증 실패 시 문제 목록(권리 근거 누락 등)을 고치도록 안내한다.
4. 라이선스 안내문은 초안이며 공개 전 전문가 확인이 필요함을 알린다.
5. 결제 연결, 사이트 공개, 플랫폼 등록은 사람이 직접 한다. 자동 등록하지 않는다.
