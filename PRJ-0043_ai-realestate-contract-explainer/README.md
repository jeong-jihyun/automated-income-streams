# PRJ-0043 AI 부동산 계약 서류 쉬운 해설 (풀이 보조 도구)

등기부등본 글(갑구·을구)과 계약서 특약 글을 읽어 근저당·가압류·신탁 같은 어려운 말을 쉬운 말로 풀어 주고, 주의할 점을 위험 순서로 보여 주는 명령줄 도구입니다. 말소된 근저당은 빼고 합계를 계산하며, 빚+보증금이 집값의 70%를 넘으면 경고합니다. **법률·부동산 전문가의 자문이 아닙니다.**

## 쓰는 법
```
python -m realestate sample/deungibu.txt --price 200000000 --deposit 100000000 --landlord 이영희 --contract sample/special_terms.txt --out report.md
```

## 지키는 것
- 모든 결과 끝에 '자문이 아님' 문구가 붙습니다. 규칙에 걸린 게 없어도 '안전하다는 뜻은 아닙니다'라고 적습니다.
- 70% 기준과 위험 단어 목록은 제가 정한 예시이며 전문가 검토를 받지 않았습니다(옵션으로 바꿀 수 있음).
- 등기소에서 직접 가져오지 않습니다. 사용자가 준 글만 처리합니다.
- 소유자와 계약서 임대인 이름이 다르면 가장 높은 경고로 표시합니다.

## 확인한 것 (테스트 10개 통과)
갑구·을구 나누기, 말소 항목 제외(말소된 근저당은 합계에서 빠짐), 채권최고액 합계, 비율 계산과 경계값(정확히 70%는 경고 안 함), 위험 항목 순서 정렬, 소유자 불일치, 경매·신탁·전세권·임차권등기 감지, 특약 빠진 항목 확인, CLI 오류 처리. 개발 중 '가압류'가 '압류'로만 잡히는 문제를 찾아 순서를 고쳤습니다.

## 확인하지 못한 것
- **실제 등기부등본 PDF·사진은 읽지 못합니다.** 시험 입력은 제가 만든 가짜 예시 글이며 실제 등기부의 줄바꿈·표 모양과 다를 수 있습니다.
- 실제 시세·선순위 보증금·세금 체납·건축물대장·용도(불법 건축물) 확인은 하지 않습니다.
- 위험 기준(70%)과 단어 목록의 법적 타당성, 최신 법령(임대차보호법 등) 반영 여부
- AI(LLM) 문장 풀이는 연결하지 않았습니다(규칙 기반 문장만 나옵니다). 전문가 검수, 화면, 결제, 개인정보 보관 정책
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
