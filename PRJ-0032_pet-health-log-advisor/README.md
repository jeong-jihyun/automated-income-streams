# PRJ-0032 반려동물 건강 기록·상담 앱 (시험용 엔진)

반려동물(강아지·고양이)의 몸무게·증상·메모를 기록하고, 일반 건강 정보 안내와 병원 제출용 요약표를 만드는 명령줄 도구입니다. **진단이나 약 안내는 하지 않습니다.**

## 쓰는 법
```
python -m petlog --file pets.json add-pet 콩이 dog
python -m petlog --file pets.json log 콩이 --date 2026-10-24 --weight 9.5 --symptom 구토
python -m petlog --file pets.json advise 콩이 --today 2026-10-24
python -m petlog --file pets.json report 콩이 --out summary.md
```

## 지키는 것
- 응급 신호(호흡곤란·경련·초콜릿·자일리톨·포도·혈변 등)가 기록에 있으면 바로 동물병원 연락을 안내합니다.
- 최근 7일 구토·설사 등이 반복되거나 30일 몸무게가 10% 이상 변하면 진료 상담을 권합니다.
- 약 이름·용량은 절대 안내하지 않고, 모든 안내에 진단 아님 문구를 붙입니다.
- 기록 파일은 임시 파일에 쓴 뒤 교체해서 쓰다 끊겨도 원본이 안 깨집니다.

## 확인한 것 (테스트 8개 통과)
기록 검증·정렬, 응급 신호 감지, 오래된 응급 기록은 반복 안내 안 함, 몸무게 추세, 반복 증상 창, 약 안내 없음, 요약표(표 깨짐 방지), CLI·깨진 파일 처리.

## 확인하지 못한 것
- **응급 신호·기준 수치(7일 3회, 10% 등)는 수의사 검토를 받지 않은 보수적 예시**입니다. 실제 서비스 전 수의사 검수가 필요합니다.
- 사진 증상 분석(AI)은 만들지 않았습니다. 사진 칸은 있으나 분석·EXIF 제거는 이 도구에 없습니다.
- 품종·나이별 정상 범위, 다른 동물, 실제 AI 상담 연결, 앱 화면, 구독 결제, 스토어 등록·심사(의료 관련 문구 정책 포함)
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
