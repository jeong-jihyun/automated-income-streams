# 설계 요약 (PRJ-0013)
설계 문서 원본: https://docs.google.com/document/d/1LijZpNzHYuA_t9NLJkD30MTMGU3y0LIcXmqDH0Nb_rk/edit
- 스택: Python + Pillow + reportlab (화면 없이 명령줄)
- 맡는 일: 검사, 스티커 가공(자르기·흰 테두리), 시트 배치, 배경화면 리사이즈, 미리보기, 안내 PDF, 설명 초안, ZIP
- 맡지 않는 일: 그림 그리기, Etsy·아이디어스 등록·가격 입력
- 설계의 설정 파일은 YAML 대신 JSON 으로 만들었음 (추가 설치 없이 쓰려고)
