# 스티커·배경화면 빌더

1. 스티커 폴더(투명 PNG)와 배경화면 폴더 경로를 확인한다.
2. `python -m sticker_shop check --stickers <폴더> --wallpapers <폴더>` 로 점검하고 불합격 사유를 쉬운 말로 설명한다.
3. 통과하면 `build ... --out <결과> --name <이름> --theme <테마>` 를 실행한다.
4. 굿노트·실제 폰 표시는 확인하지 못했다고 알리고 사람이 직접 확인하게 한다.
5. Etsy·아이디어스 등록은 사람이 직접 한다. 자동 등록하지 않는다.
