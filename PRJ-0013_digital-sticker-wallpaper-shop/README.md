# PRJ-0013 디지털 스티커·배경화면 판매 → 스티커·배경화면 묶음 준비 도구 (sticker_shop)

그림 PNG 여러 장으로 아래를 만들어 판매용 ZIP으로 묶어 줍니다. 그림 그리기, Etsy·아이디어스 등록·가격 입력은 사람이 합니다.

1. 검사: 파일명 규칙, 최소 크기, 스티커는 **투명 배경 PNG**, 배경화면은 짧은 변 최소 크기
2. 스티커 가공: 투명 여백 자르기 → 크기 맞추기 → **흰 테두리** 넣기
3. 스티커 시트: 한 장에 서로 겹치지 않게 배치 (넘치면 시트를 여러 장으로)
4. 배경화면: 기기 크기별로 꽉 차게 잘라 JPG 저장
5. 미리보기 이미지, 사용 안내 PDF, 상품 설명 초안, `sticker_pack.zip`

## 준비
Python 3.10+, `pip install -r requirements.txt`

## 실행
```
python -m sticker_shop check --stickers ./stickers --wallpapers ./wallpapers
python -m sticker_shop build --stickers ./stickers --wallpapers ./wallpapers --out ./dist --name "봄 꽃 스티커" --theme 꽃
```
`--stickers` 와 `--wallpapers` 는 하나만 써도 됩니다. 불합격이 있으면 목록만 보여 주고 멈춥니다.

## 규격 설정
`config/specs.json` 의 스티커 크기, 시트 크기, 배경화면 크기(1170x2532, 1080x2400, 1284x2778)는 **예시값**입니다. 실제 기기 크기와 판매처 안내를 확인하고 고치세요.

## 테스트
`python -m pytest -q` → 10건 (더미 도형: 투명 아님·작음·채워진 배경·전부 투명·이름 위반·JPG 스티커 검출, 자르기·흰 테두리·투명 바깥·원래 색 유지, 큰 그림 축소, 시트 30개 배치 **겹침 없음·범위 안**, 여러 시트, 너무 큰 스티커 오류, 배경화면 크기, ZIP 파일 목록, PDF, 명령 끝까지)

## 알려진 한계 (솔직하게)
- **굿노트와 실제 폰에서 보이는 모습은 확인하지 못했습니다.** 안내서의 굿노트 사용 순서는 예시입니다.
- Etsy·아이디어스 정책(AI 생성물 표기 등)과 심사는 확인하지 못했습니다. 설명 초안에 확인 항목을 넣었습니다.
- 흰 테두리는 단순 확대 방식이라 뾰족한 모양이나 구멍 있는 그림에서는 모양이 거칠 수 있습니다 (더미 도형으로만 시험).
- 배경화면은 가운데 기준으로 자릅니다. 중요한 부분이 잘릴 수 있으니 결과를 직접 보세요.
- 스티커 시트 배치는 단순한 줄 쌓기 방식이라 공간이 최대로 효율적이진 않습니다.
