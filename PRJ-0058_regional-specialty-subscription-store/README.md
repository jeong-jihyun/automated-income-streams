# PRJ-0058 지역 특산물 정기배송 스토어 (구독 일정·물량 점검 도구)

정기배송 운영에 필요한 계산을 해 주는 명령줄 도구입니다. 주기(매주·격주·매월)별 배송일과 결제일 계산(31일 시작은 2월 말일로 보정), 제철 상품 구성, 배송 3일 전 변경 마감, 그날 배송 물량이 플랜별 한도·농가 공급량을 넘는지 점검, 결제 실패 재시도·일시정지 판단을 합니다.

## 쓰는 법
```
python -m subscribe schedule sample/data.json --sub s1 --from 2026-10-07 --count 4
python -m subscribe day sample/data.json 2026-10-20
python -m subscribe skip sample/data.json --sub s1 --ship 2026-10-20 --today 2026-10-19
```

## 지키는 것
- 변경·건너뛰기는 배송일 3일 전까지만 가능(예시 값, 코드 상수로 바꿈). 결제는 배송 2일 전.
- 결제 실패는 1일 뒤·3일 뒤 재시도하고 그래도 실패하면 일시정지하며 고객 안내가 필요하다고 표시합니다.
- 제철 상품이 없는 달은 배송을 보류하라고 알립니다. 일시정지·취소 구독은 배송 목록에서 뺍니다.
- 실제 결제·배송사·농가에는 연결하지 않으며 구독자 파일을 바꾸지 않습니다(계산만).

## 확인한 것 (테스트 11개 통과)
격주·매월 배송일(윤년·연말 포함), 31일 시작 보정, 건너뛰기·일시정지 반영, 변경 마감 경계, 제철 구성과 제철 없음 처리, 플랜 물량 초과·상품 공급 부족 점검, 결제 실패 단계(대기·재시도·일시정지), 결제일 계산, CLI.

## 확인하지 못한 것
- **실제 결제(PG)·정기결제 약관·자동 갱신 고지 의무·청약철회·해지 규정을 확인하지 못했습니다.** 정기구독 표시·광고와 환불 규정은 법적 검토가 필요합니다.
- 농가 연계, 신선식품 배송(택배 냉장, 배송 지연·파손 보상), 식품 표시·위생 규정, 실제 제철·가격·공급량은 확인하지 못했습니다(가짜 예시).
- 상태 저장(건너뛰기 반영 파일 쓰기), 고객 알림 발송, 쇼핑몰 화면은 만들지 않았습니다. 수익·구독 유지율은 확인하지 못했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
