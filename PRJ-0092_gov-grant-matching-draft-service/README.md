# 정부지원사업 공고 매칭·신청서 초안 서비스

사업자 조건(업종, 업력, 지역, 직원 수, 대표 나이)을 넣으면 앱 안에 들어 있는 샘플 공고와 비교해, 자격이 맞는지 안 맞는지와 그 이유를 보여 주고, 마감이 가까운 순서로 정렬합니다. 공고 하나를 고르면 신청서 초안(문단 틀)도 만들어 줍니다.

**화면의 공고는 모두 직접 만든 가상 예시이며 실제 공고가 아닙니다.** 외부에서 공고를 가져오지 않고, 인터넷 없이 휴대폰에서 돌아갑니다.

## 쓰는 법
1. `app/index.html`을 열면 샘플 조건과 샘플 공고 7개가 이미 들어 있고 결과가 바로 보입니다.
2. 업종·지역·업력·직원 수·대표 나이·오늘 날짜를 바꾸고 "공고 찾기"를 누릅니다.
3. "신청서 초안"에서 공고를 고르고 "초안 만들기"를 누르면 문단 틀이 나옵니다. `[ ]` 칸은 직접 채웁니다.
4. 입력값은 이 기기의 localStorage에만 저장됩니다.

## 판정 규칙
- 업력·직원 수·대표 나이의 기준값은 "이상/이하"(경계값 포함)입니다.
- 마감일 당일은 신청 가능(오늘 마감), 다음 날부터 마감입니다.
- 정렬: 자격 일치 → 자격 불일치 → 마감, 각 안에서 마감 임박순(같은 날이면 공고 번호순).

## APK 받아 설치하는 법
1. 저장소를 GitHub에 푸시합니다.
2. GitHub 저장소의 Releases에서 `apk-PRJ-0092` 를 찾아 `.apk` 파일을 받습니다.
3. 받은 파일을 눌러 설치합니다.
4. "출처를 알 수 없는 앱" 설치를 막으면, 설정에서 허용한 뒤 다시 설치합니다.

## 시험
폴더 안에서 `node --test tests/test_all.js` (Node 22에서는 `tests/`만 쓰면 실패하므로 파일 이름까지 적습니다.)

## 확인한 것 / 못 한 것
확인한 것
- core.js 시험 통과 (날짜·남은 날 계산, 입력 검증, 업종·지역·업력·직원 수·대표 나이 판정과 경계값, 마감 처리, 정렬, 샘플 결과, 초안 문단).
- index.html 안의 스크립트 문법 검사 통과, 세 파일에 http 주소·외부 호출 없음, viewport 설정과 "가상 예시" 안내 문구 있음(시험에서 확인).

못 한 것
- 실제 폰 설치·화면 미확인 (브라우저에서 열어 보지 않았고, APK도 만들지 않았습니다).
- 사람 눈으로 본 글자 크기·배치 확인.
- 실제 공고 수집, 공고 원문 대조, 신청서 제출, 결제, 전송은 만들지 않았습니다. 초안은 문단 틀일 뿐 심사 통과를 보장하지 않습니다.
