# PRJ-0015 설문 결과 자동 리포트

설문 응답 CSV를 넣으면 **열 종류 판별 → 집계 → HTML 보고서(막대그래프) + PDF**를 만들어 줍니다.
유료 AI API나 인터넷을 쓰지 않는 **로컬 명령줄 도구**입니다. (설계 문서의 웹 서비스(SaaS)·결제·로그인은 만들지 않았습니다.)

## 실행
```bash
pip install -r requirements.txt
python -m survey_report check --csv sample/survey.csv
python -m survey_report build --csv sample/survey.csv --out output --title "고객 만족도"
python -m pytest -q
```
- 숫자 열: 평균·중앙값·최소·최대·분포 / 선택형 열: 응답 수 막대 / 긴 글 열: 자주 나온 말 5개 / 빈칸 수
- **개인정보 열**(이름·이메일·전화 등 열 이름 또는 값 모양으로 판단)은 기본으로 보고서에서 뺍니다. `--keep-pii`로 남길 수 있고, 남기면 경고를 표시합니다.
- CSV는 UTF-8(엑셀 'CSV UTF-8')이어야 합니다. 아니면 안내 문구가 나옵니다.

## 확인한 것 / 못 한 것
- 확인(테스트 10개, 예시 6건): 평균·중앙값·분포 값, 열 종류 판별, 개인정보 열 감지·제외, 막대 길이 비례, HTML 이스케이프, 오류 안내, PDF 생성.
- **못 한 것**: 주관식 요약은 단어 빈도일 뿐 의미 요약이 아닙니다(AI 연결은 만들지 않음). 한글 조사 처리는 단순해서 틀릴 수 있습니다. PDF는 파일에 넣지 않는 CID 한글 글꼴을 써서 이 환경에서 화면 확인을 못 했고, PDF에는 그래프가 없습니다(HTML에만 있음). 실제 설문 수천 건·다른 설문 서비스 내보내기 형식은 시험하지 않았습니다. 개인정보 감지는 보조 수단이며 법적 점검이 아닙니다.
