# PRJ-0028 앱 스토어 스크린샷·설명 생성기

앱 화면 이미지와 문구(JSON)로 **스토어용 스크린샷**(큰 글자 문구 + 둥근 화면 + 배경색)과 **스토어 문구 초안**을 만듭니다. 문구는 템플릿 방식이며 AI(API)를 쓰지 않습니다. **스토어 등록은 하지 않습니다**(직접 하세요).

```bash
pip install -r requirements.txt
python -m store_kit check --app sample/app.json
python -m store_kit build --app sample/app.json --out output --sizes ios_6.7,play_phone [--font 글꼴.ttf]
python -m pytest -q
```
- 글자는 칸에 맞게 줄바꿈·크기 자동 조절(너무 길면 오류), 규격: ios_6.7 / ios_6.5 / ios_5.5 / play_phone
- 문구 점검: 글자 수 제한, 키워드 중복 제거·100자 자르기, 근거 없는 과장 표현("1위", "최고의" 등) 경고, 스크린샷 장수

## 확인한 것 / 못 한 것
- 확인(테스트 8개): 출력 크기 정확, 머리글 글자가 실제로 그려짐·아래 여백은 배경색, 글자 크기 자동 조절, 글자 수·과장 표현·키워드·장수 점검, 오류 안내.
- **못 한 것**: **스토어 규격(픽셀 크기)·글자 수 제한·스크린샷 장수는 제가 아는 값이며 공식 안내로 확인하지 못했습니다.** 애플·구글 정책이 바뀌었을 수 있으니 등록 전 확인하세요. 실제 스토어 심사 통과 여부, 기기 틀(프레임) 이미지, 다국어 번역, 앱 미리보기 영상은 없습니다. 한글 글꼴(Noto Sans CJK)이 없으면 글자가 깨질 수 있어 경고합니다. 문구 초안은 단순 템플릿이라 사람이 다듬어야 합니다. 구독·건당 결제·웹 화면은 만들지 않았습니다.
