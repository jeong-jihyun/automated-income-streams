# PRJ-0065 가계부 자동 분류·월간 리포트 앱 (카드 문자 분류 도구)

사용자가 붙여넣은 카드 승인·취소 문자 글을 읽어 금액·날짜·가맹점을 뽑고, 키워드 규칙으로 분류해 월간 리포트와 CSV를 만드는 명령줄 도구입니다. **휴대폰 문자함·은행·카드사에는 접근하지 않습니다.** 카드 번호와 이름은 저장하지 않습니다.

## 쓰는 법
```
python -m expensecat sample/sms.txt --rules sample/rules.json --month 2026-11 --today 2026-11-10 --out out.csv
```

## 지키는 것
- 같은 문자가 두 번 들어오면 한 번만 세고, 취소 문자는 같은 금액·가맹점의 앞선 승인과 짝지어 뺍니다. 짝이 없는 취소는 따로 알립니다.
- 읽지 못한 문자(안내·잘못된 날짜)는 버리지 않고 몇 건인지 보여 줍니다.
- 내가 고친 분류(--learn)가 기본 규칙보다 먼저 적용되고, 파일은 임시파일 후 교체로 안전하게 저장합니다.
- CSV는 수식 방지(따옴표) 처리합니다.

## 확인한 것 (테스트 12개 통과)
문자 나누기, 신한/KB/현대 형태 파싱, 카드번호·이름 미보관, 중복·취소 처리, 분류 합계, 사용자 규칙 우선, 연도 넘김, 잘못된 날짜, 수식 방지, 규칙 저장, CLI.

## 확인하지 못한 것
- **실제 카드사 문자 형식은 일부 예시만 확인했습니다.** 카드사·시기마다 형식이 달라 읽지 못하는 문자가 있을 수 있습니다(그 경우 건수로 알립니다).
- 안드로이드 앱 화면, 문자 자동 읽기 권한, 스토어 등록, 구독·광고 수익은 만들지 않았고 확인하지 못했습니다.
- 해외 결제(외화)·할부·부분취소 문자는 다루지 않습니다. 분류 정확도는 키워드 규칙 수준입니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
