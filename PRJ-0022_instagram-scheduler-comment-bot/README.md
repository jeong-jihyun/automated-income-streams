# PRJ-0022 인스타그램 예약 발행·댓글 응대 도구

두 가지를 도와주는 **로컬 보조 도구**입니다. 인스타그램에 직접 올리거나 댓글을 달지 않습니다.
1. **예약 목록 점검**: 문구 길이(2200자), 해시태그 수(30개)·중복, 사진 비율(4:5~1.91:1)·크기, 날짜 형식, 1시간 안 겹침을 검사하고 "지금 올릴 차례"를 알려 줍니다.
2. **댓글 답변 후보**: 키워드 규칙으로 답변 문구를 만들고, 스팸은 무시, 부정 댓글·규칙 없는 댓글은 "사람이 보세요"로 분류합니다. 시간당 답변 한도와 이미 답한 댓글 건너뛰기 포함.

```bash
python -m insta_tool check --csv sample/posts.csv
python -m insta_tool due --csv sample/posts.csv --now "2031-03-03 00:00" --done 1
python -m insta_tool replies --rules sample/rules.json --comments comments.json
python -m pytest -q
```
## 확인한 것 / 못 한 것
- 확인(테스트 7개): 위 점검 항목 전부, 올릴 차례 계산, 댓글 분류(부정이 규칙보다 우선), 한도·중복 처리, 오류 안내.
- **못 한 것**: 인스타그램 API 연동·로그인·실제 발행/댓글 게시는 **만들지 않았고 확인도 못 했습니다**(Meta 앱 심사와 비즈니스 계정, 권한, 이용 정책 확인 필요). 문구 2200자·해시태그 30개·사진 비율은 제가 아는 값이며 정책이 바뀌었을 수 있으니 공식 안내로 확인하세요. 자동 댓글은 계정 제재 위험이 있어 "후보만" 만들고 사람이 올리게 했습니다. 구독 결제·화면은 없습니다.
