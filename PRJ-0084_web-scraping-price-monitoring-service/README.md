# PRJ-0084 웹 데이터 수집·가격 모니터링 대행 (가격 기록 점검 도구)

사람이 넣은 가격 기록 CSV(날짜·상품·가격)에서 직전 대비 하락, 기록상 최저가, 목표가 도달, 입력 오류 의심, 기록이 오래됨을 알려 주는 명령줄 도구입니다. **웹에서 가격을 수집(크롤링)하지 않습니다. 기록은 직접 넣어야 합니다.**

## 쓰는 법
```
python -m pricewatch sample/history.csv --targets sample/targets.json --today 2026-11-11
```

## 지키는 것
- 같은 날 같은 상품이 여러 번이면 마지막 값을 씁니다. 형식 오류 행은 제외하고 몇 행인지 알려 줍니다.
- 직전 기록보다 10% 이상 내리면 하락 알림, 기록이 3개 이상이고 새 최저가면 최저가 알림입니다(10%는 예시 설정).
- 마지막 값이 중앙값의 절반 미만이거나 2배 초과면 입력 오류로 보고 알림을 보류합니다.
- 마지막 기록이 7일보다 오래되면 경고하되 알림으로 세지 않습니다.
- 출력 맨 끝에 가격이 직접 넣은 기록이며 실제 현재가와 다를 수 있다고 적습니다.

## 확인한 것 (테스트 10개 통과)
행 제외와 같은 날 마지막 값, 하락·최저가 알림, 이상값 알림 보류, 목표가 알림, 오래된 기록 경고, 변동 없는 기록은 알림 없음, 목표가 파일 오류, 열 누락, 출력 문구, CLI 종료 코드.

## 확인하지 못한 것
- 웹 수집, 알림 전송, 스케줄 실행은 만들지 않았고 실제 쇼핑몰 가격과 대조하지 못했습니다.
- 중앙값 기준의 이상값 판정은 세일 폭이 매우 큰 경우(절반 이하 가격)를 오류로 오인할 수 있습니다.
- 배송비·쿠폰·옵션별 가격 차이는 반영하지 않습니다.
- 실제 의뢰인 데이터로 시험하지 못했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
