PRJ-0012 모바일 자막 스타일 묶음 준비 도구 — 산출물
====================================================

구성
- UI_설계서.docx
- 기능정의서.docx
- API설계서.docx
- 디자인시스템.docx
- 모바일_컨셉_디자인_시안.html

실행
HTML 파일을 Chrome / Edge / Safari에서 열면 모바일 컨셉 화면을 확인할 수 있습니다.
별도 빌드 도구 없이 HTML/CSS/JavaScript 단일 파일로 동작합니다.

중요한 범위/한계
- HTML의 입력, 탭 이동, 스타일 편집, 미리보기, 기본 검증은 브라우저 내 데모입니다.
- 실제 ASS/SRT, MP4/GIF, PDF, ZIP 생성은 기존 Python video_preset 엔진을 API 서버로 감싸 연결해야 합니다.
- 현재 저장소 README는 CLI를 정의하고 HTTP API 구현은 확인되지 않아 API 설계서는 신규 제안입니다.
- 프리미어/캡컷 실제 호환성, 앱 전용 프리셋 직접 생성, 마켓 로그인/등록은 지원 범위가 아닙니다.
- 글꼴 파일은 ZIP에 포함하지 않으며 재배포 권한은 별도 확인이 필요합니다.
