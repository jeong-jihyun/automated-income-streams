# PRJ-0060 라이브커머스 클립 영상 제작 대행 (클립 구간 선정·절단 도구)

라이브 방송의 자막(SRT)에서 상품 이름·가격·할인·구매 유도 표현이 많은 15~45초 구간을 골라 겹치지 않게 최대 N개 추천하고, ffmpeg로 실제 클립(mp4, 원하면 세로 9:16)과 클립 기준으로 시간을 다시 맞춘 자막을 만드는 명령줄 도구입니다. 과장 표현('무조건·100%' 등)이 든 구간에는 경고를 붙입니다. 영상 내용은 보지 않고 자막만 봅니다.

## 쓰는 법
```
python -m clipcut sample/live.srt --video live.mp4 --keywords "접이식 선풍기,선풍기" --top 3 --vertical --out clips
```

## 지키는 것
- 구간 점수는 키워드(3점)·가격·할인 표현(2점)·구매 유도 표현(1.5점)을 길이 보정해 계산합니다. 점수가 0인 구간은 추천하지 않습니다.
- 클립은 15~45초이며 서로 겹치지 않습니다. 고를 구간이 없으면 억지로 만들지 않고 이유를 알려 줍니다.
- 과장·보장 표현이 든 클립에는 경고를 표시합니다(광고 표시·표시광고 심의는 사람이 확인).
- 원본 영상은 건드리지 않고 새 파일로 저장합니다. 자동 업로드는 하지 않습니다.

## 확인한 것 (테스트 12개 통과)
SRT 읽기(점·쉼표 구분)와 오류 처리, 점수 계산 요소, 길이 제한, 겹침 없음과 판매 핵심 구간 선택, 잡담 구간 제외, 과장 표현 경고, 신호 없는 방송 처리, 클립 기준 자막 재계산, **실제 ffmpeg 절단**(길이 14초±1, 세로 변환 1080×1920 확인), 영상 포함 CLI, 오류 처리.

## 확인하지 못한 것
- **실제 라이브 방송 영상·자막으로는 시험하지 못했습니다**(ffmpeg 시험 신호 영상과 가짜 자막). 방송 자막을 자동으로 만드는 음성 인식은 포함하지 않았고 SRT가 있어야 합니다.
- 세로 변환은 가운데 자르기라서 인물·상품이 가운데가 아니면 잘릴 수 있습니다. 자막 글자 입히기, 로고·효과, 음악, 화면 속 가격 표시 검수는 하지 않습니다.
- 크몽 등 판매 플랫폼의 정책, 방송 영상·출연자 초상·음악 저작권, 표시광고 규정 적합성은 확인하지 못했습니다. 수익성·납품 품질 평가도 못 했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
