# PRJ-0024 개인정보 비식별화 도구

문서·로그·CSV 안의 개인정보를 찾아 가려 줍니다. 파이썬 표준 라이브러리만 사용, 인터넷에 보내지 않습니다.

찾는 것: 주민등록번호, 카드번호(Luhn 검사), 사업자번호(검사), 휴대폰, 일반전화, 이메일, IP, 주소(시·도로 시작), 이름(**"이름:" "성명:" 같은 라벨이 붙은 경우만**).
가리는 방법: `mask`(일부만 *), `token`([휴대폰] 이름표), `hash`(같은 값은 같은 가명 — 비밀 문구 `--key` 필요), `redact`(█).

```bash
python -m pii_tool scan sample/log.txt                       # 몇 건 있는지만 (값은 출력 안 함)
python -m pii_tool run sample/log.txt --out out.txt --mode token
python -m pii_tool run sample/users.csv --out out.csv --mode hash --key 비밀문구 --csv
python -m pytest -q
```
## 확인한 것 / 못 한 것
- 확인(테스트 8개): 9종 탐지, 체크섬·날짜·Luhn으로 오탐 줄이기(잘못된 월, 틀린 카드번호, 버전 번호 등은 안 가림), 4가지 방식, 원본 값이 결과에 남지 않음, 다시 돌려도 결과 동일(멱등), 겹침 처리, CSV 칸 단위 처리.
- **한계(꼭 읽으세요)**: 정규식 기반이라 **놓치는 것이 있습니다.** 라벨 없는 이름("홍길동님 안녕하세요"), 계좌번호, 자유 형식 주소, 여권·운전면허번호, 외국 형식은 찾지 못합니다. 주민번호는 2020년 이후 발급분에 체크섬이 없을 수 있어 **형식(날짜+성별 숫자)만 맞으면 가립니다**(오탐 가능). `hash` 방식은 비밀 문구를 알면 전화번호처럼 경우의 수가 작은 값은 되찾을 수 있으니 문구를 안전하게 보관해야 합니다.
- 실제 대용량 로그 성능, 개인정보보호법 등 법적 기준 충족 여부는 확인하지 않았습니다(법률 자문 아님). 구독·웹 화면은 없습니다. 공유 전에 결과를 사람이 확인하세요.
