# PRJ-0062 도매 상품 수집·등록 대행 (도매 상품 정리·판매가 계산 도구)

도매처 상품 목록(CSV)을 받아 상품명을 정리하고, 수수료·마진을 반영한 판매가를 계산해 '셀러 몰 등록용 정리 CSV'와 '보류 목록'을 만드는 명령줄 도구입니다. **도매 사이트에서 상품을 수집하거나 몰에 자동 등록하지 않습니다**(사용자가 준 CSV만 처리).

## 쓰는 법
```
python -m wholesale sample/wholesale.csv --config sample/config.json --out ok.csv --hold hold.csv
```

## 지키는 것
- 판매가 = (도매가 + 배송비 분담) ÷ (1 − 수수료율 − 마진율), 10원 단위 올림. 수수료율+마진율이 100% 이상이면 거부합니다.
- 재고 부족·금지어('최저가' 등)·상품명 중복·숫자 오류·이미지 없음은 조용히 고치지 않고 '보류 + 이유'로 남깁니다.
- 상표/정품 표현(나이키 등)과 최소주문 수량, http 이미지는 '주의'로 표시만 합니다(권리 확인은 사용자 몫).
- 내보내기 CSV는 =,+,-,@로 시작하는 값에 따옴표를 붙여 엑셀 수식 실행을 막습니다.
- 모르는 열(메모 등)은 무시하고 알려 줍니다. 필수 열이 없으면 시작하지 않습니다.

## 확인한 것 (테스트 10개 통과)
판매가 공식 계산, 이익률 하한, 상품명 정리, 금지어·중복·저재고 보류, 상표 주의, 수식 방지 내보내기, 필수 열 누락·잘못된 설정값·빈 값 처리, CLI 출력.

## 확인하지 못한 것
- **도매처·마켓의 실제 수수료, 배송비 정산, 상품 등록 양식, 상표/지식재산 규칙을 확인하지 못했습니다.** 기본 수수료율 6%·마진 15%는 예시입니다.
- 도매 사이트 수집과 마켓 자동 등록은 만들지 않았습니다(약관·계정 위험). 도매처 재고는 CSV를 받은 시점 값이라 등록 직전에 다시 확인해야 합니다.
- 실제 도매 데이터·실제 판매로 시험하지 못했습니다(가짜 6행). 수익은 확인하지 못했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
