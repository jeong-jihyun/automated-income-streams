# PRJ-0011 AI 일러스트·아이콘 팩 판매 → 아이콘 팩 준비 도구 (icon_pack)

사람이 AI 도구로 만든 아이콘 PNG 폴더를 **점검하고, 크기별로 변환하고, 미리보기 모음·ZIP·사용 안내 PDF·상품 설명 초안**으로 묶어 줍니다.
그림 생성, 마켓 로그인·자동 업로드, 가격 결정은 하지 않습니다.

## 준비
Python 3.10+, `pip install -r requirements.txt`

## 실행
```
python -m icon_pack check --input ./icons
python -m icon_pack build --input ./icons --out ./dist --name "미니멀 가계부 아이콘 팩" --theme 가계부
```
점검 내용:
- 파일명 규칙 (영문 소문자·숫자·하이픈 `.png`), 정사각형, 최소 512px
- 투명 배경 (알파 채널 + 네 모서리 투명)
- 완전히 같은 파일, 아주 비슷한 그림(평균 해시 거리 3 이하)
- 스타일: 그림 하나를 뺀 나머지 세트의 대표 색과 얼마나 다른지 (3장 이상일 때)

불합격이 하나라도 있으면 목록만 보여 주고 멈춥니다. 통과하면 `png/64·128·256·512/`, `preview_sheet.png`, `license_guide.pdf`, `icon_pack.zip`, `listing_draft.txt` 를 만듭니다.

## 규격 설정 (중요)
`config/specs.json` 의 크기, 기준값은 **예시값**입니다.

## 테스트
`python -m pytest -q` → 7건 (더미 아이콘 20장: 정상 14, 불투명 배경, 알파 없음, 이름 위반, 작음, 완전 중복, 스타일 다름 / 정상 세트에서 오탐 없음 / 크기 변환 / 모음 이미지 칸 수 / ZIP 안 파일 수 / 오류 케이스)

## 알려진 한계 (솔직하게)
- 마켓의 실제 규격·심사 통과(Creative Market, Freepik), AI 생성물 표시 규칙, 실제 판매 성과는 확인하지 못했습니다.
- 스타일 검사는 "색 범위"만 봅니다. 선 굵기, 모양 통일감 같은 디자인 품질은 판단하지 못합니다.
- 비슷한 그림 검사는 단순한 평균 해시라 같은 모양을 크게 바꾸면 놓칠 수 있고, 단순한 도형은 서로 비슷하다고 잘못 잡을 수도 있습니다 (더미 도형으로만 시험).
- 라이선스 문구는 초안입니다. 사용한 AI 도구의 약관(상업 이용·재판매)은 사람이 확인해야 합니다.
