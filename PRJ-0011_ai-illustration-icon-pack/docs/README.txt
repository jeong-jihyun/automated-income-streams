실행
압축 해제 후 HTML 파일을 Chrome, Edge, Safari 등 최신 브라우저에서 엽니다.
별도 설치/서버 없이 화면 이동과 일부 브라우저 로컬 미리보기 동작을 확인할 수 있습니다.

주의
HTML은 독립 실행형 프론트엔드 컨셉 시안입니다. 브라우저에서 지원하는 기본 파일 메타데이터/파일 해시 미리보기만 수행하며, 기존 Python checker의 알파 모서리 검사, ahash 유사도, 색상 스타일 검사 및 실제 resize/contact sheet/PDF/ZIP 패키징은 수행하지 않습니다.
운영 기능은 API 설계서의 계약을 기준으로 기존 icon_pack 모듈과 연결해야 합니다.
specs.json의 수치는 저장소 README에서 예시값으로 명시되어 있습니다. 실제 판매 전 마켓 공식 규격을 확인하세요.
마켓 자동 로그인/업로드, 가격 결정, AI 이미지 생성 기능은 포함하지 않습니다.
