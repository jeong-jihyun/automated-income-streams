# PRJ-0069 소액 투자 전략 백테스트 서비스 (단순 전략 비교 도구)

가격 CSV로 존버(buyhold)·적립식(dca)·이동평균(sma) 전략을 같은 조건에서 돌려 최종 금액, 최대 낙폭(MDD), 연환산 수익률, 변동성을 비교하는 명령줄 도구입니다. **과거 계산일 뿐 미래 수익을 말하지 않으며 투자 조언이 아닙니다.**

## 쓰는 법
```
python -m backtest sample/prices.csv --cash 1000000 --monthly 100000 --fee 0.0005 --slip 0.0005 --fast 5 --slow 20
```

## 지키는 것
- 신호는 t일 종가로 계산하고 체결은 다음 날 종가에 하며(미래를 보지 않음), 수수료와 슬리피지를 매매마다 반영합니다.
- 가격 파일이 60줄 미만이거나 종가가 0 이하이거나 날짜가 오름차순이 아니면 시작하지 않고 몇 행인지 알립니다.
- 10일을 넘게 빠진 구간과 하루 40% 넘는 변동은 '분할·오류 가능성'으로 경고만 합니다.
- 적립식(dca)은 월 적립액이, 이동평균(sma)은 fast<slow가 필요하며 아니면 거부합니다.

## 확인한 것 (테스트 10개 통과)
비용 없는 존버 = 가격 비율, 비용이 결과를 낮춤, 알려진 MDD, 매월 적립, 이동평균의 룩어헤드 없음·양방향 매매, 입력 검증, 빠진 구간·급변 경고, 전략 비교와 CLI.

## 확인하지 못한 것
- **sample/prices.csv는 합성 데이터 400행**입니다. 실제 종목 가격으로 시험하지 못했습니다.
- 세금·배당·분할·상장폐지(생존 편향)·호가 단위·체결 불가는 반영하지 않았습니다.
- 전략의 실제 유효성은 판단하지 않았고 화면·서비스·가격 수집은 만들지 않았습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
