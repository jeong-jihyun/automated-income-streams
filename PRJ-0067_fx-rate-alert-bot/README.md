# PRJ-0067 환율·금리 알림 봇 (기준가 도달 판정 도구)

규칙(통화쌍·기준가·방향·대기시간)과 사용자가 준 시세 CSV로 '기준을 넘어서는 순간'을 판정하고, 보낼 문구를 JSONL 파일(outbox)에만 기록하는 명령줄 도구입니다. **시세를 수집하지 않고 알림을 실제로 전송하지 않습니다.**

## 쓰는 법
```
python -m fxalert sample/rules.json sample/readings.csv --state state.json --outbox outbox.jsonl --now 2026-11-11T09:00
```

## 지키는 것
- 기준을 넘어서는 순간에만 한 번 알리고, 같은 시세 파일을 다시 돌려도 이미 처리한 시각은 건너뛰어 중복 알림이 없습니다(상태 파일).
- 한 번 알린 규칙은 기준에서 rearm_pct%만큼 되돌아와야 다시 켜지고, 그래도 cooldown_min 분 안에는 다시 알리지 않습니다.
- 직전 값보다 20%를 넘게 변한 시세는 의심 값으로 건너뛰고 그 이유를 알립니다.
- 가장 최근 시세가 --now보다 180분 넘게 오래되면 '알림이 늦을 수 있음'이라고 알립니다(판정에서 빼지는 않음).
- 규칙의 연산자·기준값·id(중복, _로 시작)가 이상하면 시작하지 않고 알립니다.

## 확인한 것 (테스트 10개 통과)
넘어서는 순간에만 알림, 이하(<=) 규칙, 급변 값 건너뜀, 재무장, 대기시간 차단, 상태 파일 유지(재실행 중복 없음), 오래된 시세 안내, 잘못된 규칙, 잘못된 시세 줄 건너뛰기, CLI(outbox·상태 파일).

## 확인하지 못한 것
- **실제 환율·금리 데이터와 연결하지 않았습니다.** 시세 CSV는 사용자가 넣거나 합성한 예시입니다.
- 카카오·메일·텔레그램 전송은 만들지 않았습니다. outbox 파일까지만 만듭니다.
- 스케줄러(주기 실행)·서버 운영은 만들지 않았고, 시간대·휴장일 처리는 입력 시각을 그대로 믿습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
