# PRJ-0059 중고 전자기기 매입·리퍼 판매 (매입가 산정·판매 글 도구)

사용자가 넣은 최근 거래가(CSV)로 모델별 시세(이상치 제외 중앙값)를 구하고, 점검표로 상태 등급(A~D)과 수리비를 정해 매입 제안가와 예상 이익을 계산하며, 판매 글 초안을 만드는 명령줄 도구입니다. **분실·도난 확인, 개인정보 초기화가 끝나지 않으면 판매 글을 만들지 않습니다.**

## 쓰는 법
```
python -m refurb quote sample/comps.csv --model "예시폰 15" --storage 128GB --check sample/check_B.json --today 2026-10-25
python -m refurb listing --model "예시폰 15" --check sample/check_B.json --imei-checked --factory-reset --lost-stolen-clear
```

## 지키는 것
- 시세는 같은 모델·용량의 최근 60일 거래만, 5건 미만이면 '시세를 정하기 어렵다'며 매입가를 내지 않습니다. 사분위 범위로 이상치를 뺍니다.
- 등급: 고장 기능이 있으면 D, 화면·외관 흠집 0단계+배터리 85% 이상 A, 1단계 이하+80% 이상 B, 2단계 이하 C. 등급 계수·수리비는 예시값.
- 매입가 = 예상 판매가×(1-수수료) − 수리비 − 목표 이익(1천원 단위 내림, 음수 없음). 예상 판매가는 달라질 수 있다고 항상 안내합니다.
- 판매 글에는 고장·배터리 상태를 숨기지 않고 쓰며, '새것 같은·완벽' 같은 과장 표현은 점검에서 걸립니다. 시세를 크롤링하지 않고 중고마켓에 자동 게시하지 않습니다.

## 확인한 것 (테스트 12개 통과)
시세 필터(기간·모델·용량)와 이상치 제외, 표본 부족 처리, 등급 규칙과 수리비, 입력 오류, 매입가 계산과 음수 방지, 판매 글 전 필수 확인 3종, 고장 공개, 과장 표현 점검, 시세 파일 오류 행 안내, CLI.

## 확인하지 못한 것
- **실제 중고 시세는 사용하지 않았습니다**(가짜 거래가). 당근마켓·번개장터 시세 수집은 약관상 가능한지 확인하지 못해 만들지 않았고, 시세는 사람이 CSV로 넣어야 합니다.
- **IMEI 분실·도난 조회는 실제로 하지 못합니다.** 사용자가 확인했다고 표시하는 방식뿐입니다. 장물 취득·개인정보 처리 관련 법규와 중고 전자기기 매입업 신고·허가 요건은 확인하지 못했습니다.
- 등급 계수·수리비·수수료는 예시이며 실제 수리 견적·판매 속도·마진은 확인하지 못했습니다. 기기 기능 자동 진단은 하지 않습니다(사람이 점검표 입력).
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
