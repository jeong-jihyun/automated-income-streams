# PRJ-0075 지역 나눔·교환 플랫폼 (글 점검·매칭 후보 도구)

나눔(offer)·구해요(want) 글 CSV에서 금지 품목을 걸러 내고, 위치를 동 단위로만 공개하며, 가까운 거리의 비슷한 글끼리 매칭 후보를 만들고 오래된 글을 정리하는 명령줄 도구입니다. **연락·거래 중개는 하지 않습니다.**

## 쓰는 법
```
python -m sharing sample/posts.csv --today 2026-11-11 --max-km 2
```

## 지키는 것
- 의약품·주류·담배·동물·상품권·현금 등 금지 품목이 의심되면 매칭에서 빼고 이유를 보여 줍니다.
- 공개용 위치는 동 이름과 소수 둘째 자리(약 1km)로 반올림한 좌표만 씁니다. 정확한 좌표는 내보내지 않습니다.
- 거리는 하버사인 공식으로 계산해 기준(기본 2km) 안의 글만 매칭하고 한 나눔 글은 한 번만 짝지어집니다.
- 14일이 지난 글은 만료로 표시하고 매칭에서 뺍니다.

## 확인한 것 (테스트 11개 통과)
금지 품목 보류, 동 누락, 좌표 반올림, 서울-부산 거리, 만료 경계, 매칭 짝·거리, 나눔 글 중복 사용 방지, 잘못된 입력, CLI.

## 확인하지 못한 것
- **금지 품목 목록은 단어 포함 검사라 놓치거나 잘못 걸러낼 수 있습니다(예: '총' 같은 짧은 단어).** 실제 운영 기준과 법규는 확인하지 못했습니다.
- 매칭은 제목에 겹치는 단어가 있는지만 봅니다. 의미 비슷함·사진 확인은 하지 않습니다.
- 연락 중개·채팅·신고·사기 방지·화면·서비스 운영은 만들지 않았고 위치 정보 처리의 개인정보 적합성은 확인하지 못했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
