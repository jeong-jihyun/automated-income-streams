# PRJ-0002 구글 시트 템플릿 생성기

가계부, 프로젝트 관리, 재고 관리 템플릿을 **직무별(프리랜서·소상공인·학생)** 로 자동 생성하고,
수식 오류를 자동으로 검사하는 프로그램입니다. 판매 등록은 사람이 직접 합니다.

## 빠른 시작
```bash
pip install -r requirements.txt
python -m engine.cli --kind budget --job freelancer --theme navy --out output
python -m pytest -q
```
- 결과: `output/<종류>_<직무>_<테마>.xlsx`, `output/listing_*.json`(상품 문구 초안)
- 수식 검사에는 LibreOffice(`soffice`)가 필요합니다. 없으면 `--skip-recalc`로 정적 검사만 합니다.

## 템플릿
| kind | 시트 구성 |
|---|---|
| budget | 사용설명서, 설정, 거래내역, 월별요약(차트), 분류별지출(차트) |
| project | 사용설명서, 설정, 작업목록(상태 자동), 대시보드(차트) |
| inventory | 사용설명서, 설정, 상품목록, 입출고, 재고현황(발주 필요 표시) |

## 구글 시트로 올리기
.xlsx를 구글 드라이브에 올려 "Google 스프레드시트로 열기" 후 확인합니다. 판매할 때는 원본 공유가 아니라
`.../copy` 형태의 **사본 만들기 링크**를 구매자에게 전달하세요.

## 화면(React) / 크롬 확장
- `ui/` : 종류·직무·색상을 고르면 실행 명령어를 보여 줍니다. `cd ui && npm install && npm run build`
- `extension/` : Gumroad/Etsy 등록 화면에 제목·설명·태그 **복사 버튼만** 표시합니다(자동 입력·자동 등록 없음).
  chrome://extensions → 개발자 모드 → "압축해제된 확장 프로그램 로드" → `extension` 폴더 선택.
  팝업에 `listing_*.json` 내용을 붙여넣고 저장합니다.
