# PRJ-0002 구글 시트 템플릿 — Claude 프로젝트 지침

이 내용은 프로젝트 폴더 바로 아래의 `CLAUDE.md` 와 같습니다. Claude 웹 프로젝트의 지침으로 붙여 넣을 때 사용하세요.

## 목적
수식 완성형 구글 시트 템플릿(가계부·프로젝트 관리·재고 관리)을 직무별로 자동 생성하고 검사한다.

## 작업 규칙
- 답변은 한국어로, 쉬운 말로, 생각의 흐름이 보이게 설명한다.
- 템플릿을 바꾸면 `python -m pytest -q` 로 모든 조합의 수식 오류가 0개인지 확인한다.
- 샘플 데이터의 기대값(월별 합계, 재고 수량)은 테스트에 고정되어 있으니 같이 고친다.
- 크롬 확장은 복사 버튼만 제공한다. 사이트 입력칸 자동 채우기·자동 등록은 만들지 않는다.
- 타사 템플릿 디자인을 베끼지 않는다.

## 폴더
engine/(Python) · templates/(직무 프리셋 JSON) · ui/(React) · extension/(Chrome) · docs/ · claude/

## 자주 하는 요청
1. "카페 사장님용 재고 템플릿" → `templates/presets.json` 에 직무 추가 후 테스트
2. "차트 추가" → `engine/builder.py` 해당 build_* 함수 수정
3. "문구 수정" → `engine/listing.py`
