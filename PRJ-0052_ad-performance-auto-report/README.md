# PRJ-0052 SNS 광고 성과 자동 리포트 (주간 보고서 생성 도구)

메타·네이버 광고 관리자에서 내려받은 CSV를 합쳐 주간 성과 보고서(마크다운)를 만드는 명령줄 도구입니다. 비용·노출·클릭·전환과 클릭률·클릭당 비용·전환당 비용·광고수익률을 계산하고 지난주와 비교하며, 전환 0·표본 작음·데이터 누락 같은 주의사항을 표시합니다. 광고 계정에 접속하지 않습니다.

## 쓰는 법
```
python -m adreport --meta sample/meta.csv --naver sample/naver.csv --week 2026-10-19 --out report.md
# 열 이름이 다르면: --map map.json  ({"meta":{"spend":"내 열 이름"}})
```

## 지키는 것
- 0으로 나누는 지표(클릭 0일 때 CPC 등)는 '-'로 표시합니다.
- 주간 데이터가 7일치보다 적으면 알려 줍니다. 클릭 30 미만이면 비율 해석 주의를 붙입니다.
- 필요한 열이 없거나 숫자·날짜가 잘못되면 몇 번째 행인지 알려 주고 멈춥니다(조용히 넘기지 않음).
- 합계는 내려받은 파일 기준이며 광고 관리자 화면과 다를 수 있다는 문구를 항상 붙입니다.

## 확인한 것 (테스트 11개 통과)
CSV 읽기(천 단위 쉼표), 주 계산(월요일 시작), 주간 합계가 직접 계산과 일치, 0 나누기 처리, 변화율, 주의사항 4종, 두 플랫폼 합산 보고서, 깨끗한 데이터의 '특이사항 없음', 광고수익률 열이 없는 경우, 오류 5종, 열 이름 지정(--map), CLI.

## 확인하지 못한 것
- **실제 메타·네이버 광고 내려받기 파일은 사용하지 못했습니다.** 열 이름 매핑은 제가 예시로 정한 것이라 실제 파일의 열 이름·인코딩·날짜 형식과 다를 수 있습니다(다르면 --map 필요).
- 시험 데이터는 무작위로 만든 가짜 숫자입니다. 광고 API 자동 연동, 전환 귀속 기준 차이, 캠페인별 상세 분석, 차트·PDF·이메일 전송은 만들지 않았습니다.
- 구독 서비스로서의 화면·로그인·결제·다중 고객 분리는 이 도구 범위 밖입니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
