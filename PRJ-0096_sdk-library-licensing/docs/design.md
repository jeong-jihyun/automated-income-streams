# 설계
- core.js: 순수 함수. 브라우저(window.Core)와 node(module.exports) 양쪽에서 쓴다. 기기 시계는 읽지 않고 '오늘'은 입력으로 받는다(샘플 기본값 2026-11-17).
- 날짜: `YYYY-MM-DD`를 UTC 자정으로 바꿔 일 수를 센다. 존재하지 않는 날짜(2026-02-30)는 거부. 달 더하기는 말일에 맞춘다.
- 키 형식: `접두어(영대문자 2~8)-연도4-번호4-검사값4`. 검사값 = 앞 부분 글자 코드 합 % 10000(4자리). 암호 보안이 아니다.
- 판정 우선순위: 형식 오류 > 입력 오류 > 만료(남은 일 < 0) > 좌석 초과(사용 > 허용) > 만료 임박(0 ~ 30일) > 유효. 만료일 당일은 남은 0일로 '만료 임박'(당일까지 유효), 다음 날부터 만료. 30일째는 임박, 31일째는 유효. 사용 좌석 = 허용 좌석은 유효.
- 견적: 좌석 구간 누진(예시 1~10석 120,000 / 11~50석 100,000 / 51석~ 80,000 원/년) x 기간 + 지원 추가금(기본 0 / 표준 600,000 / 프리미엄 1,800,000 원/년) x 기간. 다년 할인 1년 0%, 2년 5%, 3년 10%를 정가 합계에 곱해 반올림, 두 항목에 allocate로 나눈다. 부가세 = round(공급가 x 10%), 항목별 부가세도 allocate. 항목 합 = 총합.
- 갱신: 종료일 = 시작일 + (년 x 12)개월 - 1일. 안내일 = 종료일 - 60/30/7일. 오늘과 비교해 지남/오늘/예정 표시.
