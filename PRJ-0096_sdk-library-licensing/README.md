# 개발 SDK·라이브러리 라이선스

자체 개발 모듈을 기업에 연간 라이선스할 때 쓰는 세 가지 도구입니다. 인터넷 없이 휴대폰에서 돌아가며, 결제·전송·로그인은 없습니다. 단가는 예시이고 법률 자문이 아닙니다.

## 할 수 있는 일
1. 라이선스 키 검사기: 키(예: `ACME-2026-0001-0673`), 만료일, 허용 좌석, 사용 좌석을 넣으면 유효 / 만료 임박(30일 이내) / 만료 / 좌석 초과 / 형식 오류를 알려 줍니다. 검사값은 글자 코드를 더하는 단순 합계 규칙이라 암호 보안이 아닙니다(위조를 막지 못함).
2. 연간 라이선스 견적: 좌석 구간별 단가(구간 누진), 지원 등급 추가금, 다년 할인(2년 5%, 3년 10%), 부가세 10%. 항목 합 = 총합이 되도록 나머지를 처리합니다.
3. 갱신 일정: 계약 시작일과 기간으로 종료일과 갱신 안내일(만료 60/30/7일 전)을 목록으로 보여 줍니다.

날짜는 화면 맨 위 "오늘" 칸의 값을 씁니다(기본값은 샘플 날짜 2026-11-17). 기기 시계를 읽지 않아서 같은 입력이면 항상 같은 결과가 나옵니다.

## 쓰는 법
1. `app/index.html`을 열면 샘플이 이미 들어 있고 결과가 바로 보입니다.
2. 칸 값을 바꾸고 각 버튼(키 검사 / 견적 계산 / 갱신 안내일 계산)을 누릅니다.
3. "샘플로 되돌리기"로 처음 값으로 돌아갑니다. 입력값은 이 기기의 localStorage에만 저장됩니다.

## APK 받아 설치하는 법
1. 저장소를 GitHub에 푸시합니다.
2. GitHub 저장소의 Releases에서 `apk-PRJ-0096` 을 찾아 `.apk` 파일을 받습니다.
3. 받은 파일을 눌러 설치합니다.
4. "출처를 알 수 없는 앱" 설치를 막으면, 설정에서 허용한 뒤 다시 설치합니다.

## 시험
폴더 안에서 `node --test tests/test_all.js` (Node 22에서는 `node --test tests/` 가 폴더를 파일로 읽어 실패해서 파일 이름까지 적습니다.)

## 확인한 것 / 못 한 것
확인한 것
- core.js 시험 19개 모두 통과 (키 형식·검사값, 만료 당일·30일째·31일째 경계, 좌석 초과, 구간 단가, 다년 할인, 돈 합계 보존, 갱신 안내일, 윤년·말일 처리).
- index.html 안의 스크립트 문법 검사 통과, 세 파일에 http 주소 없음, viewport 설정 있음, core.js에 기기 시계 호출 없음(시험에서 확인).

못 한 것
- 실제 폰 설치·화면 미확인 (브라우저에서 열어 보지 않았고, APK도 만들지 않았습니다).
- 사람 눈으로 본 글자 크기·배치 확인.
- 실제 라이선스 서버 연동, 암호 서명 검증, 결제, 전송은 만들지 않았습니다. 단가·할인율은 예시입니다.
