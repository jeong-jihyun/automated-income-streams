# PRJ-0046 상품 사진 배경 제거·보정 대량 처리 (단순 배경 전용)

폴더 안의 상품 사진을 한꺼번에 읽어, 단색에 가까운 배경을 흰색(또는 연회색)으로 바꾸고, 상품을 가운데에 맞춰 마켓용 정사각형 등 규격으로 저장하는 명령줄 도구입니다. 배경이 복잡한 사진은 억지로 처리하지 않고 이유와 함께 '실패'로 알려 주며, 결과는 report.csv에 남습니다.

## 쓰는 법
```
python -m photobatch sample out --preset square_1000 --color white
python -m photobatch sample out --dry-run   # 저장 없이 성공/실패만 미리 보기
```

## 지키는 것
- 가장자리 색이 들쭉날쭉하면(복잡한 배경) 처리하지 않고 실패로 표시합니다. 조용히 넘기지 않습니다.
- 상품 안쪽에 배경색과 같은 부분(구멍·하이라이트)은 지우지 않습니다.
- 밝기 보정은 모든 색에 같은 배수(0.85~1.2배)만 곱합니다.
- 규격 크기는 예시 값이며 각 마켓의 실제 현재 규정은 확인하지 못했습니다.

## 확인한 것 (테스트 10개 통과)
상품 영역 찾기, 흰 배경·가운데 정렬·규격 크기, 상품 색 유지, 여백 비율, 복잡한 배경 거부, 너무 작은 사진·알 수 없는 규격·상품이 안 보이는 경우 거부, 안쪽 구멍 보존, 일괄 처리와 report.csv, 깨진 파일 처리, dry-run, CLI. 결과 이미지를 눈으로 확인했습니다(배경 흰색, 붉은 상품 색 유지).

## 확인하지 못한 것
- **실제 상품 사진으로는 시험하지 못했습니다.** 시험 이미지는 도형으로 만든 가짜 상품입니다. 그림자·반사·유리·털·투명한 물건, 상품 색이 배경과 비슷한 경우는 거칠게 처리되거나 실패할 수 있습니다.
- AI 배경 제거(복잡한 배경)는 연결하지 않았습니다. 그림자 생성, 상품 크기에 맞춘 자동 여백 최적화, 색상 정확도(실물과 같은 색)는 다루지 않습니다.
- 마켓별 실제 이미지 규정(크기·여백·배경색), 대량(수천 장) 처리 속도, 업로드 연동
- 화면(웹), 결제, 고객 사진 보관·삭제 정책
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
