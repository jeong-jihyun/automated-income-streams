# PRJ-0085 알림톡·문자 발송 시스템 구축 (발송 준비·점검 도구)

문구 템플릿과 수신자 CSV로 문구를 채우고, 번호 형식·광고 수신 동의·광고 금지 시간·SMS/LMS 길이·중복을 점검해 outbox 파일(JSONL)을 만드는 명령줄 도구입니다. **실제 문자·알림톡은 보내지 않습니다(status 는 READY 로만 남음).**

## 쓰는 법
```
python -m dispatchq sample/templates.json reminder sample/recipients.csv --send-at 10:00 --out outbox.jsonl
```

## 지키는 것
- 휴대폰 번호는 010 등 11자리(+82 형식 포함)로 맞추고 그 밖은 제외합니다.
- 템플릿의 {값}을 채울 칸이 비어 있으면 그 행을 제외합니다.
- 광고(kind=ad)는 수신 동의(consent_ad=1)가 있는 사람만, 21:00~08:00 사이가 아닐 때만 만들고 '(광고)' 표시와 무료수신거부 문구를 붙입니다(시간대와 수신거부 번호는 예시 설정).
- 글자 수는 cp949 바이트로 90 이하 SMS, 2000 이하 LMS, 그 위나 이모지 등은 제외합니다.
- 같은 번호에 같은 문구는 한 번만 만듭니다.

## 확인한 것 (테스트 8개 통과)
번호 정리, 채울 값 없음·번호 오류·중복 제외, 광고 동의·표시, 광고 금지 시간 경계, SMS/LMS 판정, 템플릿 오류, CLI 가 outbox 만 쓰고 발송 문구를 안내하는지.

## 확인하지 못한 것
- 실제 발송 업체(알림톡·문자 API) 연결은 만들지 않았고 발송 시험도 하지 못했습니다.
- 알림톡은 업체 사전 승인 템플릿이 필요한데 승인 절차와 형식 제한은 다루지 않았습니다.
- 광고 표시 문구·시간대·수신거부 번호가 현행 법규와 맞는지 확인하지 못했습니다(예시 값이며 법률 자문 아님).
- 정보성 문자의 시간 제한은 두지 않았습니다. 이통사별 바이트 계산 차이는 확인하지 못했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
