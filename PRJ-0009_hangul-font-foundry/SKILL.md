# 한글 폰트 키트

1. 글리프 SVG 폴더(`U+AC00.svg` 형식)가 있는지 확인한다. 없으면 `charset` 으로 필수 글자 목록을 먼저 만든다.
2. `python -m hangul_font_kit check --glyphs <폴더>` 로 점검하고 문제를 쉬운 말로 설명한다.
3. 통과하면 `build --glyphs <폴더> --out <결과>` 를 실행한다.
4. 글자 디자인 품질, OS별 표시, 마켓 심사는 확인할 수 없다고 알린다.
5. 마켓 입점·등록은 사람이 직접 한다.
