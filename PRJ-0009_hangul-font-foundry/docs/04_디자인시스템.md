# PRJ-0009 디자인 시스템
버전 1.0 · 모바일 폰트 제작 워크스페이스

## 1. 디자인 원칙
- 작업 중심: 글자 제작 → 검수 → 빌드 흐름을 한눈에 파악
- 정밀함: 코드포인트, 파일명, 오류 규칙을 명확히 표기
- 신뢰성: 실제 데이터와 데모 데이터를 시각적으로 구분
- 모바일 우선: 한 손 조작, 하단 탭, 큰 터치 영역

## 2. 색상 토큰
| 토큰 | 값 | 사용 |
|---|---|---|
| Primary | #635BDB | 주요 CTA, 선택 탭 |
| Primary Dark | #4941B5 | 강조/pressed |
| Ink | #202033 | 제목/본문 |
| Muted | #77788B | 보조 텍스트 |
| Canvas | #F6F6FA | 앱 배경 |
| Surface | #FFFFFF | 카드/패널 |
| Border | #E8E8F0 | 구분선 |
| Success | #16865B | 통과/완료 |
| Warning | #B7791F | 경고 |
| Danger | #C43D4B | 오류 |

## 3. 타이포그래피
- 한글 UI: system-ui, -apple-system, BlinkMacSystemFont, "Noto Sans KR", sans-serif
- 화면 제목 24/32, 섹션 18/26, 본문 14/22, 캡션 12/18
- 코드포인트/파일명은 ui-monospace 계열 사용
- 글리프 미리보기는 UI 폰트와 분리해 사용자가 만든 폰트를 표시

## 4. 간격·모서리·그림자
- spacing: 4, 8, 12, 16, 20, 24, 32
- radius: 10(입력), 14(카드), 20(대형 패널), pill(상태)
- 카드 그림자는 낮은 불투명도로 최소 사용
- 콘텐츠 최대 폭 720px, 모바일 좌우 여백 20px

## 5. 컴포넌트
- Button: primary / secondary / ghost / destructive, 높이 48px
- BottomNav: 5개 탭, 아이콘+라벨, 활성 상태 명시
- StatusChip: 완료/누락/오류/진행 중
- ProgressBar: 전체 수와 완료 수 텍스트 병기
- GlyphTile: 글자, 코드포인트, 파일 상태
- IssueRow: 심각도, 문제 설명, 대상 파일, 해결 안내
- EmptyState: 현재 상태 설명 + 다음 작업 CTA
- Toast: 저장/실패 결과, 자동 사라짐 시간 충분히 확보

## 6. 인터랙션
- 버튼은 처리 중 disabled 및 로딩 텍스트 표시
- 검수/빌드 시작 전 확인 대화상자 제공
- 위험 작업은 결과와 영향 범위를 설명
- 탭은 화면 전체를 전환하며 선택 상태 유지
- 입력값은 라벨과 예시를 함께 제공

## 7. 반응형
- 360~767px: 하단 탭, 1열 카드, 안전 영역 반영
- 768~1023px: 2열 카드, 넓은 상세 패널
- 1024px 이상: 좌측 내비게이션 또는 상단 탭으로 확장 가능
- prefers-reduced-motion 지원
