# PRJ-0009 기능정의서
버전 1.0 · README 구현 범위와 일치하는 기능 기준

|---|---|---|---|---|
| F-001 | 문자 세트 생성 | 출력 CSV 경로 | KS X 1001 2,350자 및 숫자·영문·기본 기호 목록 구성 | chars.csv |
| F-002 | 글리프 파일 등록 | SVG 파일 | 파일명/경로/확장자 확인 및 프로젝트에 배치 | 글리프 목록 |

## 2. 검수 규칙
- 필수 글자 누락: 기본 빌드 차단. 시험 목적일 때만 --allow-missing 허용
- 파일명: U+XXXX.svg 형식
- SVG viewBox: 0 0 1000 1000
- 기준선: 위에서 800
- 지원 도형: path의 절대좌표 M/L/H/V/C/Q/Z 및 rect
- 미지원: transform, 상대좌표, arc(A) 등
- 열린 경로/깨진 SVG는 오류 처리

## 3. 비기능 요구사항
- 재현성: 동일한 입력과 설정에서 동일한 결과를 만들 수 있도록 빌드 설정과 로그 기록
- 데이터 무결성: 원본 SVG를 빌드 과정에서 덮어쓰지 않음
- 오류 가시성: 파일 단위 오류 위치와 해결 가이드 제공
- 보안: 업로드 파일 크기 제한, SVG 외부 리소스 로딩 금지, 경로 traversal 차단
- 모바일 UX: 네트워크 지연 시 진행 상태와 재시도 제공

## 4. 범위 제외
- 자동 글자 디자인/AI 생성
- 마켓 자동 입점, 심사, 상품 등록, 결제/정산
- OTF(CFF), 힌팅, 커닝, 글자 겹침 자동 정리
- Windows/macOS 렌더링 호환성 인증
- 전문가 수준 라이선스 법률 검토

## 5. 수용 기준
1. 문자 세트 출력에 KS X 1001 완성형 2,350자가 포함된다.
2. 누락 파일, 잘못된 파일명, 잘못된 viewBox, 열린 경로, 미지원 명령을 구분해 표시한다.
3. 누락 글리프가 있으면 기본 빌드가 중단된다.
4. 정상 입력에서 TTF 및 견본 PNG/PDF 산출 여부를 확인할 수 있다.
5. 모바일 탭 5개가 모두 실제 화면 전환을 수행한다.
6. API 연결 전 데모 데이터는 데모라고 명확히 표시한다.

## 6. 테스트 시나리오
- 정상 SVG / 잘못된 이름 / 잘못된 viewBox / 열린 path / 상대좌표 / A 명령 / 누락 글리프 / --allow-missing / 20자 샘플 TTF 재읽기 / 견본 PNG·PDF 생성.
