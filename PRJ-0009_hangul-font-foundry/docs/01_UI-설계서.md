# PRJ-0009 모바일 UI 설계서
버전 1.0 · 기준: 저장소 README.md · 플랫폼: 모바일 우선 반응형 웹

## 1. 제품 목표
한글 폰트 제작자의 반복 작업을 모바일에서 확인·관리한다. 글자 디자인 자체는 사용자가 SVG로 수행하며, 앱은 글리프 목록, 누락/오류 확인, 빌드 실행, 결과물 미리보기를 지원한다. 마켓 입점과 심사 제출은 자동화하지 않는다.

## 2. 주요 사용자 흐름
1. 프로젝트 생성 또는 기존 프로젝트 열기
2. 글자 세트 생성: KS X 1001 완성형 한글 2,350자 + 숫자·영문·기본 기호
3. 글리프 파일 업로드/동기화
4. 검수 실행 및 오류 항목 수정
5. TTF·견본 PNG·문장 미리보기·견본 PDF 생성
6. 라이선스/상품 설명 초안 확인 후 직접 검토

## 3. 화면 구조
| 화면 | 목적 | 핵심 UI |
|---|---|---|
| 홈 | 프로젝트 상태 파악 | 진행률, 누락 글자, 최근 검수, 빠른 작업 |
| 글리프 | 글자 단위 작업 | 검색, 필터(전체/완료/누락/오류), 글자 카드, 상세 상태 |
| 검수 | 규격 오류 해결 | 오류 요약, 파일명·캔버스·경로·명령 검사 결과, 오류별 해결 가이드 |
| 빌드 | 결과물 생성 | 글꼴명, 자간, 미리보기 문장, 빌드 실행, 산출물 목록 |
| 설정 | 프로젝트 환경 | 글꼴 메타데이터, 기준선, 캔버스, 작업 안내 |

## 4. 화면 상세
### 홈
- 상단: 프로젝트명, 저장 상태
- KPI: 글리프 완료 수 / 전체 수, 누락 수, 오류 수
- 진행률은 실제 서버 응답값으로 표시하며 임의 샘플 수치를 실제 상태처럼 표시하지 않는다.
- CTA: 글자 목록 열기, 검수 실행, 빌드로 이동

### 글리프
- 검색은 한글 글자, 유니코드(U+AC00), 파일명으로 검색
- 필터: 전체 / 완료 / 누락 / 오류
- 상세 패널: 글자, 코드 포인트, 파일명, 캔버스 규격, 검사 결과
- 모바일에서는 카드형 2열 또는 1열로 배치하고 상세는 전체 화면 시트로 연다.

### 검수
- 실행 전 대상 글리프 경로 확인
- 검수 항목: 필수 글자 누락, U+XXXX.svg 파일명, viewBox 0 0 1000 1000, 기준선 y=800, 열린 경로, 미지원 SVG 명령(transform/상대좌표/A 등)
- 결과는 오류/경고/통과로 구분하고 파일명과 수정 방법을 함께 제공

### 빌드
- 입력: glyphs 경로, 출력 경로, 글꼴명, 자간, 미리보기 문장
- 실행 전 누락 글리프 차단 여부를 명시
- 성공 시 TTF, 견본 PNG, 문장 미리보기, PDF, 라이선스 초안의 파일별 상태 표시
- 마켓 등록/심사/판매는 수동 작업임을 고지

## 5. 내비게이션
하단 고정 탭 5개: 홈, 글리프, 검수, 빌드, 설정. 현재 위치는 색상과 텍스트 굵기로 함께 구분한다. 탭 이동은 실제 화면 패널 전환으로 구현한다.

## 6. 상태 및 예외
- Empty: 아직 글리프 세트가 없는 상태와 생성 CTA 표시
- Loading: 검수/빌드 진행 중 중복 실행 방지
- Error: API 오류 원문과 재시도 동작 제공
- Partial: 일부 글리프만 준비된 상태를 명확히 표시
- Success: 결과 파일명, 생성 시간, 크기 표시

## 7. 접근성·반응형
- 터치 타깃 최소 44px
- 본문 대비 4.5:1 목표, 상태는 색상만으로 전달하지 않음
- 360px 모바일부터 데스크톱까지 대응
- 키보드 포커스 표시, 입력 라벨 제공, 모션 최소화 옵션 고려

## 8. 구현 주의
현재 저장소 CLI가 실제 기능의 기준이다. 모바일 화면의 버튼은 실제 API 연결 전까지 데모 동작임을 표시해야 하며, 프론트엔드에서 SVG 검사나 TTF 생성을 가짜로 완료 처리하면 안 된다.
