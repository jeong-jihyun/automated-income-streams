# PRJ-0044 AI 공시·뉴스 요약 알림 (투자자용 참고 도구)

사용자가 준 공시·뉴스 목록(JSON)에서 관심 종목만 골라, 제목 키워드로 분류(유상증자·실적·계약 등)하고 중요도 순으로 정리해 알림 글을 만드는 도구입니다. 비슷한 제목은 하나로 합치고, 이미 보낸 항목은 다시 보내지 않습니다. **매수·매도 추천이나 투자 자문이 아닙니다.**

## 쓰는 법
```
python -m digest sample/items.json --watch 가나전자,다라화학 --state sent.state.json --min 2
# 먼저 --dry-run 으로 미리 볼 수 있습니다
```

## 지키는 것
- 출처·시각이 없는 항목은 받지 않습니다(알림마다 출처와 시각을 표시).
- 모든 알림 끝에 '투자 자문 아님, 원문 확인' 문구가 붙고, 추천·전망 문구는 만들지 않습니다.
- 알림을 실제로 보낸 뒤에만 '보낸 목록'에 기록합니다(전송이 실패하면 다음에 다시 보냄). 합쳐진 중복 기사도 함께 기록합니다.
- 공시·뉴스를 직접 수집하지 않습니다.

## 확인한 것 (테스트 10개 통과)
분류와 중요도, 제목 유사도 중복 합치기, 중요도→시각 정렬, 관심 종목 필터, 최소 중요도, 입력 검증, 알림 글에 출처·시각·원문 링크·고지문 포함, 반복 알림 방지, 전송 실패 시 기록 안 함, dry-run, CLI. 개발 중 합쳐진 중복 기사가 다음 실행에서 다시 알려지는 오류를 찾아 고쳤습니다.

## 확인하지 못한 것
- **실제 공시(DART 등)·뉴스를 가져오지 않았습니다.** 시험 데이터는 가짜 예시이며 실제 수집·API 이용약관은 확인하지 못했습니다.
- 분류는 제목 키워드뿐이라 '유상증자 철회'처럼 반대 뜻도 같은 분류로 잡힙니다. 본문은 읽지 않으므로 요약이 아니라 분류입니다.
- 키워드·중요도 등급의 투자 관점 타당성은 검토하지 않았습니다.
- 실제 알림 전송(문자·메신저·이메일)은 연결하지 않았습니다(전송 함수를 꽂아 쓰는 구조). 자본시장법상 유사투자자문업 해당 여부는 확인하지 못했으니 서비스로 내기 전 전문가 확인이 필요합니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
