# 설계 메모

## 흐름
입력 글 -> `splitInquiries`(줄 나누기, 번호·불릿 제거) -> 줄마다 `classify` + `urgency` -> `groupByTeam`(칸별 묶기·정렬) -> 화면.

## 분류
- 칸마다 키워드 목록. 문의에 들어 있는 서로 다른 키워드 개수가 가장 많은 칸을 고른다.
- 동점이면 규칙 목록에서 앞에 있는 칸. 하나도 안 맞으면 `기타(담당 미정)`.
- 대소문자·여러 칸 공백은 무시하고 비교한다.

## 긴급도 점수 (core.js `DEFAULT_URGENCY`)
- 화난 표현 1개당 2점 (최대 3개), 기한 표현 1개당 3점 (최대 2개), 반복 문의 표현 1개당 1점 (최대 2개), `!!`·`??` 같은 연속 부호 1묶음당 1점 (최대 2묶음).
- 5점 이상 긴급, 2점 이상 주의, 나머지 보통. 기준값은 설정 객체로 바꿀 수 있다.
- 칸 안 정렬: 점수 높은 순, 같으면 입력 순서.

## 규칙 편집
- 글 형식 `칸 이름: 키워드, 키워드`. 전각 콜론·쉼표도 읽는다. 콜론 없음, 키워드 없음, 칸 이름 중복은 오류 글로 알려 주고 계산하지 않는다.

## 저장과 안전
- localStorage 한 키에 입력·규칙 글만 저장(try/catch). 막혀 있어도 화면은 뜬다.
- 사용자 입력은 textContent로만 화면에 넣는다. 네트워크 호출 없음.

## 한계
- 뜻 이해 없음(부정문, 비꼬는 말, 오타). 기본 키워드는 예시. 실제 폰 화면 미확인.
