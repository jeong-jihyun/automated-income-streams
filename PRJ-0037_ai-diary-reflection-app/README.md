# PRJ-0037 AI 일기 요약·회고 앱 (기록·요약·회고 엔진)

하루 일기와 기분(1~5)을 기록하고, 하루 요약과 주간·월간 회고(기록 일수, 기분 평균·흐름, 자주 나온 말, 대표 문장)를 만드는 명령줄 도구입니다. 요약은 AI가 아니라 문장 뽑기 방식이며, AI 회고는 함수를 꽂으면 덧붙는 구조입니다.

## 쓰는 법
```
python -m diaryrefl --file diary.json add "오늘은 산책을 했다. 기분이 좋았다." --date 2026-10-25 --mood 4
python -m diaryrefl --file diary.json summary 2026-10-25
python -m diaryrefl --file diary.json reflect 2026-10-19 2026-10-25
```

## 지키는 것
- 마음 상태를 진단하지 않고, 모든 회고에 안내 문구를 붙입니다.
- '죽고 싶다' 등 위기 표현이 있으면 AI에 보내지 않고 상담전화(109)·긴급전화 안내를 먼저 보여 줍니다.
- AI 회고는 짧거나 실패하면 붙이지 않고, 규칙 기반 회고만 남깁니다.
- 일기 파일은 임시 파일에 쓴 뒤 교체해 쓰다 끊겨도 안 깨집니다.

## 확인한 것 (테스트 8개 통과)
낱말·문장 처리, 요약 문장 선택·순서, 저장 규칙(같은 날 이어 쓰기·입력 검증), 회고 수치(기록률·평균·흐름·최고/최저 날), 빈 기간, 위기 표현 처리, AI 함수 연결·실패, CLI·깨진 파일.

## 확인하지 못한 것
- **일기 내용은 암호화하지 않고 평문 JSON으로 저장합니다.** 실제 서비스에는 암호화·잠금·계정·백업이 필요합니다.
- 한글 낱말 뽑기는 조사를 간단히 떼는 방식이라 어색한 낱말이 나올 수 있고, 요약 품질은 짧은 샘플로만 봤습니다.
- 위기 표현 목록과 상담전화 번호는 제가 아는 예시이며 공식 확인과 전문가 검토가 필요합니다. 우회 표현은 못 잡습니다.
- 실제 AI 회고 연결·품질, 앱 화면, 구독 결제, 스토어 등록·심사, 정신건강 관련 정책
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
