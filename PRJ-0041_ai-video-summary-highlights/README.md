# PRJ-0041 AI 영상 요약·하이라이트 서비스 (자막 기반 엔진)

강의·녹화 영상의 자막(SRT/VTT)으로 한눈에 보기 요약, 구간별 목차, 하이라이트 구간(시간)을 만들고, 영상 파일이 있으면 ffmpeg로 하이라이트를 잘라 새 파일로 저장하는 명령줄 도구입니다. 낱말 중요도(TF-IDF) 방식이며 AI가 아닙니다.

## 쓰는 법
```
python -m vidsum sample/lecture.srt --out out --window 100 --highlights 2
python -m vidsum lecture.srt --video lecture.mp4 --out out    # 하이라이트 mp4도 저장
```

## 지키는 것
- 자막 글만 보고 고릅니다. 영상 화면·소리는 분석하지 않는다는 문구를 항상 붙입니다.
- 원본 영상은 건드리지 않고 새 파일(highlight_01.mp4 …)로만 저장합니다.
- SRT·VTT 시간 형식, 태그 제거, 정렬되지 않은 자막, 시간이 거꾸로인 줄을 처리합니다.
- 저작권이 있는 영상은 권리자 허락 없이 공유하지 말라는 안내를 붙입니다.

## 확인한 것 (테스트 9개 통과)
SRT/VTT 읽기(짧은 시간 형식·태그·정렬·오류), 구간 나누기, 구간 제목이 주제를 따라가는지, 요약·하이라이트 선택(길이 제한), 보고서, ffmpeg 명령 구성·실패 처리, **실제 ffmpeg로 6초짜리 시험 영상에서 구간을 잘라 길이 확인**, CLI.

## 확인하지 못한 것
- **음성 인식은 하지 않습니다.** 자막이 이미 있어야 합니다(자동 자막 생성은 연결하지 않음). 자막이 틀리면 결과도 틀립니다.
- 요약 품질은 제가 만든 5분짜리 가짜 강의 자막(주제 3개)으로만 봤고, 실제 긴 강의·회의·영어/혼합 언어 영상으로는 시험하지 못했습니다.
- 하이라이트가 '정말 중요한 장면'인지는 판단하지 못합니다(화면·소리 미분석). 구간 경계가 문장 중간에서 잘릴 수 있습니다.
- AI 요약 연결, 대용량 영상 처리 시간·서버 비용, 업로드·계정·구독 결제, 화면, 영상 저작권 확인
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
