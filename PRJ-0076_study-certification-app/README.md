# PRJ-0076 학습 인증 스터디 앱 (공부 시간 검증·랭킹 도구)

공부 시간 기록 CSV를 검증하고 연속 일수, 그룹 랭킹, 의심 패턴 표시, 리포트 글을 만드는 명령줄 도구입니다. **사진·위치로 실제 공부를 확인하지는 않습니다(스스로 입력한 기록).**

## 쓰는 법
```
python -m studycert sample/logs.csv --today 2026-11-11 --since 2026-11-05 --until 2026-11-11
```

## 지키는 것
- 미래 날짜, 끝이 시작보다 빠른 기록, 형식 오류는 제외하고 어느 행인지 이유를 보여 줍니다.
- 같은 사람의 겹치는 기록과 하루 16시간 초과는 뒤 기록을 제외하고 이유를 남깁니다.
- 랭킹은 총 분 → 공부한 날 수 → 이름순이며, 같은 기록은 같은 순위(1,1,3)로 둡니다.
- 같은 길이가 4번 이상 반복되면 [확인] 표시를 하되 부정 확정이라고 쓰지 않습니다.

## 확인한 것 (테스트 11개 통과)
기록 필터링, 겹침·16시간 제외, 연속 일수(오늘 기록 없을 때 어제까지 유지 포함), 랭킹·동점, 기간 필터, 반복 패턴 표시, 리포트 문구, 잘못된 열, CLI.

## 확인하지 못한 것
- **실제 공부 여부는 확인할 수 없습니다.** 기록 조작은 완전히 막지 못하며 반복 패턴 표시는 참고용입니다.
- 앱 화면, 로그인, 푸시 알림, 사진 인증, 타이머는 만들지 않았고 서버·서비스 운영도 하지 않았습니다.
- 랭킹 경쟁이 학습 동기에 실제로 도움이 되는지는 사용자 시험을 하지 못했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
