# PRJ-0082 이메일 분류·자동 답장 구축 대행 (분류·답장 초안 도구)

메일 목록 CSV와 키워드 규칙 JSON으로 메일을 분류하고 답장 초안과 우선순위를 CSV로 만드는 명령줄 도구입니다. **메일을 받아오거나 보내지 않습니다(초안만 만듭니다).**

## 쓰는 법
```
python -m mailtriage sample/mails.csv sample/rules.json > result.csv
```

## 지키는 것
- noreply·광고·자동응답 메일에는 답장 초안을 만들지 않습니다.
- 같은 상대에게는 한 번만 초안을 만들고, --replied 파일에 적은 주소는 건너뜁니다(답장 반복 방지).
- 맞는 규칙이 없으면 '기타'로 두고 사람이 확인하게 표시합니다.
- 긴급·오늘까지 같은 말이 있으면 우선순위를 높음으로 표시합니다.
- CSV 칸이 = + - @ 로 시작하면 앞에 ' 를 붙여 엑셀 수식이 실행되지 않게 합니다.
- 주소가 없거나 번호가 중복인 행은 제외하고 몇 행인지 알려 줍니다.

## 확인한 것 (테스트 10개 통과)
행 제외, 분류·이름 치환, 우선순위, 자동 발송 메일 건너뛰기, 상대별 1회 초안, 이미 답장한 주소 제외, 규칙 없음 처리, CSV 수식 방지, 규칙 파일 오류, CLI 종료 코드.

## 확인하지 못한 것
- 실제 메일함(Gmail 등) 연결과 발송은 만들지 않았고 시험하지 못했습니다.
- 키워드 개수 세기 방식이라 문맥을 이해하지 못합니다. 부정문('환불 원하지 않아요')도 환불로 분류될 수 있습니다.
- 한국어 외 언어, 첨부 파일, 스레드(답장 사슬) 판별은 하지 않습니다.
- 실제 업무 메일로 분류 정확도를 재 보지 못했습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
