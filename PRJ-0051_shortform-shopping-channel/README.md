# PRJ-0051 숏폼 쇼핑 채널 (장면표·자막·무음 영상 제작 도구)

제품 정보(JSON)로 세로 숏폼(9:16)의 장면표, 자막(SRT), 설명 글을 만들고, 원하면 글자 카드로 된 무음 영상(mp4, 1080×1920)까지 만드는 명령줄 도구입니다. 첫 장면과 설명 글 맨 위에 광고 표시가 항상 들어갑니다. 업로드는 하지 않습니다.

## 쓰는 법
```
python -m shortform sample/product.json out --video
# out/plan.json, subtitles.srt, caption.txt, video.mp4
```

## 지키는 것
- 첫 장면 화면 문구에 '광고 · 구매 시 수수료를 받을 수 있어요'를, 설명 글 맨 위에 #광고를 넣습니다(문구는 예시).
- '무조건·100%·1위·최저가' 같은 과장·보장 표현이 있으면 만들지 않습니다. 가격은 확인한 날짜와 함께만 말합니다.
- 영상 길이는 60초 이내(말하는 속도 초당 6자 기준)이며 넘으면 줄이라고 안내합니다.
- 영상은 글자 카드 + 무음입니다. 유튜브·인스타에 자동 업로드하지 않습니다.

## 확인한 것 (테스트 13개 통과)
장면 구성과 시간 계산, 광고 표시 위치, 광고 표시를 지웠을 때 점검, 입력 거부 5가지, 60초 초과 거부, 가격 날짜 없으면 가격 장면 생략, SRT 형식, 파일 생성, **실제 mp4 생성**(ffmpeg, 1080×1920, 길이가 장면표와 1초 이내로 일치, 한글 글꼴로 그린 화면을 눈으로 확인).

## 확인하지 못한 것
- **제품 영상·사진·음성(내레이션)·배경 음악은 없습니다.** 만들어진 영상은 글자 카드뿐이라 그대로 올려도 시청자 반응이 좋을지는 확인하지 못했습니다(음성 합성·영상 소스는 연결하지 않음).
- 한글 글꼴은 이 작업 환경의 Noto Sans CJK를 썼습니다. 다른 컴퓨터에서는 --font로 글꼴을 지정해야 합니다.
- YouTube Shorts·인스타 릴스의 현재 규격·길이·광고 표시 정책(예: 유료 광고 표시 기능)은 확인하지 못했습니다. 쿠팡파트너스 등 제휴 약관, 조회·수익 효과도 미확인.
- 실제 제품 정보로는 시험하지 못했습니다(가짜 예시 제품).
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
