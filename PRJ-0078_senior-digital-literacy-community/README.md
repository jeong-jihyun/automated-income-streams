# PRJ-0078 시니어 디지털 교육 커뮤니티 (모임 운영 보조 도구)

수강생 CSV와 수업 CSV로 주제·요일·수준이 맞는 수업에 정원만큼 배정하고(넘치면 대기), 큰 글씨용 안내문과 출석률(연속 2회 결석 표시)을 만드는 명령줄 도구입니다. **결제·채팅·영상 수업 기능은 없습니다.**

## 쓰는 법
```
python -m seniorlearn enroll sample/learners.csv sample/classes.csv
python -m seniorlearn attend sample/attend.csv
```

## 지키는 것
- 수업 수준이 본인 수준 이하이거나 한 단계 위(도전)일 때만 후보로 삼습니다.
- 정원이 차면 대기로 보내고, 맞는 수업이 없는 사람은 따로 알려 줍니다.
- 안내문에는 전화번호를 넣지 않고 이름과 요일·시간만 적습니다(전화번호 마스킹 함수는 core에 있음).
- 형식 오류 행은 제외하고 몇 행인지 이유를 보여 줍니다.

## 확인한 것 (테스트 9개 통과)
오류 행 제외, 전화번호 마스킹, 정원·대기 배정, 한 단계 위 도전 수업 판정, 맞는 수업 없는 사람 표시, 큰 글씨 안내문 내용, 연속 결석 표시, 열 누락 오류, CLI 종료 코드.

## 확인하지 못한 것
- 어르신이 실제로 안내문을 읽기 편한지(글자 크기·화면)는 시험하지 못했습니다. 출력은 글자 크기를 정하지 않는 일반 텍스트입니다.
- 수준 판정은 본인이 적은 숫자(1~3)에 의존하며 실력 평가는 하지 않습니다.
- 앱 화면, 결제, 화상 수업, 서비스 운영은 만들지 않았습니다.
- 배정은 이름순 탐욕 방식이라 전체 최적을 보장하지 않습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
