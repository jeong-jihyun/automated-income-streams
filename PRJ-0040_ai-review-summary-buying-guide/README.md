# PRJ-0040 AI 상품 리뷰 요약·구매 가이드 앱 (요약 엔진)

리뷰 CSV(별점·글·날짜)를 읽어 의심 리뷰를 따로 표시하고, 별점 분포와 항목별(배송·가격·품질·사이즈·소음·디자인·사용감) 장점·단점을 근거 인원수와 실제 리뷰 한 줄로 보여 주는 구매 가이드(마크다운)를 만드는 명령줄 도구입니다. AI가 아니라 낱말 세기 방식입니다.

## 쓰는 법
```
python -m reviewsum sample/reviews.csv --out guide.md --affiliate
```

## 지키는 것
- 똑같은 글, 하루에 몰린 5점, 너무 짧은 글은 '의심'으로 표시해 통계에서 빼고 개수를 밝힙니다. 가짜라고 단정하지 않습니다.
- 장점·단점은 최소 2명 이상 언급한 항목만 보여 주고 근거 인원수를 함께 적습니다.
- 제휴 링크를 쓰면 수수료 안내 문구를 붙입니다(--affiliate). 제품 품질을 보증하지 않는다는 문구를 항상 붙입니다.
- 읽을 수 없는 줄은 건너뛰고 줄 번호를 알려 줍니다.

## 확인한 것 (테스트 8개 통과)
CSV 읽기·오류 줄 건너뛰기, 의심 리뷰 표시, 긍정/부정 판별, 항목별 집계, 가이드 수치(분포 합계·평균), 제휴 문구, 전부 의심일 때 오류, 최소 근거 필터, CLI.

## 확인하지 못한 것
- **긍정·부정 낱말과 항목 키워드는 제가 정한 간이 목록이라 오판이 많습니다**(부정문 '안 좋아요', 비꼬는 말, 사투리 등 처리 못 함). 요약 품질은 13개짜리 가짜 샘플로만 봤고 실제 쇼핑몰 리뷰로 시험하지 못했습니다.
- 의심 리뷰 기준(같은 날 5점 5개 등)은 예시이며 실제 조작 리뷰를 얼마나 잡는지 확인하지 못했습니다.
- **리뷰 수집은 만들지 않았습니다.** 쇼핑몰 리뷰를 긁어 오는 것은 이용약관·저작권·법 문제가 있을 수 있어 사용자가 합법적으로 얻은 CSV만 처리합니다.
- AI 요약 연결, 수백~수만 개 처리 속도, 제휴 프로그램 가입·링크 연동, 화면, 광고 수익, 제휴·광고 표시의 법적 적합성
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
