# PRJ-0019 웹사이트 가동·상태 모니터링

내 사이트 주소를 주기적으로 점검해서 **연속 N번 실패하면 장애 알림, 되살아나면 복구 알림**을 한 번씩만 보내고, **상태 페이지(HTML)** 를 만들어 줍니다. 표준 라이브러리만 사용(SQLite 기록).

```bash
python -m uptime_monitor --config sample/sites.json                 # 한 번 점검 + status.html 생성
python -m uptime_monitor --config sample/sites.json --loop 300      # 5분마다 계속 (Ctrl+C로 끔)
python -m pytest -q
```
설정: `fail_threshold`(연속 실패 횟수), `timeout_sec`, `slow_ms`, `keyword`(페이지에 있어야 할 문구), `webhook_url`(슬랙 등 수신 주소, 선택).
**본인이 운영하는 사이트만** 점검하세요. 간격은 30초 미만으로 줄여지지 않습니다.

## 확인한 것 / 못 한 것
- 확인(테스트 6개, 로컬 시험 서버): 정상/HTTP 500/문구 없음/느림/접속 거부/시간 초과 판정, 장애·복구 알림이 상태가 바뀔 때만 한 번씩 나감, 가동률 계산, 상태 페이지 이스케이프, 웹훅 실제 전송, 설정 오류 안내.
- **못 한 것**: 24시간 상시 실행(서버·스케줄러 필요), 여러 위치에서 점검, SSL 인증서 만료 점검, 구독 결제·로그인, 상태 페이지 공개 호스팅은 없음. 실제 슬랙·카카오 웹훅 형식은 시험하지 않았습니다(`{"text": ...}` 형식만 보냄). 점검 PC가 꺼지거나 인터넷이 끊기면 사이트 장애로 오판할 수 있습니다.
