# PRJ-0070 양도세·배당세 자동 계산기 (예상 세금 계산 도구)

거래 CSV(매수·매도·배당)를 선입선출(FIFO)로 짝지어 양도차익, 기본공제, 예상 양도세, 배당 원천징수와 금융소득 기준 초과 경고를 계산하는 명령줄 도구입니다. **예상값이며 세무 신고·자문이 아닙니다.**

## 쓰는 법
```
python -m taxcalc sample/trades.csv [--config cfg.json]
```

## 지키는 것
- 같은 종목은 먼저 산 것부터 팔린 것으로 보는 선입선출(FIFO)로 양도차익을 계산하고, 남은 수량은 다음 해로 이어집니다.
- 해외 주식은 연도별 손익을 합산한 뒤 기본공제(2,500,000)와 세율(22%)을 적용합니다(둘 다 설정의 예시값).
- 국내 주식은 기본값으로 과세하지 않되 결과에는 보여 줍니다.
- 배당은 원천징수액이 입력돼 있으면 그대로 쓰고 없으면 추정하며(둘을 구분해 표시), 합계가 큰 해에는 금융소득 종합과세 경고를 냅니다.
- 보유 수량보다 많이 판 행, 잘못된 type·market·숫자는 계산하지 않고 어디가 문제인지 알립니다.

## 확인한 것 (테스트 11개 통과)
FIFO 원가·차익, 남은 수량 이월, 해외 손익 합산·공제, 국내 비과세 표시, 배당 원천징수(입력/추정), 초과 매도 거부, 손실 해 경고(세액 0), 큰 배당 경고, 같은 날 매수 후 매도, 잘못된 입력, CLI.

## 확인하지 못한 것
- **현행 세법과 맞는지 확인하지 못했습니다.** 공제·세율·기준금액은 예시이며 연도마다 바뀝니다.
- 종목별 과세 여부, 환율 적용일, 필요경비 인정 범위, 결손금 이월, 가산세는 반영하지 않았습니다.
- 홈택스 신고 연동·화면·서비스 운영은 만들지 않았습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
