# PRJ-0025 노쇼 방지 예약 알림 + 대기자 채우기

예약 알림(기본 24시간 전·2시간 전), 손님 답장 처리(1=확인, 2=취소), **취소가 나면 대기자에게 자리 제안**(15분 안에 1/2 답, 시간이 지나면 다음 대기자), 노쇼 집계를 해 주는 로컬 도구입니다. 파이썬 표준 라이브러리 + SQLite.
**문자를 실제로 보내지 않습니다.** 보내는 함수(sender)를 바깥에서 넣는 구조이고, 명령줄에서는 화면에 출력만 합니다.

```bash
python -m noshow --config sample/config.json add 홍길동 010-1234-5678 "2031-03-05 10:00"
python -m noshow --config sample/config.json wait 김영희 010-2222-3333 "2031-03-05 10:00"
python -m noshow --config sample/config.json remind --now "2031-03-04 10:00"
python -m noshow --config sample/config.json reply 010-1234-5678 2 --now "2031-03-04 11:00"
python -m pytest -q
```
## 확인한 것 / 못 한 것
- 확인(테스트 8개): 같은 시간 중복 예약 차단, 알림은 시점마다 한 번만, 발송 실패 시 다음에 재시도, 확인한 손님은 마지막 알림만, 취소→대기자 제안→거절/시간초과→다음 사람→수락, 방문 완료 표시와 노쇼 집계(확인하고 안 온 손님 포함).
- **못 한 것**: **실제 문자(SMS/알림톡) 발송 연동 없음**(문자 업체 가입·발신번호 등록·비용 필요). 발송 문구가 정보성인지 광고성인지에 따른 법적 요건(동의·수신거부 안내 등)은 확인하지 못했습니다. 손님 답장을 받는 수신 서버(웹훅)는 없습니다. 병원은 환자 정보(민감정보) 취급 규정이 있어 그대로 쓰면 안 될 수 있습니다. 구독 결제·관리 화면·여러 지점은 없습니다. 시간은 서버 현지 시각 기준입니다.
