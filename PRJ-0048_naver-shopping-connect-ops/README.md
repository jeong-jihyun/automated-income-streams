# PRJ-0048 네이버 쇼핑 커넥트 운영 (후기 글 초안·점검 도구)

직접 써 본 제품의 사실(사용 일수·장점·아쉬운 점)을 JSON으로 넣으면 후기 글 초안을 만들고, 이미 쓴 글은 고지문·과장 표현·사진 수·분량·균형을 점검하는 명령줄 도구입니다. **써 보지 않았거나 아쉬운 점이 없으면 초안을 만들지 않습니다.**

## 쓰는 법
```
python -m connect make sample/facts.json --out post.md
python -m connect check post.md --photos 3
```

## 지키는 것
- 사용 일수(1일 이상)·장점·아쉬운 점이 없으면 초안을 만들지 않습니다(경험 지어내기 방지).
- 초안은 맨 위와 맨 아래에 제휴 수수료 고지를 넣습니다(문구는 예시이므로 최신 공식 문구를 직접 확인).
- 점검은 '무조건·100%·역대급·완치' 같은 과장·효능 단정 표현, 고지 위치(처음 200자), 사진 3장 미만, 분량, 아쉬운 점 유무를 봅니다.
- 네이버에 자동으로 올리거나 상품을 수집하지 않습니다.

## 확인한 것 (테스트 12개 통과)
초안 생성(고지 위·아래, 아쉬운 점, 가격 표기), 필수 입력 누락 거부(5가지), 사용 0일 거부, 점검 규칙들, 고지 위치 점검, 입력 파일 오류, CLI. 생성된 초안은 사진·분량만 추가하면 점검을 통과하는 구조입니다.

## 확인하지 못한 것
- **네이버 쇼핑 커넥트의 현재 약관·가입 조건·고지 문구·수수료 정책을 확인하지 못했습니다.** 고지 문구와 사진 3장·600자 기준은 제가 정한 예시입니다.
- 실제 상품 후기 시험은 가짜 예시 제품으로만 했습니다. 초안은 뼈대일 뿐 사용자가 직접 문장을 다듬어야 하며, 검색 노출·전환·수익은 확인하지 못했습니다.
- 사진이 직접 찍은 것인지는 검사하지 못합니다(장수만 받음). 표시광고법상 문구 적합성은 전문가 확인이 필요합니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
