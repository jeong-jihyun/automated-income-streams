# PRJ-0023 영수증·명함 OCR

사진(또는 OCR 글자)에서 **영수증(상호·날짜·품목·합계·부가세)** 과 **명함(이름·회사·전화·이메일·주소)** 항목을 뽑아 CSV로 만들어 주는 명령줄 도구입니다. 글자 읽기는 컴퓨터에 설치된 `tesseract`를 부르고, 읽은 글자를 표로 정리하는 부분은 직접 만들었습니다.

```bash
python -m ocr_app receipt 영수증.jpg --out receipts.csv            # 한글: tesseract-ocr-kor 설치 필요
python -m ocr_app namecard 명함1.png 명함2.png --out cards.csv
python -m ocr_app receipt sample/receipt.txt --out r.csv           # 글자 파일로 정리 부분만 시험
python -m pytest -q
```
- 못 찾은 항목은 비워 두고 경고를 표시합니다. 품목 합계와 총합계가 다르면 "인식 오류 확인" 경고가 나옵니다.
- CSV는 엑셀에서 한글이 안 깨지도록 BOM 포함, `=` `+` `@`로 시작하는 글자는 수식 실행 방지 처리.

## 확인한 것 / 못 한 것
- 확인(테스트 8개): 영수증·명함 항목 추출, 경고, CSV·수식 방지, 이미지 손질, **실제 tesseract로 영문 영수증 이미지를 읽어 날짜·합계 추출**, 한글 언어 데이터가 없을 때 안내.
- **못 한 것**: 이 환경에는 tesseract의 **한글(kor) 데이터가 없어 한글 사진은 시험하지 못했습니다.** 실제 영수증·명함 사진(구겨짐, 각도, 조명)에서의 인식률은 모릅니다. 영수증 양식이 다양해 품목 줄 규칙이 안 맞는 경우가 많을 수 있습니다. 모바일 앱(Google Play·App Store), 카메라, 구독·광고 기능은 만들지 않았습니다(파이썬 명령줄 도구). 영수증·명함은 개인정보이므로 저장·공유 시 주의하세요.
