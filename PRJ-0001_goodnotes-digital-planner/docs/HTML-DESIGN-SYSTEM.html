06 · Accessibility rules

  • 본문과 배경의 텍스트 대비는 WCAG 2.2 AA 기준으로 검증합니다.
  • 색상만으로 성공·오류·선택 상태를 전달하지 않습니다.
  • 키보드 포커스 표시와 명확한 레이블을 제공합니다.
  • 터치 대상은 최소 44×44px를 권장합니다.
  • 모션 감소 설정을 존중하고 상태 변경을 텍스트로도 안내합니다.
