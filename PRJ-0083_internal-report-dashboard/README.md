# PRJ-0083 사내 보고서 취합 대시보드 구축 (팀별 CSV → HTML 한 장)

팀별 주간 보고 CSV가 든 폴더를 합쳐 지표×팀 표, 전주 대비 증감(%), 막대, 합계가 있는 HTML 대시보드 한 장을 만드는 명령줄 도구입니다. **서버·로그인·자동 수집 없이 파일만 읽습니다.**

## 쓰는 법
```
python -m reportboard sample/reports --out dashboard.html --teams 영업,고객지원,인사
```

## 지키는 것
- CSV 열은 team, week, metric, value 입니다. 숫자가 아니거나 빈 칸인 줄은 제외하고 파일 이름과 행 번호를 대시보드 아래와 화면에 남깁니다.
- 같은 팀·주·지표가 여러 번 나오면 마지막 값을 쓰고 몇 건 덮어썼는지 알려 줍니다.
- --teams 로 적은 팀이 이번 주 보고가 없으면 경고를 맨 위에 표시합니다.
- 전주 값이 없거나 0이면 증감은 표시하지 않습니다.
- 팀·지표 이름은 HTML 로 이스케이프합니다.

## 확인한 것 (테스트 10개 통과)
제외 줄의 파일·행 번호, 쉼표 숫자, 중복 마지막 값, 전주 대비 계산, 누락 팀 경고, 새 지표의 증감 없음, 합계, HTML 이스케이프, 빈 폴더·열 누락 오류, CLI 파일 생성.

## 확인하지 못한 것
- 주 이름(2026-W46)을 글자 순서로 비교합니다. 연도가 바뀌는 주나 W9와 W10처럼 자릿수가 다른 이름은 올바르게 정렬되지 않을 수 있습니다(두 자리 맞춤 필요).
- 합계는 단순 합이라 평균이 의미 있는 지표(처리율 등)에는 맞지 않습니다.
- 브라우저·휴대폰에서 모양을 확인하지 못했습니다.
- 엑셀 파일(.xlsx), 구글 시트 직접 읽기, 서버 배포는 만들지 않았습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
