# PRJ-0039 소상공인 SNS 문구 일괄 생성기 (글 틀 기반)

매장 정보(JSON)로 한 달 치 SNS 게시글과 해시태그를 만들어 날짜별 표(CSV)로 내보내는 명령줄 도구입니다. AI가 아니라 글 틀을 돌려 쓰는 방식이고, 올리기는 직접 합니다(자동 게시 없음).

## 쓰는 법
```
python -m snsgen sample/shop.json --start 2026-11-01 --days 30 --seed 1 --out captions.csv
```

## 지키는 것
- 글은 매장 정보에 적힌 상품·이벤트·영업시간만 써서 만듭니다. 없는 할인이나 효능을 지어내지 않습니다.
- 같은 주제가 이틀 연속 나오지 않고, 같은 글은 가능한 한 피합니다. 틀이 모자라 반복되면 숨기지 않고 알려 줍니다.
- '최고·1위·100%·완치·무조건' 같은 과장·단정 표현은 점검 칸에 표시합니다. 협찬이면 #광고를 항상 붙입니다.
- 받침에 맞춰 조사(을/를, 이/가, 으로/로 등)를 고릅니다.

## 확인한 것 (테스트 9개 통과)
매장 정보 검증, 주제 연속 방지·재현성, 글 다양성과 반복 표시, 정보 밖 내용 미사용, 말투(friendly/formal), 과장 표현 점검, 해시태그 개수·광고 표시, 조사 처리, CLI. (개발 중 조사 오류와 반복이 많은 문제를 시험으로 찾아 고침)

## 확인하지 못한 것
- **해시태그 10개·글 2,200자 제한과 광고 표시 규정은 제가 아는 값입니다.** 플랫폼·법(표시광고법 등) 기준은 바뀔 수 있어 공식 안내로 확인해야 합니다.
- 과장 표현 목록은 일부뿐이라 놓치는 표현이 있습니다. 업종별(의료·식품 등) 광고 심의 규정은 반영하지 않았습니다.
- 영문·숫자로 끝나는 상호의 조사는 간이 처리입니다. 틀이 정해져 있어 글이 비슷해 보일 수 있고, 실제 반응(좋아요·방문)은 확인하지 못했습니다.
- AI 문구 생성 연결, 사진·이미지 생성, 인스타그램·네이버 등 실제 게시(만들지 않음), 화면, 구독 결제
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
