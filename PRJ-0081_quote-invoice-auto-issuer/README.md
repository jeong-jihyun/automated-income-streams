# PRJ-0081 견적서·청구서 자동 발행 시스템 (HTML 문서 생성 도구)

품목·할인·부가세가 적힌 JSON 사양 파일로 견적서 또는 청구서 HTML 한 장을 만들고, 번호(Q-202611-001 형식)를 이어 매기는 명령줄 도구입니다. **전자세금계산서 발행, 메일 발송, 결제는 하지 않습니다.**

## 쓰는 법
```
python -m quoteinv sample/quote.json --out out
```

## 지키는 것
- 금액은 Decimal 로 계산하고 원 단위 절사(floor)가 기본, half_up 도 고를 수 있습니다. 부가세율 10%는 예시 설정값입니다.
- 번호는 종류(견적 Q, 청구 I)와 월별로 이어지고 out 폴더의 numbers.json 에 기록합니다.
- 사업자번호는 형식과 검증 숫자만 확인하며 실제 등록 여부는 확인하지 않습니다.
- 입력 글자는 HTML 로 이스케이프해서 넣습니다.
- 형식 오류는 한 번에 모두 모아 보여 주고 종료 코드 2로 끝납니다.

## 확인한 것 (테스트 11개 통과)
공급가액·할인·부가세·합계 계산, 절사·반올림 차이, 부가세 없음, 한글 금액, 번호 이어 매기기(월·종류별), 사업자번호 검증 숫자, 입력 오류 메시지, HTML 이스케이프와 안내 문구, CLI 로 파일 생성·번호 증가·오류 종료 코드.

## 확인하지 못한 것
- 세법상 올바른 반올림·면세·영세율 처리는 확인하지 못했습니다. 부가세율과 절사 방식은 예시이며 실제 발행 전 세무 전문가 확인이 필요합니다.
- 브라우저에서 인쇄했을 때의 모양(여백·쪽 나눔)은 확인하지 못했습니다.
- 번호 기록 파일을 두 곳에서 동시에 쓰는 경우는 막지 않습니다.
- PDF 변환, 메일 발송, 전자세금계산서 연동은 만들지 않았습니다.
- 설계 문서(드라이브)는 읽지 않고 시트 한 줄 설명으로 범위를 잡았습니다.
