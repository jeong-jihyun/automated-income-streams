# PRJ-0031 사주·타로·MBTI AI 상담 앱 (재미용 시험 엔진)

MBTI 간이 검사 채점, 타로(메이저 22장) 뽑기, 간이 사주(연주·일주·시주, 오행 개수), 상담 글 생성을 하는 명령줄 도구입니다. 재미와 자기 성찰용이며 미래를 단정하지 않습니다.

## 쓰는 법
```
python -m fortune mbti sample/mbti_questions.json 5,1,5,1,1,5,5,1
python -m fortune tarot --n 3 --seed 7
python -m fortune saju 2000-01-01 --hour 12
```
코드에서 `reading.consult(질문, 카드, mbti, 오행, llm=내_AI_함수)`로 AI 문장을 붙일 수 있습니다. AI는 연결돼 있지 않고, 함수를 꽂아야 쓰입니다.

## 안전 장치 (테스트로 확인)
- 위기 표현("죽고 싶다" 등)은 AI에 보내지 않고 상담전화(109) 안내만 합니다.
- 건강·법률·투자·임신 결정 질문은 풀이로 답하지 않고 전문가 상담을 권합니다.
- AI 결과에서 단정·공포 문장("반드시", "100%", "사망", "저주" 등)은 문장째 지우고, 거의 다 지워지면 기본 문장으로 바꿉니다. AI 오류 시에도 기본 문장.
- 모든 풀이에 "재미와 자기 성찰용" 문구를 붙입니다.

## 확인한 것 (테스트 9개 통과)
MBTI 채점·동점·오류, 타로 재현성·중복 없음, 사주 기준일(2000-01-01 일진 무오 등) 계산, 안전 필터, AI 실패 대체, CLI.

## 확인하지 못한 것
- **사주 정확도**: 월주(절기 계산) 미구현, 입춘을 2월 4일로 근사, 음력·윤달·태어난 지역 시차 미반영. 만세력 프로그램과 대조해 보지 않았음(일진·연주는 몇몇 알려진 날짜로만 확인).
- 실제 AI 연결·풀이 품질, 안전 필터의 한계(정규식이라 우회 표현은 못 막음), 위기 안내 문구·전화번호의 최신성(공식 확인 필요)
- 앱 화면, 결제, 앱스토어/구글플레이 등록·심사(점술 앱 정책 포함), MBTI 상표·검사지 저작권(샘플 문항은 자체 제작 간이 문항으로 공식 검사가 아님)
