# 설계

## 구성
- `app/core.js`: 화면 없는 계산 함수 모음. 브라우저는 `window.SnsCore`, node는 `module.exports`.
- `app/index.html`: 입력 칸, 버튼, 결과 그리기. 처음 열 때 샘플 계획을 넣고 바로 한 번 계산한다.
- `app/style.css`: 18px 기본 글씨, 세로 화면용 한 줄 레이아웃.
- `tests/test_all.js`: node:test 시험.

## 판정 규칙 (코드 기준)
- 입력 줄: `날짜, 채널, 제목`. 날짜는 `YYYY-MM-DD` 또는 `.` `/` 구분. 없는 날짜·빈 채널은 오류 줄로 따로 모은다.
- 중복: 같은 날짜 + 같은 채널(대소문자 무시)이 2건 이상.
- 빈 날: 선택한 달에서 게시가 없는 날. 옵션으로 토·일 제외.
- 주: 월요일 시작. 7일이 모두 이 달인 주만 "주당 최소 게시 수 미만" 판정. 일부만 걸친 주는 표시만 한다.
- 요일 쏠림: 게시 5건 이상일 때 최다 요일 비율이 기준(기본 40%)을 넘으면 경고.
- 선택한 달 밖의 일정은 계산에서 빼고 건수만 알린다.

## 견적
- 공급가 = 단가 x 게시 수. 부가세 = 공급가 x 비율을 한 번 반올림. 합계 = 공급가 + 부가세.
- 채널별 부가세는 `allocate` (가장 큰 나머지 순으로 1원씩)로 나눠 채널 합이 전체 부가세와 같다.

## 안전
- 외부 호출, 결제, 로그인, 전송 없음. 저장은 localStorage만(실패해도 동작).
- 화면에 넣는 사용자 글은 이스케이프한다.
