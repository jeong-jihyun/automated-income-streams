# SNS 콘텐츠 일정 관리 대행

게시 계획(날짜, 채널, 제목)을 한 줄씩 넣으면 문제를 찾아 주고, 월 달력과 대행 월 견적을 보여 주는 휴대폰용 웹앱이에요. 자동으로 게시하지 않아요. 인터넷 없이 돌아가요.

## 하는 일
- 같은 날 같은 채널에 글이 겹치는지 찾아요.
- 게시가 없는 빈 날을 알려 줘요 (주말 제외 옵션 있음).
- 주(월~일)마다 게시 수를 세고, 기준보다 적은 주를 표시해요.
- 한 요일에 몰렸는지 봐요 (기본 40% 초과, 5건 이상일 때).
- 월 달력 표로 보여 줘요.
- 견적: 게시당 단가 x 게시 수 = 공급가, 부가세(기본 10%), 합계. 채널별 부가세는 나머지 처리로 나눠서 합이 딱 맞아요.

## 쓰는 법
1. `app/index.html` 을 열어요. 샘플 데이터가 이미 들어 있어요.
2. "점검하고 견적 보기" 버튼을 눌러요.
3. 입력 칸이나 계획 글을 고치고 다시 눌러요. (입력한 값은 이 기기 브라우저에만 저장돼요.)

입력 모양: `2026-11-05, 인스타, 제목` (쉼표 또는 탭). `#` 로 시작하는 줄은 건너뛰어요.

## APK 받아 설치하는 법
1. 저장소를 GitHub에 푸시해요.
2. GitHub의 Releases 에서 `apk-PRJ-0090` 을 열고 `.apk` 파일을 받아요.
3. 폰에서 받은 파일을 눌러 설치해요.
4. "출처를 알 수 없는 앱" 설치 허용을 물으면 허용해요.

(이 폴더에는 APK 만드는 설정이 없어요. APK는 별도 단계에서 만들어요.)

## 시험하는 법
`node --test tests/test_all.js` (Node 22 기준. 또는 폴더에서 `node --test`)

## 확인한 것 / 못 한 것
확인한 것
- `core.js` 의 계산 시험 15개가 모두 통과했어요 (줄 읽기, 달력 칸, 중복, 빈 날, 주별 합, 요일 쏠림, 달 밖 일정 제외, 나머지 처리 합 보존, 견적 합계).
- 화면 코드를 가짜 화면 객체로 돌려서 샘플 결과(12건, 중복 1, 견적 396,000원)와 월 오류 문구가 나오는 것을 확인했어요.
- 소스에 http 주소나 CDN이 없어요.

못 한 것
- 실제 폰 설치·화면 미확인 (실제 브라우저·폰에서 열어 보지 못했어요. 글자 크기와 달력 칸 모양은 눈으로 못 봤어요).
- APK 빌드와 GitHub 푸시, Releases 올리기.
- 공휴일 반영, 채널별 단가, 한 달을 넘는 일정 처리.
